# 封面人物资产库

`model-assets/registry.json` 是人物资产的唯一入口。用户说“御用模特”或“默认模特”时，解析 `defaultModelId`（当前为 `dalala-cover-muse-007`）；用户明确说“01 号模特”时，仍解析为 `dalala-cover-muse-001`。

## 调用顺序

1. 从注册表解析 `modelId`。
2. 读取该人物的 `identity.json`。
3. 把 `primaryReference` 作为人物身份参考图，不得只凭文字描述重建人物。
4. 根据构图规则改变景别、位置、动作、服装、光线和背景时，保持 `identityLock.locked` 中的身份特征。
5. 生成后对照主参考图检查脸型、五官关系、年龄感、肤色和发色；身份明显漂移时不得作为该人物的模板资产。

主参考图必须永久保留。新增通过确认的角度、表情和动作图时，只增加到 `approvedReferences`，不得覆盖原图。

当前默认人物母图为 1024×1536（2:3）。工作台默认封面画幅仍为 3:4；生成封面时根据选中的构图规则处理画幅，不得拉伸或覆盖母图。
