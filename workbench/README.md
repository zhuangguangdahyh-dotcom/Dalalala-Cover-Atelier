# Dalala 封面工作台 · 本机首版

## 启动

在此目录运行 `npm start`，打开 http://127.0.0.1:4318 。本机版现在直接进入工作台，无需登录；右上角仍可切换封面制作和风格实验室。若旧版已有管理员账号，会沿用其身份以保留原来的素材和任务记录。新安装使用固定的本机身份。

## 已实现

- 前台：输入需求、上传最多 6 张 JPG / PNG / WebP、选画幅、选择已上架模板、提交制作、等待页、小游戏、交付保存、带意见或空意见重做、个人制作记录。
- 等待：参考与用户素材轮播，沿边缘移动的光点；游戏必须主动选择；制作完成时保留游戏，并提供成品提醒及查看按钮。
- 小游戏：只保留“猫咪版贪吃蛇”。玩家控制俯视银灰虎斑猫拾取鸡胸肉冻干，死亡后可重新开始或结束；生成完成时游戏边框提示，可直接查看成品或结束当前一局后进入交付页。
- 后台：参考逐张管理、导入新参考、执行拆解、修改 Skill 并保留历史副本、字体依赖展示、新主题测试、验收上架/下架。封面名称与内容建议在最终验收后生成。
- 身份：本机版免登录，沿用原管理员身份；旧账号及会话数据保留供历史兼容。前后台输入草稿分别保留在当前会话。旧登录接口可通过 `DALALA_LOCAL_NO_LOGIN=0` 恢复，仅供本机兼容测试。

## 制作执行器

服务器以 `codex exec --model gpt-6-sol --config model_reasoning_effort=medium --sandbox workspace-write` 调用本机已登录 Codex；模型与推理强度由工作台固定，不受本机 Codex 全局默认值变化影响。任务先写 `request.json`，执行器加载所选 Skill 与用户数据，再生成分析和成品。仅在 `result.json` 声明成功且实际 PNG 存在时进入交付。后端拆解任务要求实际 Skill 文件存在才算完成。

真实图像生成仍需在运行时验证。本机检测到 Codex 不代表非交互环境一定拥有图像工具或有效授权；不可用时任务显示失败，不会把参考图或旧输出当成新作品。

## 数据

历史账号、登录会话与上传位于 `workbench/data/`；本机免登录模式会沿用已有管理员记录。任务按 UUID 保存，含请求、实时阶段记录、执行日志、分析、结果和输出。规则仍维护在项目的 `skills/` 与 `cover-skills/registry.json`。重做建立新任务并关联旧版，不覆盖旧图。服务重启时未完成任务标记为中断并允许重试。

## 验证

`npm test` 使用独立临时数据与注册表验证登录、权限、素材和任务隔离、发布门槛、输入校验。`node tests/preview-server.mjs` 启动 14320 端口的隔离界面测试环境；测试账号仅存在临时目录，绝不进入正式服务。

## 尚未交付的线上部分

此版本仅监听本机回环地址，且免登录会授予本机操作者管理员权限，因此不能直接对外转发这个服务。若以后制作供外部用户使用的网页应用，应部署独立的前台服务，隔离风格实验室和客户素材，并先验证线上图像生成能力与供应商地区可用性。
