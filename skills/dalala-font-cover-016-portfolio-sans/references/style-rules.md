# 字形结构与角色边界

原图里有四种可读的文字声部，不是一套字体的同字重排列：网页姓名 `Louis Liang` 的高重、宽字身与圆字腔承接深色背景；黑色中文结论极粗、方正、整句一条长线；中文方法行明显变轻变小；`PORTFOLIO` 则变为淡色细线尾注。上方数字加英文词也用简洁无衬线，不增设装饰花字。以上是从原图归纳的测试目标，并非已取得授权的商业字体名称或经确认字库。

- `heroName`：保留大小写词形，字身圆润但不是泡泡体；小写 `o`、`u`、`a` 腔口开放，黑暗背景上的大面积实色清楚。单行，不能挤压空格或缩到网站屏幕中部。
- `mainTitle`：中文粗重近方骨架，笔画不糊腔、不追求手写笔触；黑色直立单行。选中的重点字保持**同一黑色字形**，粉色填充、细边线与黑色控制点属于另外的封面效果层。
- `supportingText`：现代黑体中粗，阿拉伯数字与 `AI`/其他拉丁缩写基线一致；宽度仅约主标题的 43%–50%，小行与大行不抢注意。
- `footerWord`：极细大写英文，在浅底以低到中对比粉色呈现；一行字宽约 38% 画布，不带投影／描边。

测试阶段必须分别验证拉丁大小写、中文繁简常见部件和含数字的混排。具体品牌名称、文字内容、色值可变；字形角色、相对字重与行数不变。若换字后越界，应先改写内容或重新选择内容角色，不拉宽画布或变成两行。
