# 字形待测质量门槛

当前没有生成测试或批准参考；各项均未通过记录。

1. 拉丁大小写、中文部件、数字、空格和混排均逐字准确；同一角色字骨一致，实心字内部不糊。
2. 网站姓名单行接近网站内宽的 93%，视觉够厚、不轮廓化；文字不盖住中央人的眼睛。
3. 中文结论完整单行、字高统一；中心重点词和左右主字同字形，只在其**背后**出现独立编辑选框。
4. 中文方法行的视觉高度为主字 40%–48%，英文尾注细且不抢中文；不得通过把粗字压扁来适配。
5. 透明背景可与纸底／深屏分别合成；查看原尺寸与 360 px 缩略图，无错字、伪汉字、阴影污边或虚假透明。
6. 经过至少一条同机制内容与一条不同领域内容测试，并获用户确认后，才能考虑完成字体资产验收；在此之前 registry 保持 testing。
