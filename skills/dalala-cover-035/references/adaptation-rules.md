# 参考 035｜跨内容重建语法

## 先判主题，再替换槽位

确认行业、账号身份、要讲的具体数量、类别词、四字结论和能支撑第一人称表达的真实人物。原题「5个 / vlog / 创意视角」是“数量承诺 → 内容类别 → 角度/方法”的完整逻辑；迁移时保留这三个语义角色，不能只换行业名。若新内容无法压成左 2–3 字、左下 3–6 个拉丁字母、右侧四个汉字，先重写标题，不增行、不移出文字带。

## 锁定的画面关系

- 3:4 整张连贯照片；中心近脸高机位自拍，脸部中心约 (52%,35%)，人物从画面 y≈2% 延续到 y≈98%。左侧数字标题 x≈3–30%、y≈27–41%；小写拉丁类别 x≈9–29%、y≈40–50%；右侧四字竖排 x≈76–96%、y≈35–75%。
- 人物脸、直视镜头、笑或与主题相称的自然表情是主角。职业道具必须和人物动作真实相连，位置在下部；背景至少能读出现场材质和透视。左右文字包围脸但不碰眼、鼻、嘴。
- 白字与小面积冷色字维持明度层级；青蓝环境和中性地面在新行业可换成等价的现场冷/中性色关系，具体色值不继承。
- 白字分字手写，左侧数字与量词尺度不同；右侧窄竖带的单字中心有自然错位。拉丁字小写且轻，不换成普通网页斜体。

## 素材诊断与改造

1. **T0 原貌保留**：有高机位近脸自拍、两侧净区、手部动作和真实场景时，按 3:4 裁切并局部校色即可。
2. **T1 空间重排**：同一照片面部、动作成立但侧边不足，可受控扩充原场景纹理或微调裁切；不能挤窄脸或把人物缩成半身远景。
3. **T2 结构改造**：有合适人物和真实道具，但姿态/景别不满足时，用同一人物可验证素材重建高机位透视与手部连接，保留身份和产品事实；成图须检查五官与手指。
4. **T3 重拍/重建全场**：只有平视证件照、产品孤图或无事实场景时，需重拍或建立完整可信现场。不要抠人贴蓝门，不要为凑数量生成无行业意义的 AI 人物。

素材锚点：脸型五官、真实身份、手与道具接触、职业物件准确形状。自由区：现场冷色来源、衣着、植物、门框和地面具体材质、小暖色物件。背景弱化只能在字后局部进行，不能擦掉支撑自拍现场感的透视与纹理。

## 可测试的迁移示例

- 设计师账号：设计师在真实施工现场高机位自拍，手持测量或记录工具；“5个 / site / 看店视角”只是长度示意，具体中文与英文须改成自然、准确的标题后才能测试。
- 医生账号：医生在允许拍摄的真实工作环境自述沟通方法，保持高机位近脸和下部职业动作；“数量 / 类别 / 四字结果”需对应实际内容，不以手术道具制造噱头。

测试至少一组与原 vlog 题材不同、内部逻辑完整的新主题，并核对 360 × 480 缩略图。示例并非已完成的测试或可直接发布的文案。

## 字体、色彩与层序

白色中文/数字调用 `dalala-cover-035-white-hand`，青色小写拉丁词调用 `dalala-cover-035-cyan-latin`；两者均从 `font-style-rules/registry.json` 解析，当前仅测试态。单独生成透明 RGBA 字层，逐字核对，检查独立字体 QA。不可静默换成普通字体。

先完成照片与真实人物/工具，再调局部字后明度，再合成左白字、拉丁词、右竖白字。图中不加额外边框、信息卡、CTA、署名、花边、粗描边或贴纸。脸与字的局部对比不足时优先处理环境明度和文字落点。

## 失败即退回

平视脸、人物面积偏小、手部断裂、右四字变横排、左字变固定字号、文字压脸、摄影背景变纯色、拉丁字变霓虹粗字、假皮肤、产品/职业物件不真实、语义槽位与行业无关、360 px 下标题或两侧结构消失，任一项出现都不得宣称复刻通过。
