# 字形规则

来源是参考 024 的中文大标题。字骨必须是正确现代汉字；整体为实心白色圆厚笔画，线宽约单字宽的 10–19%，但不同笔画有自然粗细差与局部鼓胀。水平笔画可向右伸出，竖画可短收，转角多圆钝，端点不齐但不破碎。字腔保持开放，`理`、`类`、`命`、`稿` 等复杂字在缩略图仍可辨。`地`、`初` 可宽，`是`、`的` 可窄；每字大小和基线依 Cover Skill 的目标盒变化，字自身不能被横向拉伸。

表面为均匀实色，不加颗粒、裂缝、飞白、笔刷毛边或镂空。轮廓有手作起伏，但没有随机噪点和统一外扩描边。重复字若出现仍需逐次独立构形。字体只决定字形与单字动作；整句瀑布式排版由 Cover Skill 决定。色值由具体封面配色方案给出，不固定纯白 HEX。
