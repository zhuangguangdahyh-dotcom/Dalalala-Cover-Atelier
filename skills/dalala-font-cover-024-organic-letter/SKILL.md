# 参考 024 中文大字测试字体

从 `font-style-rules/registry.json` 解析 `dalala-cover-024-organic-letter`，读取本目录 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md` 与 `integration.md`。样式证据是 `../dalala-cover-024/assets/reference-original.jpg`；`approvedReference=null`，不得称原图字体已复刻成功。
