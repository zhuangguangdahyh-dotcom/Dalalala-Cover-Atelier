# 004 字体测试规则

证据为参考 004 原图中的“冒”“险”；未知商业字体名称，不声称识别出具体字体。

标准汉字结构，粗而平滑的实心手写；横画有自然弧度，转折圆钝与局部尖收并存，粗细随笔势变化，内部字腔保持开放。局部字宽比例可变化，不能整体电脑倾斜替代手写动作。建议主笔宽为字符框宽的 6–12%，仅作首测区间；大小由 Cover Skill 的字框约束决定。

无飞白、笔刷纤维、纸张纹理、粉笔碎边、镂空、描边、投影、立体挤出；原图字面平整，不能为强调手作添加脏污。字色由当前封面 primaryText 角色提供，当前模板要求高明度，字体本身不绑定 HEX。

每次按输入准确生成完整字符，包括被人物遮挡的部分。分字透明图层，无背景、无人物、无额外符号；不要从原图凭空补出一张“已批准字体样张”。新字符必须检查部件数量与结构，不复用残缺遮挡剪影。
