# 039 切角厚字（测试态）

读取 `references/style.json`、`references/style-rules.md`、`references/generation-prompt.md`、`references/vitality-qa.md`。唯一正向视觉依据是 `../../assets/reference-original.jpg` 上方主标题，尚无用户批准的独立字体样张。输入标题原文、语义分组和 3:4 画布尺寸；单独输出透明文字层。保持一行、实心极粗黑体骨架、适度局部平切和斜切、轻微逐字宽窄差。前组亮中性、后组高亮，具体色值由封面配色方案决定。检查字形、标点、双色断点和 360 px 阅读后再合成。未通过参考测试不得宣称 active。
