# 021 中英叙事手写字规则

参考字“镜头／越过 Memory”是短中文与英文混写的一次完整手写动作。中文不是小孩油漆字：没有大面积缺墨和喷溅；它的生命力主要来自错落的字宽、长笔、拐角、笔画收势和并不规整的行形。英文不是电脑小字注释：M 与中文同级，后续小写缩到其高度约 35–50%，紧贴 M 右侧，词尾长笔在下方收住。

- 保留标准汉字部件和英文拼写；每个字符单独设计姿态。字宽、字高与倾角在相邻字间变化，但要使读者一眼认字。中文主笔宽度约为字高 5–10%，个别长竖更细。
- 主笔多为实心、清洁、略带手工抖动；起收笔混合平切、轻圆切、突然停笔和自然拖长。允许笔画局部叠接，禁止全字平均做旧或统一毛边。
- 上下两组中文不能排成机械等宽、同一基线的规整两行。每行 1–2 个字承担伸长动作，其余字安静；保持紧凑但不能笔画粘连误读。
- 拉丁词应与汉字在笔压、边缘和倾角上像一只手写成；高首字母、小小写、长下划线是字体身份，不能用常规手写英文字体大小缩放凑。
- 字色由 Cover Skill 的色彩角色输入，原参考为高明度近白。禁止固定原图 HEX、白描边假粗、阴影、霓虹和三维字。
- 该 Font Skill 不决定封面的照片、硬切位置或具体标题坐标；这些由 `dalala-cover-021` 管理。
