# 透明标题层生成输入模板

输入 `exactChinese`（分成上、下两组短语）、`exactLatin`、`canvasWidth`、`canvasHeight`、`textBox`、`fillRole` 与参考 021 原图。只输出与画布同尺寸的真透明 RGBA 字层，不输出人物、墙面、假棋盘格或额外图案。

先逐字校验中文标准字骨与英文大小写、拼写；再按参考的同手写笔势造型：短中文两组不等宽，少量长竖/横挑出字框，笔画连续实心，边缘只有自然手写不齐。拉丁首字母接近汉字高度，其余小写收至首字母高约 35–50%，词尾一笔形成简洁下划线。保持白色或当次指定高明度文字角色。不要用普通黑体、现成手写字体、油漆大飞白、统一颗粒、外描边、阴影、立体挤出。

生成后分别检查每字结构、字距、真假透明、原尺寸和 360 px 可读性。错字、误接笔、英文无义或误拼、词尾线像外加装饰时重做，不自动换字体。
