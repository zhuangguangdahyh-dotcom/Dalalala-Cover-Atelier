# 047 四点空间宋字｜测试态验字门槛

逐字查看透明单字层，再合成到四个固定字区。以下任一项失败即重做该字，不能静默换用普通宋体。

1. 输入的四个汉字逐字准确，部件、笔顺关系和字腔保持标准汉字可辨；无漏笔、连错笔或增字。
2. 粗竖、细横和尖锐端点形成宋骨对比；四字各有 1–2 处有理由的伸出或切口，不把同一形变复制四次。缩至 360 px 宽，细横不断，字腔不糊。
3. 字面实心、干净、边界锋利；无飞白、毛笔纹、霓虹、金属渐变或多重外描边。
4. 四个单字在封面合成后仍是独立空间节点，轻微倾斜和宽窄变化不破坏原字区面积；灰影在右下、硬边、低于白字一层，不误读为额外笔画。
5. 人脸、手部和关键产品不被字或影压住；四字在最终 360 px 缩略图中能按新标题预期语义读通。原参考字位存在顺读歧义，不能把歧义当作可复制特征。

此文件是测试标准，不代表已有批准样张。通过真实内容复刻并经用户确认后才可调整字体状态。
