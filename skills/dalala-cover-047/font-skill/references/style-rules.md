# 字形规则

标准汉字结构是硬门槛。以高对比宋骨为基础，粗竖和薄横要在 360 px 预览仍可辨；撇捺、点与钩可有尖锐、略外伸的终端。每字仅选 1–2 个方向性动作，四字不共用同一模板形变。整体是实心、干净、锋利的编辑字体；不做书法飞白、粗黑体、镂空或毛边。

每字单独输出透明层。四字可有约 ±4° 的视觉倾斜、约 5%–9% 的字宽差，但必须保留可识的字腔。以字高约 4%–7% 的中性灰硬边错位影置于字后偏右下；影比字暗且略薄，不产生模糊发光、厚 3D 挤出或多重描边。色值由封面配色决定，字面始终是局部最高明度之一。

QA：原文逐字正确；四字单独辨认；横笔不断、字腔不闭；灰影不被误认成第二笔；在人物与绿植等杂色背景前仍清晰；360 px 宽预览可读。任一项失败重做该字，不以普通字体兜底。
