# 参考 057 适配规则

## 语义槽位

`真人体验者` 与 `线描指导者` 必须存在交互；`手中证据物` 是指尖与目光的共同目标；`前景场景容器` 说明证据物的用途或后果。先写清四者因果，才选择人物、物件和环境。右侧线描指导者可以是行业角色、历史人物、拟人专家或对应主题的角色，但不能默认通用 AI 小人。不要机械保留“古人”“树”“房屋”。

## 不可变版式

- 3:4；左上两行标题 x1–44%、y6–24%，靠左，首行略小，字区不加框。
- 真人脸 x18–47%、y34–58%；身体进入左下；视线朝右，至少一只手携带小物。
- 右侧白填充线描人物 x55–100%、y7–84%，头大、身体出右框、俯身并指向左下持物。实景与线稿不能均匀分栏。
- 底部线描场景 x14–60%、y69–89%，与实景桌面共享透视，少量真实物与线描相穿插；底部安静区 y89–100%。
- 背景明度为左上浅、中右较暗，线描白最亮，标题和描线最深。允许变色，不改变面积和对比等级。

## 素材处理条件

| 输入情况 | 处理 |
|---|---|
| 真人有完整脸、向右视线、清晰手与持物 | 可用 T1 空间重排，重裁到左下并修复左上文字墙。 |
| 没有持物动作或手部残缺 | 重拍或在身份一致前提下 T2 姿态重构；不得凭装饰箭头代替互动。 |
| 背景左上杂乱、右侧过亮 | 局部修复/扩图，重新建立浅字区与中暗背板；保留实拍质感。 |
| 证据物过大或过小 | 改变景别和手持方式，使其约占画宽 8–15%，并让指尖落向其中心。 |
| 主题没有可落地的下方场景 | 更换主题物/场景方案；无法找到因果关系时不调用本模板。 |

## 文字与字体

两行各 3–5 个汉字，优先 4＋4；第一行交代“谁/什么来源”，第二行给“做什么/会怎样”。超长先改写。字体使用 `dalala-cover-057-fine-angular-han` 测试态依赖，生成透明文字层；保留细线与局部锐角笔势，禁用粗宋体、普通细黑体、阴影、外描边或标签底。无独立副标题槽位。

## 合成与 QA

照片底图 → 真人及真实持物 → 右侧白填充线描指导者 → 底部白填充线描场景 → 穿插的真实物局部 → 标题。允许前景场景盖住真人下半身，不允许盖脸、持物或手指目标。检查原尺寸与 360 px 缩略图；若指向关系或两种媒介反差不清，则返回素材或线稿阶段重做。
