# 参考 057 Cover Skill｜测试前规则

状态 `studied`。本规则已拆解原图，尚未经过跨主题复刻和用户验收，禁止自动生产或上架。先读 `references/manifest.json`、`references/anatomy.json`、`references/adaptation-rules.md` 与原图 `assets/reference-original.jpg`；人审报告见 `references/analysis.md`。

## 调用输入

取得行业、账号身份、主题、平台、标题、实拍主体图、拟被指认的小物，以及可转成线描容器的具体场景。先分析真人脸、手势、身份、持物与背景的事实锚点。没有与主题对应的可见证据物及下方场景时，判为不适配。只支持独立设计的 3:4 竖版，不直接裁为横版。

## 构图合同

1. 在左上 x1–44%、y6–24% 留干净浅色墙面，两行黑色标题，约 4＋4 字，第二行略大。主标题依赖 `dalala-cover-057-fine-angular-han`；不得静默替换系统字体。
2. 真人坐落左下，脸约 x18–47%、y34–58%，上身与手从左下延伸；视线指向右侧。真人持物约 x51–65%、y50–70%，须能被看见。
3. 右侧指导者用白色填充和微颤深色线描，不用实拍抠图，头部约 x62–89%、y7–30%，身体延至右下并出框。人物俯身，其手指指向真人持物。
4. 底部 x14–60%、y69–89% 是白填充的主题场景线描容器，以简洁透视落在实景桌面；局部真实小物或材料穿插其边界。桌面下方保留低信息区。
5. 保持实景照片、线描白块、黑色标题的媒介反差。色值可变，但左上须可读，右侧线描须从中暗背景中跳出。

## 适配与执行

先将行业语义映射为“谁教谁、指向什么、下方承接什么”。先处理实拍底图和空间，必要时重新拍摄/扩图以保住左上字区、真人脸手和主题物；再生成线描人物及前景容器的独立透明层；最后独立生成标题透明层并合成。绘制房屋/容器时保留清晰的正反遮挡与桌面接触关系。执行细则与失败条件见 `references/adaptation-rules.md`。

## 放行门槛

核对标题逐字、字形与两行结构，人物视线、指尖、持物之间的关系，真人身份准确，房屋/场景有落地透视。360 px 缩略图仍应读出标题、两个不同媒介的人物和底部场景。首次测试需使用与原图不同行业且叙事完整的主题。未通过用户确认前 `renderAllowed=false`。
