# 字形规则

参考图左上“ 中国古人 / 教你种树 ”的两行黑字。整体是细线几何骨架中嵌入少量宋骨/手写锐角动作：横竖线细且稳定，撇捺局部楔形加厚，笔画末端有尖锐收势，少量接笔断开或错位。字腔开阔，重心稳；每字动作有差异，但不是装饰性乱切。第二行比第一行更有撇捺张力，字面高约 1.08–1.18 倍。黑色实心，无描边、投影、发光、底框和旧纸纹。

逐字检查标准汉字结构，不可因拉长笔画使“种”“树”等字误识。字距为 0–0.05 个字宽，行间隙约首行字高 20–30%；两行左对齐，整体宽度不超画宽 44%。不能调用普通细黑体、粗宋体或 `dalala-breath-cut-song` 直接代替。
