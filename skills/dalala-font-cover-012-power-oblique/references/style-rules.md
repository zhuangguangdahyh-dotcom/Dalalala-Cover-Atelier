# 012 混合中英数字力量斜体测试规则

证据来自参考 012 顶部主标题、亮色副标题条和七张卡片的编号标签。成图无法证明具体商业字体名称，本依赖只记录可观察的字骨、字面比例、斜度和节奏。

## headline 变体

- 结构：`2–3 位阿拉伯数字 + 2–4 个中文等效字 + 3–7 个拉丁字符`，严格单行。
- 字骨：现代超粗 grotesk/展示无衬线，横竖近等粗，端点平切，转角利落；数字宽大、圆腔饱满，中文略压窄但保持标准部件，拉丁小写厚实紧凑。
- 姿态：数字、中文和拉丁统一前倾 8°–12°，是整组的同向速度，不是逐字随机旋转或高低跳动。
- 比例：数字高度约为中文 1.25–1.45 倍；拉丁词高度约为中文 0.95–1.12 倍。数字承担 42%–48% 的标题视觉重量。
- 字距：整体紧配，约 `-0.06em` 至 `-0.02em`；不同文字系统之间用光学间距连接，不留出像三个独立 Logo 的大缝。
- 表面：实心平涂，可按 Cover Skill 分成两至三种颜色角色；不使用描边、金属、渐变、飞白、颗粒或厚 3D。允许 `0.2%–0.5%` 画布宽的短暗影/短位移，只用于与深底分离。
- 星芒：拉丁短词只允许一个四角星式强调，优先替代字母点；没有带点字母时放在一个升部上方。星芒不改变字符拼写，也不扩散为装饰串。

## banner 变体

- 字骨：直立或最多 2° 前倾的超粗方形无衬线；字面充满率高、字腔清楚、端点平切，比 headline 更稳定。
- 排版：7–10 个中文等效字严格单行，字距约 `-0.02em` 至 `0.02em`；文字层自身保持水平，由 Cover Skill 旋转整个底板与文字组。
- 表面：单色实心深字，无描边、无阴影、无逐字大小变化。亮色圆角底板不属于字体输出。

## card-label 变体

- 结构：阿拉伯数字、句点与 4–7 个中文等效字，严格单行。
- 字骨：粗重、略紧凑的圆方无衬线；比 banner 轻一档但缩略图仍清楚。数字、句点和中文基线统一。
- 排版：字距 `0` 至 `0.03em`；不做斜体、描边或跳字。外围标签重点保证编号和类别轮廓，主卡标签必须完整可读。

## 共通禁区

不得变成爆点节奏字、手写记号笔、圆萌气泡字、机械压扁系统黑体、网页自动 oblique、描边综艺字、霓虹字或立体金属字。任何变体都必须逐字准确、透明背景并在实际字区内完整输出。
