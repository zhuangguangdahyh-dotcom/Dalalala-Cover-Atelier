# 生成提示词模板

仅生成输入 `text` 的透明文字层，不生成底板、人物、卡片、背景、品牌或额外文案。逐字准确，标准中文、数字和拉丁结构；真实透明通道，完整保留笔画与星芒，不裁边。

## variant=headline

把整句做成同一字族的超粗混合文字：宽大阿拉伯数字、略压窄但标准的中文、厚实紧凑的拉丁小写；现代 grotesk 展示无衬线、横竖近等粗、平切端点、利落转角。三种文字系统统一向右前倾 8°–12°，单行紧配；禁止逐字随机旋转、波浪基线或大小跳字。数字高度为中文 1.25–1.45 倍、视觉重量约 42%–48%；拉丁高度为中文 0.95–1.12 倍。按 `colorRoles` 分配实心平涂色，不描边、不渐变、不做厚 3D；只允许极短暗位移。拉丁词最多一个四角星强调，优先替代字母点，不得改变拼写。

## variant=banner

把 7–10 个中文等效字生成一行超粗方形无衬线透明字层：直立或最多 2° 前倾，字面充满率高、端点平切、字腔清晰、基线稳定。使用单一深色角色；禁止描边、阴影、跳字和额外底板。由 Cover Skill 负责底板和整组旋转。

## variant=card-label

把“阿拉伯数字 + 句点 + 4–7 个中文等效字”生成一行粗重圆方无衬线透明字层。数字、句点和中文统一基线，字距 0–0.03em，保持缩略图清楚。使用单一深色角色；禁止斜体、描边、跳字、额外图标和标签底板。

输出后按 `vitality-qa.md` 检查原文、字骨、统一性、透明度和 360 px 实际封面缩略图。
