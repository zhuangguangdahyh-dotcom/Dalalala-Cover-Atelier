# 参考 019｜主题画面与文字适配语法

## 先抽象原图，不搬运原图物件

原图实物：蓝天、山坡、海面、红屋顶、钟楼、海岸线、船。它们形成的可迁移角色是：①上部低纹理亮面承托横向大英文；②右上较暗且相对安静的局部承托中文；③中下部一侧的高密度可识别主题证据；④另一侧连续低细节空间；⑤从主体向画内延伸的真实边界/路线；⑥近中远的体积和尺度差。复制海湾或钟楼不等于复制设计逻辑。

## 每次调用的选图顺序

1. 写出行业、账号、主题、观众需要看见的对象及其身份/事实锚点。先确定英文承担“名称/类别”，中文承担“短译名/关键主题”；两者应真实、相关、能形成两级信息。
2. 在候选图片上标记五区：上方英文区 x10–93%、y6–19%；中文区 x59–90%、y22–35%；主体证据区优先 x0–62%、y40–100%；连续呼吸区优先 x55–100%、y40–85%；从中部流向下方的真实方向线。区域允许自然穿插，不能硬切色块。
3. 优先选已有“上静、主体明确、另一侧可展开、透视/边界有方向”的图。背景内容按当前主题选择：空间项目用营业或施工事实，宠物用动物与具体用品，餐饮用菜品与操作环境，图书内容用书籍与阅读现场。不要为了相似而强制出现天空、水或塔。
4. 检查 3:4 安全裁切。先保住主体，继而留足英文/中文承字面和呼吸区；左/下近景可自然出画。裁切后主体与开放面的视觉重量须与 anatomy 对应。若需要把主体缩得很小才能留字，换片。
5. 局部处理按目的执行：T0 保留原貌；T1 重裁、调光、弱化杂物；T2 在不改变事实的前提下修复或扩出背景。抠图不是默认步骤。真实案例不可凭空拼造建筑、产品或品牌；概念场景不得假称真实案例。新图的光向、焦距、尺度、透视必须一致。
6. 先处理图像，再分别用 `dalala-cover-019-latin` 与 `dalala-cover-019-han` 生出透明字层。英文保持一行高瘦前倾、大面积近白字；中文保持一行方硬厚块、小面积暖亮字。具体色值以图片和品牌重配，只锁明度、色温、面积关系。

## 主题替换例（仅说明角色，不是默认素材）

- 工装：真实门店一侧集中展现经营功能和材料细节，另一侧以通透顾客动线舒展开；可用柜台或地面透视线代替海岸。英文用已核对项目/系列短名，中文用两三字准确主题。
- 宠物：可辨的猫或狗及护理用品占主题证据区，操作台/走廊或柔和背景成为呼吸区，桌沿形成方向线；不能把动物做成无主题关系的通用 AI 小人。
- 餐饮：真实菜品与制作动作形成较密的一侧，另一侧用干净台面或空间纵深；用台面边线带视线，不保留原图海洋题材。
- 文化/读书：书堆、书架、读者动作构成可识别主题，另一侧为较安静墙面或桌面；仍保持上下两级短标题的尺度。

## 何时拒绝套版

长句、多个卖点、单人胸像、孤立产品白底照、全画面均匀高密素材、无法留出双语标题区、缺少准确的拉丁短词或 2–3 字中文时不适配。不能通过添加黑条、贴纸箭头、假水域或重复主体掩盖问题。

## 后续测试门槛

先做接近参考的结构试作，再用**不同主题与不同图像内容**复刻；只有改人名/改色/换几个词不算测试。分别看原尺寸、宽 360 px、单独字层和遮字后的场景骨架；用户确认前不进入生产推荐。
