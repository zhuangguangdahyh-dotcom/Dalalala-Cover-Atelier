# 字骨规则

- 汉字必须先通过标准字形结构检查。厚竖/撇捺与极细横画构成明确粗细对比，宽展近方形，不做普通宋体等比放大。
- 在字的转角、出锋和部分字腔使用少量三角锐楔、方形切口及短平切。每字最多 1–2 处突出的结构动作；保留字腔，不把笔画切断成错字。
- 题眼 2–4 字，字框约高 15% 画布；问题句两行，每行约 5–6 个等效汉字，字框约高 8–9%。字距紧、基线稳，行尾可轻度阶梯，不随意旋转单字。
- 题眼两侧成对书名号用双细斜线；冒号用两枚大圆点。若文案语义不需书名号，可将两侧线视作成对强调线，但不能只留单边装饰。
- 字面为纯浅色实心，红底上的旧印刷颗粒主要留在底图，字层只允许极轻微自然印刷边缘；不加黑描边、投影、浮雕、故障切裂或书法飞白。
- 署名用同一宋骨家族的较细字重，正常横排；不与题眼争主次。重复字逐字校验，标点的位置和方向另查。
