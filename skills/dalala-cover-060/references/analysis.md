# 参考封面 060｜中文视觉拆解（待用户确认）

> 依据：本地注册表指向的原图 `assets/reference-original.jpg`，2880 × 3840，3:4。以下百分比以左上角为 (0,0)、整张画布宽高各为 100% 估算；是复刻约束的初稿，尚未通过换内容测试与用户验收。图中文字可读为「一起来画画」。

## 1. 第一眼结论与画布

第一眼先看到上半张手画的黑色大字，再看到右侧真人与左侧大头玩偶并肩，最后落到下沿的桌面与打开的涂画本。它把“画画”从一句标题变成现场动作：墙面像纸，标题像孩子刚写下；桌上又出现同一玩偶的简笔画。爆点不是信息量，而是**手工字、真人、实体玩偶、纸上玩偶**这四层媒介在一张图里相互呼应。画面约上 52% 是米白墙纸与标题，下 48% 是人物、玩偶和桌面。3:4 竖版，不按长图裁切。

## 2. 内容角色与空间位置

- **主标题**：「一起来画画」，无独立副标题。约 x7–96%、y6–48%。不是五字一条整齐横排，而是前半句散在上中、后半句向左下和右下展开，形成两层不规则台阶。字的黑色视觉面积约 10–15%，宽笔和大空隙同时存在。标题不盖住真人眼睛、玩偶眼睛。
- **左上小插画**：约 x6–34%、y9–29%，黑色带耳造型内有棕色圆脸，带着向右下斜伸的手臂。它是主题预告和实体玩偶的缩小回声，不能替代为无关贴纸。
- **真人**：约 x48–99%、y35–83%，头脸主要落在 x52–82%、y36–69%，胸肩延伸至右边界。真人近景与画面齐平，视线向左上标题/玩偶方向，红上衣提供画面的唯一较强暖色块。右手在 x88–100%、y72–84% 附近接触桌沿。
- **玩偶/主题物**：约 x0–63%、y36–88%，大头占下半部左侧，脸约 x14–53%、y56–78%；身体左、下出血。玩偶体量大于真人面部，眼睛巨大、向右上看，负责亲和力与记忆点。它的头顶与标题下缘轻微交叠，实体对象不能被切成孤立贴图。
- **桌面与打开的画本**：桌面从 y81–82% 横切入，深棕近黑，占底部约 18–19%。画本约 x45–95%、y83–99%，斜放；左页是玩偶形象草图，右页是几条浅灰线。画本被底边裁去，不需显示完整矩形。它是“正在画”的事实证据，不能换成纯装饰白块。
- **辅助信息与装饰**：没有角标、品牌署名、按钮、箭头、正文或价格。唯一装饰是与主题一致的小插画、纸纹和画本上的涂画，信息密度集中于上方标题与下方两张脸。

## 3. 骨架、重心、阅读路径与留白

主轴是从左上小插画，经黑色标题折向右侧真人脸，再折回左下玩偶脸，最后落向右下画本的松散 Z 形。上半部手绘字承担视觉重量，下半部两张脸分担情绪重量，底部横向深桌面把分散元素压住。标题周边需保留约 6–10% 的纸色净边；上沿 y0–7% 和右上 x62–100%、y0–20% 是呼吸区。下半部允许主体出血，但真人眼睛、玩偶眼睛、画本上的对应形象都要可辨。左右不是平均双人照：左侧玩偶大且靠前，右侧真人略靠后，二者头部高低错开。

## 4. 素材处理、景别、透视和图层

参考混合近景实拍、玩偶/实体造型与二维蜡笔字画。真人按胸像近景抠出或换景，保留脸型、肤色、发际线和自然皮肤质感；玩偶保留眼睛、鼻子、耳/帽、黑色外轮廓的识别特征。两者无夸张透视，头部大小差来自景别与前后位置：玩偶更近、更大；真人稍后且右侧。人物与玩偶可各自裁切，但不得只剩半张脸。桌面遮住二者下身，真人右手在桌沿之前，画本浮在桌面之上，纸页略斜并有接触阴影。小插画先于标题或与标题并层；标题在米白底上，局部可被玩偶头顶/相机顶部自然挡住，不能发生整字被遮没。建议图层自后向前：暖白纸质背景 → 小插画/标题 → 真人与玩偶主体 → 桌面遮挡 → 真人手 → 画本与绘画细节。参考图中玩偶头后有相机状黑色圆柱，是现场物件；迁移时可换为主题工具，但要仍与“创作中”有关。

## 5. 字体解剖与专属依赖

主标题是**逐字手画的粗黑蜡笔/油画棒字**，不是标准黑体覆颗粒。笔画约为字高的 6–10%，横竖有轻微粗细与压力差；端点钝、破碎、偶有回笔，边缘有纸纹吃墨和白色跳孔。汉字结构仍可读，但笔画不齐、字心不完全水平，部分部件松开。单字字宽约画布宽 17–28%，字高约画布高 13–22%；字与字间距在不同位置变化约 0–7% 画布宽。上、下两层的视觉行距约 1–5% 画布高，局部字形接近而不粘连。字体黑色基本实心，无描边、无投影、无 3D、无统一倾斜。文字块整体是松散的手绘簇，不是矩形段落。现有松弛铅笔体偏细、粗记号体偏平滑，均无法直接承担这种“粗蜡笔 + 粉质断痕 + 儿童笔顺”的角色，因此建立本模板内测试态 `dalala-cover-060-wax-crayon-hand` 字体 Skill；待字体复刻验收前不得退回普通字体。

## 6. 色彩、材质与光影

米白偏暖背景及同色留白占约 47–55%，黑色标题、玩偶外轮廓与桌面合计约 32–40%，真人皮肤/玩偶棕脸约 9–14%，红衣约 5–9%，其他微小橘红颊色和画本线条约 1–3%。主文字与底必须是高明度反差；桌面是最深的大块，玩偶黑衣把上、下联系起来。具体 HEX 可随行业和素材改变，但“浅暖背景 + 深色手绘字/主体轮廓 + 单处较鲜明衣物点色 + 深色底台 + 浅色画纸”的面积和对比关系要保留。背景有轻微旧纸/墙面颗粒和不均匀斑点；字边可见干性蜡笔擦痕；玩偶面部有材质细纹；真人用柔和正面光，皮肤有自然体积，不能抹成插画或塑料。桌面有粗糙哑光纹理，画本有手绘炭笔/蜡笔痕迹和小幅接触阴影。

## 7. 为什么成立、内容条件与跨行业转译

大字给出邀请，真人提供可信的现实入口，夸张玩偶让主题有可亲近的代表，桌上的画本把邀请变成已开始的行动。四个层次共同证明主题，所以换内容时也要保留**主题物同时以实体与手绘稿两种形态出现**这一机制。适合手作、绘画、教学、亲子体验、产品创作、宠物角色开发、设计过程、餐食研发等能展示“做出来/画出来”的主题。需要一位可看清面部的人、一个可识别的主题对象，以及对象的纸上草图或制作稿。主标题建议 5–7 个汉字、分成两层手排；超长先改写，不放副标题挤占画面。若内容更专业，可把玩偶换成真实产品、动物或工具的放大近景，但其纸上版本要在画本出现，且不能使用无关通用卡通人。

跨行业示例：宠物护理可用真人 + 宠物玩偶/真实宠物 + 桌上护理步骤手绘；餐饮研发可用主厨 + 夸张食材/菜品模型 + 菜谱草图；空间设计可用设计师 + 建筑模型 + 手绘平面草图。内容槽位变了，仍保持左大物、右真人、底部工作台、上方蜡笔标题的占比和 Z 形阅读。若行业不具备“实体对象与手稿互证”的素材，先补拍/制作素材，不能靠贴纸填空。

## 8. 固定项、可变项、失败模式与验收

**固定**：3:4；上半暖浅纸底上的双层不规则黑色粗蜡笔字；左上小绘画与左下实体主题物同源；右侧真人近景；下沿深色桌面与斜放画本；画本中再次出现主题物；左物右人、上字下物的重量关系。主体区、文字区、桌面与画本的面积浮动建议控制在上述范围约 ±3 个百分点。**可变**：人及服装、主题物、工具、标题具体文案、画本内容与配色的具体色值；每项替换后仍回到同一功能区、面积与遮挡关系。**可选**：现场工具或轻微纸张污点；不新增角标、二维码、营销按钮。

失败信号：标题换成普通黑体加噪点；字太密变大字报；小插画与实体对象不相关；玩偶/产品成了漂浮贴图；真人与物件等大等距像合照；画本只剩白纸或与主题无关；桌面过高压住脸；主题色泛滥冲掉浅底黑字对比；用原图内容换词而没有新行业语义。验收时同时看原尺寸与 360 px 缩略图：标题逐字准确、第一眼看得出手绘邀请，真人和主题物双脸/双焦点可辨，画本上的同源形象可辨，整体仍呈“上字—中双主体—下工作台”的结构。当前仅完成视觉拆解，未做真实内容复刻、缩略图成品检查或用户确认，状态保持 `studied`、`renderAllowed: false`。
