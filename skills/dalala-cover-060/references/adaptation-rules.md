# 060 适配与执行规则（待测试）

## 槽位翻译

先填行业、账号身份、主题、现实中的展示对象。`presenter` 是现实入口，`heroObject` 是放大且可识别的主题物，`miniDrawing` 和 `paperDrawing` 分别是它的缩小预告与制作痕迹。四者必须讲同一件事。若没有真人，可以在测试中尝试真实的操作者，但不得未经用户确认就改为纯插画版式。

## 锁定骨架

- 画布 3:4。y0–52% 保持浅色纸底与大字；标题范围 x7–96%、y6–48%，两层松散台阶；上沿保留约 6% 安全区。标题 5–7 个汉字，复杂字要优先控制数量。
- 左上 miniDrawing x6–34%、y9–29%，左下 heroObject x0–63%、y36–88%，两者必须同源。右侧 presenter x48–99%、y35–83%；真人脸与主题物脸/关键识别面分别可见，不能等大并排。
- 深桌面 y81–100%，纸页 x45–95%、y83–99%，右下裁出画幅；纸页上主题草图可辨，不能换成纯白纹理。
- 小画、标题、实物、真人、桌面、画本之间要有实际遮挡、接触或语义呼应。标题最多被对象轻微压边，不遮灭整字；桌面挡住下身但不挡关键表情。

## 素材改造触发

| 条件 | 动作 | 目的 |
| --- | --- | --- |
| 真人照片背景杂乱或文字区不足 | 抠出真人，重建暖浅纸面，保留真实面部与自然光 | 给蜡笔字足够净底 |
| 主题物体积不足或透视不符 | 重拍/扩图成左下近景，允许边缘出血 | 建立左大右小的空间重量 |
| 没有同源画稿 | 按真实主题物结构画简稿，再做成桌上纸页与左上小画 | 形成实体与画稿的互证 |
| 标题超过固定空间 | 改写到 5–7 字；重排单字角度和间距 | 保持两层手绘簇，不扩大字区 |
| 现有素材不能呈现桌面接触 | 补拍或合成接触阴影与前后遮挡 | 避免人物/物件漂浮 |

## 字体与颜色

主标题依赖 `dalala-cover-060-wax-crayon-hand` 测试态字形，笔画粗黑、纸粉跳孔、逐字手写且汉字结构准确。独立透明文字层；字距不平均，字的角度微变，但句子阅读顺序不能乱。色值可变，必须保持浅暖底约半幅、深字和深桌面约三分之一、人物/物件的暖点色小面积。浅色纸页与暗桌面形成末端反差。不要锁定原图红衣或棕桌的具体 HEX。

## 最小真实测试与 QA

至少完成一个与原参考不同且内容逻辑完整的主题，并再用另一组标题长度或另一种主题物试排。用户确认前不标记 active。原尺寸检查：中文逐字正确；人物和主题物的身份锚点没有变形；同源的小画/实体/纸上稿能对照；纸张、人物、桌面的遮挡一致。360 px 检查：先读到大字，随后认出左右两主体和底部画纸；上字中物下桌的骨架仍成立。失败时修正素材或标题，不能靠添加贴纸、按钮和高饱和色补救。
