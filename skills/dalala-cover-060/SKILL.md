# 参考封面 060｜测试态 Cover Skill

状态：`studied`。先读 `references/manifest.json`、`references/anatomy.json`、`references/adaptation-rules.md` 和 `assets/reference-original.jpg`。生成前按行业、账号身份、主题与展示对象填写素材诊断及主题设计；缺少实体对象与其纸上版本时，先补素材。此阶段不得自动推荐、不得发布为 active。

## 固定的视觉机制

3:4 画布；上方浅暖纸面和双层不规则黑色粗蜡笔标题，左上有与左下主题物同源的小手绘；中下部左侧大体量主题物、右侧真人；底部深色桌面横切并放一页可识别的主题手稿。阅读顺序为标题 → 真人/主题物 → 纸上主题物。人物、文字、产品和具体色值可换，但必须遵守 manifest 的面积、位置、明暗和遮挡合同。

## 调用步骤

1. 判断主题是否有真实的创作/制作关系，确认真人、主题物、手稿三种素材。先锁定身份和产品事实锚点，再确定可抠图、可裁切、可重绘的区域。
2. 把主标题改写为 5–7 字，分两层散排。按 `fontDependencies` 调用 `dalala-cover-060-wax-crayon-hand`，单独生成透明文字层并逐字校对；不得用普通字体加噪声替代。
3. 将主题物放左下近景，真人放右侧稍后；用主题物的简化画稿填入桌上斜放的纸页。上方小画也必须源于同一对象。
4. 重建暖浅纸底、低对比颗粒、深色桌面与自然的主体接触/遮挡。具体配色依内容重分配，保留浅底、深字、单处暖点色的面积关系。
5. 输出前按 `references/anatomy.json` 的区域和 `references/adaptation-rules.md` 的 QA 检查原尺寸与 360 px 缩略图。当前必须经真实跨主题复刻和用户确认后才可提升状态。

## 失败处理

标题溢出时改写文案；物件与手稿无关联时重画手稿；主体无足够留白时先重构底图；字体风格不符时重做独立文字层。任一硬门槛失败，不生成可生产模板。
