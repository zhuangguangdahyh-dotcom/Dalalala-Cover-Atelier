# 参考 021｜试作检查

当前无测试成品，本清单仅供拆解确认后的试作使用。

1. 参考来源、3:4 画幅和上下约 46:54 的水平硬切正确；360 px 缩略图仍明显是“上远下近”，不是普通双图拼贴。
2. 上幅远景人物完整、步态可读；下幅同一人物的脸、探身动作、手与真实圆洞边缘接触可读。主体尺度跃迁明显，身份连续。
3. 圆洞有厚度、光向和遮挡关系；不存在平面假圆、错透视、断臂或无接触阴影。
4. 标题跨接缝并主要落在左侧，人物脸完整；两行中文与拉丁大 M、小 emory 的强弱关系仍在。新内容逐字准确，拉丁词有真实语义。
5. 字体独立透明层 alpha 真实；无普通手写字体回退、白字厚描边、投影、发光或均匀做旧。字腔开放，360 px 可读。
6. 上幅暗框与下幅明亮大面形成清楚对照；具体色值随内容调整，白字与其底色分离，肤色自然。
7. 不加副标题、CTA、贴纸、箭头或第三张图。复刻测试与跨行业测试分别记录图片、失败项和用户确认；未确认前不得发布 `active`。
