# Dalala 切块结论体规则

- 骨架：窄长、粗重、低字面留白的现代黑体骨架，整体高度统一但宽度允许明显变化。
- 填充：近白高明度实心块面，不使用描边、阴影、渐变或纸张材质冒充字形设计。
- 端点：以平切为主，在少数横竖交会处加入约 25–45 度的斜切。
- 字腔：保留识字所需的主字腔；每个重点字允许一处矩形、三角形或断桥式负形。
- 节奏：普通字负责稳定，关键词允许加宽 10%–25% 或增加一次异形切口。
- 中英混排：`AI` 与中文同高同重，字母保持几何无衬线结构，不使用独立科技字体。
- 排列：紧密成块，字间距可轻微压缩；禁止逐字旋转、上下跳动或综艺贴纸化。
- 禁区：普通粗黑体、镂空字、圆头可爱体、毛笔飞白、故障字、多重描边。
