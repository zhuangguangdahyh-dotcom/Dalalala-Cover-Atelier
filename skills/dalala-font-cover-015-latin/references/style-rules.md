# 两种英文角色

`skyKicker`：全大写，宽而结实的旧式衬线/板状衬线字骨，顶部占画布约 2–6%、宽约 60–67%W。参考中词组有很浅的弧形和逐词微小倾斜，不是标准水平电脑字。字距约 0.08–0.18 em，局部白色掉墨；后下方可有 1–2% 字高的灰暗错位影，目的是把白字从天空中轻轻提起，不能做立体厚挤出。

`rockLogo`：全大写、厚重而略窄的旧式切割展示字，形成两行几乎无空隙的矩形字块。参考文字主体约宽 34–39%W、高 11%H；右侧单枚符号宽约 7–10%W，同高。字形有不均匀的小缺口和微妙不平直边缘，但总体以白色实心笔画为主。行距约 0–0.08 em；行宽通过选词、字面设计和光学调距匹配，不靠拉伸。符号颜色取当前主强调角色而非固定红色，内容须有真实含义。

两者共用“风吹日晒的旧印刷字”材质，但上方宽松，下面高密度。英文内容必须来自本次真实栏目/品牌/主题，不能把参考游戏文字当模板内容。两组分别出透明层，再按 Cover Skill 合成。
