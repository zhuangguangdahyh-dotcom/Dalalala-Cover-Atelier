# 字形规则

- 粗实心方块字，字形略向不同方向倾斜，横竖厚度有小幅变化。端点以斜切、尖切、轻微手绘错位收住，不做圆头或完全统一的几何直角。
- 汉字各部件必须符合标准结构；「海」「拔」「温」「低」等密集字腔要保住开口，禁止因粗化粘死。问号与中文同样斜切、同一边缘语言。
- 第一行 `questionLead` 用干净高明度实填；下面两行 `icyPayoff` 在同字骨内部加入下半部 20–35% 面积的冷浅色微斑驳。主题换色时保留“上干净／下轻纹理”的差异，不固定原图冰蓝色值。
- 字外薄深边在 1263 px 宽参考上约 1–3 px，短硬影约偏 2–5 px；尺寸变化时等比例调整。必须看得出是实心字，不可形成厚白贴纸边、浮雕、镂空、霓虹光晕或长投影。
- 字距紧，但字腔不堵；同一行可容许少量角度与高度错位，不可复制完全相同字面动作。行块比例和位置由 Cover Skill 控制，本字体只负责字形及局部字面材质。
