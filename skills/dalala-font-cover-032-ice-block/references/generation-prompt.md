# 透明文字层生成合同

输入 `text`（逐字原文）、`role`（`questionLead` 或 `icyPayoff`）、`canvas`、`fillRole`、`outlineRole`。以源图作为字形参考，输出仅含文字的真实 RGBA 透明层。不要生成背景、人像、山峰或雪花。

保留超粗实心、斜切不齐的汉字骨架、压紧但不粘连的字距和自然轻微倾角。`questionLead` 近纯亮实填；`icyPayoff` 上亮、下部有少量浅冷色霜斑。黑/深灰细轮廓和极短硬影克制。逐字照输入写，不添字、不漏字、不替换标点；先核对汉字部件，再核对角色填充与透明边缘。失败则重生或人工复核，不调用普通字体兜底。
