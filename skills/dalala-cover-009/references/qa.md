# 参考 009｜复刻质量门槛

本轮只有原图拆解，以下供后续测试使用；未实测的项目不得标注通过。

1. 3:4 原尺寸：核对每个汉字和标点、真人双眼、主物眼口、至少 3 个不同子物及真实握持；不允许同物克隆、白抠图边或悬浮接触。
2. 位置：左近脸约宽 35%–42%，中上主物约宽 40%–50%，右上短喊与顶部弧字不互撞；底部两行左短右长的阶梯结构清楚。允许估计框内微调，不许更改骨架。
3. 字体：依赖的 Font Skill 必须测试通过。白芯厚圆字仍有自然字高和基线变化，粉边窄而利落，黄色影只向右下硬错位；英文弧字空心且沿拱弧，不与主字混为一种普通圆体。
4. 360 px 缩略图：无需放大即可分辨真人眼神、中央大物、短喊和主标题两行；至少能数出 3 个不同辅助物形。白字在皮肤和浅色玩偶上仍清晰。
5. 跨内容：测试案例必须换完整主题与可见对象，标题语义和全部物件能互相证明；仅换名字/色彩不算。用户确认前维持 studied 与 `renderAllowed=false`。
