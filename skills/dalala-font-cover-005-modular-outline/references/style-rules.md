# 005 模块描边主标题测试规则

证据是参考 005 的《克苏鲁》。未知其商业字体名称，不声称识别到具体字库。

骨架为超粗几何模块字：横竖近等粗，整体宽厚；转角主要为方角，仅做克制小圆；内部字腔是矩形、梯形或窄槽。选择性笔画允许出现机械式断开、短伸出、阶梯或错位，但每字最多 1–3 个结构动作，且不得破坏标准汉字部件和可读性。

标题使用高明度实心填充和暗色描边，描边约为字高 `3%–5%`；不使用飞白、纸纹、渐变、长阴影、发光或金属质感。字符间距紧凑，为字宽 `-3%` 到 `1%`。标题 2–4 个中文等效字，外加左右镜像的双尖括号；括号高度为汉字的 `85%–95%`，与最近汉字的净距约半个主笔宽。

颜色由当前封面的 `primaryText / outlineRole` 提供，不锁 HEX。每次生成完整正确的标题，透明背景，无人物、照片、英文和其他装饰。
