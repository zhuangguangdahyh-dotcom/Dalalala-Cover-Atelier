# 参考 031｜跨内容重建语法

仅供人工确认后的测试规划。原图见 `../assets/reference-original.jpg`，量化边界见 `anatomy.json`；任何真实制作先依项目设计流程形成完整 `coverPlan`，且本模板当前 `renderAllowed=false`。

## 调用前判断

明确行业、账号身份、主题误区/纠偏、实际能展示的人物、工作或生活场景、能够证实主题的卡片内容。必须能说清“顶部为什么叫停某件事、人物为什么困惑、下方几种用法如何回应”。缺少真人、真实场景或有依据的内容卡片时不适用。卡片内容若涉及他人品牌、病例、案件或客户资料，只展示有权使用、必要时脱敏的事实素材。

## 锁定空间语法

1. 画幅 3:4。真实室内工作桌铺满画面，右侧大近景真人 x35–100/y25–100，脸 x56–91/y34–59；右侧和底边自然越框。左半幅保留桌面、屏幕与生活化辅助物，不做纯色空场。
2. 顶部 x3–98/y4–18 放 **一行**近满宽黄亮字/深色硬影主标题；将一个主题关键词做 1.2–1.45 倍高度的突出字形，但保持逐字准确。标题压住部分远层卡片，不压脸。
3. 4–8 张有不同内容和尺寸的卡片在 x7–99/y1–55 散布，围绕人物头部。单张宽约 10–25% 画宽，旋转约 ±5–14°，深浅、景别、透视和阴影有变化。保持眼睛、嘴和主标题字腔净区；不重复复制同一张，不排网格。
4. 左下 x5–48/y60–68 放人群/数量提示，x5–48/y69–76 放白底结果条。上行突出一个数字或短词，下行用黄填黑描边交付具体类别。两级文字要在真实桌面上可读，不能变小到成为说明文字。
5. 视觉路径“顶部冲突 → 右侧人物 → 工具卡 → 左下可用答案”。色彩随主题更换具体值，但始终保留主字高纯度/高亮度、深硬影、较低饱和真实场景、白底结果条的对比结构。

## 素材诊断与改造级别

- **T0 事实与身份锁定**：脸、五官、人物经确认的身份特征、真实工具外形和 UI 事实不得损坏。原图未授权的人物或品牌不能被当作通用素材直接搬进新主题。
- **T1 空间重排**：已有右侧近景真人及左侧工作桌时，调整裁切、局部背景明暗，分层安排卡片与字。保留手势及桌面透视，不是只移动主标题。
- **T2 结构改造**：照片具人物身份但缺少足够左侧桌面或扶头/思考动作时，扩图或重构景别、姿态；卡片来自该主题真实界面/照片，给每张设置透视、阴影和前后关系。逐项检查手指、眼镜、UI 字和产品结构。
- **T3 主题重建**：人物、场景或卡片基本不匹配时，重新拍摄/生成同一身份与行业的真实情境。不能把静物、纯肖像和随机 logo 强拼为参考构图。身份无法可靠保持时停止测试。

## 内容槽位转换示例

- AI/效率：真人是创作者/使用者；卡片展示真实工具界面与生活任务，底部交付可验证的使用场景。
- 设计/装修：设计师位于工作桌，卡片是方案、材料、平面或实景的不同证据；顶部纠偏只针对明确的设计误区，避免空泛反常识句。
- 医生/律师等专家：人物与工作环境必须真实；卡片使用经许可或脱敏后的流程、图示、文本或器具，不能伪造病例、判例、承诺疗效/结果。
- 餐饮/产品：主理人及实际台面/制作场景成立时，卡片可为原料、步骤、成品或真实用户场景。没有人时换模板，不用通用 AI 小人顶替。

## 文案和字体

顶部推荐短命令或短判断，约 5–7 个汉字当量，可包含 1 个 1–3 字母强调词；下方第一行约 5–7 个汉字当量和一个数字，结果条 4–6 个汉字。三块均锁单行，过长先改写，不扩字区和增加行数。字体四角色从 `dalala-cover-031-punch-display` 测试态依赖读取，`approvedReference=null`；先单独生成透明文字层，核字和 QA 后合成。

## 失败边界与下一关

一旦人物脸部净区、右侧近景面积、顶部字的宽度、卡片前后关系或左下两级结果被破坏，即使色彩和词语相似也判不属于 031。正式复刻需先接近参考，再以不同主题做跨行业测试；360 px 与原尺寸都通过 `qa.md` 并获用户确认，才可考虑后续上架。
