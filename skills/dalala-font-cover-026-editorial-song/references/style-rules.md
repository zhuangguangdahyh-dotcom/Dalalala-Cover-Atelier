# 中文字形规则

- 参考的主标题「打开书本里的世界」是八字一行，近紧排、重心端正、字面宽展。高对比的竖画与细横画明显，撇捺及转角是书卷式尖锋，不是圆头、刷痕或任意缺笔。不能把普通系统宋体整体加粗或横向拉宽冒充。
- 四个角色共享字骨但不共享字号和强度：主标题最强，地点中文其次，章节题再小，正文以可读为先。主标题目标高约画高 7–9%、宽约画宽 82–86%；章节题字高约为主标题的 25–35%，正文约为章节题的 45–60%。这些目标盒由 Cover Skill 决定。
- 标题字距约单字宽 0–4%；不逐字旋转、挤撞或上下跳动。章节说明行距约字高 1.15–1.3 倍；若字稿过长，先改写，不压窄字形。白字可留极轻短灰影供合成层使用，字形本身保持实色清洁。
- 每字准确、常用部件位置正确；小字号不能糊成伪汉字。若图像生成无法稳定保字，应进入人工排字和逐字复核，不得默默改用另一个字体风格。
