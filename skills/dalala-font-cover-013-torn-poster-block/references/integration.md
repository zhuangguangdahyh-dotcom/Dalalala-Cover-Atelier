# 封面调用接口

从 `font-style-rules/registry.json` 解析 `dalala-cover-013-torn-poster-block`，加载机器配置和提示词。输入原文、画布尺寸、`mainTitle` 字区及强调/深墨颜色角色；生成每字透明层并逐字校对。Cover Skill 负责将字逐个压在独立撕纸片上，设置不等形纸边、约 ±4° 的纸片旋转、上下微错和短接触影。字形本身只允许约 ±2° 的微调。

若结果错字、破损过度、字面过小或透明度不真，最多重做 3 次后进入人工复核。不得用浏览器系统字体、现有其他字体风格或整块标题图片替代；不能把测试态字体作为可生产的已批准风格推荐。
