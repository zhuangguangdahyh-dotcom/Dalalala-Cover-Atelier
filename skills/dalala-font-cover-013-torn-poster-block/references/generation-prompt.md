# 透明标题层生成模板

输入：`{text}`，目标画布 `{canvasWidth}×{canvasHeight}`，标题区域 `{textBox}`，颜色角色 `{colorRoles}`。以参考 013 原图中的中文标题字骨为唯一视觉证据。

为标题的每一个汉字分别绘制一层真实透明背景的印刷字形。原文逐字准确，字序一致，单行。字骨为宽厚、平切、重心稳的现代方形黑体，黑度高但字腔完整。每个字带独立而少量的丝网印刷漏墨、边缘侵蚀和粗颗粒，不用同一噪声贴图复制。连续前 1–2 字采用强调色角色，其余为深墨色角色。字形占对应纸片目标空间的 68–84%，最终由 Cover Skill 放入独立撕纸片；此处不画纸片、报纸、人物、道路、背景、投影、描边、装饰或额外文字。输出单字透明层及可复核的整行预览。中文结构、偏旁和笔画必须准确。
