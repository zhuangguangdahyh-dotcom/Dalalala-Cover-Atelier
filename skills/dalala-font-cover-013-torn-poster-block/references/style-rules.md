# 字骨与印刷动作

源参考是六个中文大字，每字黑体骨架厚、重、稳，端点平切，横竖笔画饱满，封闭字腔仍能辨认；前两字为暖色印墨、后四字为近黑印墨。标题视觉不来自某个被确认的商业字体，而来自字骨、逐字实例、局部印刷破损与纸片装配的共同作用。

每字独立生成，字面占它所属纸片宽高约 68–84%；整体保持可读的水平节奏，不将字骨夸张扭曲。笔画里可有粗颗粒、边缘缺墨和少量不规则侵蚀；破损不得打断核心识字结构。六字不能重复同一纹理蒙版。强调段为相邻 1–2 字，颜色由封面色彩角色给出，不锁参考红色数值。

字体层只含墨字与真实透明背景，纸片、纤维边、短阴影、错位和互压由封面合成规则处理。不得把整条纸板、阴影或假透明棋盘格生成在字体层内。
