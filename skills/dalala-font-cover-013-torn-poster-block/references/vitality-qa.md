# 字体测试硬门槛

任何一项失败即退回重做或人工复核，不能换用普通字体兜底。

1. 与输入文字逐字一致；没有缺字、错字、额外字或被纹理遮断的关键笔画。
2. 单行可连续阅读；每字对应独立透明层，字形可准确对齐自己的纸片。
3. 在 360 px 封面缩略图中可辨认标题，粗笔画和字腔仍有清晰明暗边界。
4. 厚重方形字骨、平切端点和受控局部漏墨均成立；不能退化成普通粗黑体、毛笔字、圆泡泡字或故障字。
5. 六字磨损不机械重复；强调段集中，不散成每字一个颜色。
6. 输出有真实 alpha；无纸片、背景、假棋盘格、长投影或额外文案。

字体仍为测试态，用户未确认前不填写 `approvedReference`，也不改 `productionApproved`。
