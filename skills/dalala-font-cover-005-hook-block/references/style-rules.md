# 005 顶部钩子字测试规则

证据是参考 005 顶部中文句。未知其商业字体名称，不声称识别到具体字库。

骨架为宽体、粗重、方正的展示黑体：横竖接近等粗，字面充满率高，端点以平切为主，在少量转角和收笔加入短切口或小阶梯。字的重心稳定、字腔仍须清晰；不得整体圆化，也不得通过任意拉宽普通黑体冒充。

表面为高明度实心填充，外缘加细暗边；再向同一方向做画布宽 `0.25%–0.45%` 的浅灰/暗灰短位移，呈轻微凸起。位移必须贴近字身，不形成长投影、3D 挤出或多层彩边。字间距约单字宽 `2%–5%`，9–13 个中文等效字保持单行。

颜色由当前封面的 `primaryText / outlineRole / shadowRole` 提供，不绑定具体 HEX。每次生成完整、准确、可辨的汉字，透明背景，无人物、照片、引号或额外文案。
