## 1. 画布与第一眼

第一眼先看到上半部宽阔的浅暖矩形光框和框内独立家居组合，接着被下半部拱形暖光中的双行细衬线标题带走，最后读到底部压轴的超大品牌并列字。它像一张布料品牌的空间主题发布海报：用真实场景建立“可感知的生活”，用舞台光和文字建立发布感。真正的识别点不是某件家具，而是**深棕织物底、发光矩形橱窗、下方半圆舞台光、轻重两级衬线字**的纵向连续关系。

## 3. 视觉重心、主轴、阅读路径

主轴在 x50 附近：页眉中轴 → 上部橱窗家居 → 下部光弧与主题 → 页脚。页眉左、右两角做水平压重，橱窗的右侧高柜与左侧沙发、植物做内部错位平衡。视觉重量约为：上部橱窗 45–50%，下部主题光区 25–30%，底部大署名 15–20%，页眉其余 5–10%。深底占绝大多数可见区域；橱窗内左右留暗空，使家具的外轮廓清楚。橱窗与光弧之间 y53–60 有约 7% 画高的暗色呼吸带；副题与页脚间 y85–91 有约 6% 暗带。这两段不可被文字填平。

阅读顺序不是传统顶部大标题：先“亮框里的场景”，再“半圆暖光上的主题”，然后“解释主题的副题”，最后“底部合作品牌”；页眉只在需要确认出处时回读。缩成 360 px 宽时必须仍一眼看到：横向发光橱窗、中心家居组、下方光弧、两行主题和底部重字。

## 4. 素材处理、景别与图层

家具是一组视角一致的中远景布景，不是室内照片铺满整框。沙发约占内窗宽度 35–40%，三件前景家具与地毯横向展开；蓝色竖柜/门占高约 23% 画布，开放架约 21%，在沙发后形成竖向支撑。植物从沙发左后露出，边几、书和织物压在前景；圆毯锚住落地感。原参考很可能是渲染或合成布景，不能据此断言具体生产软件。

替换素材时先判断：是否有一组可识别的主产品/空间角色，是否能组成同一透视和同一地面。若已有完整干净布景，重裁到橱窗；若产品分散，精细抠图并按“后景高物 → 中景主产品 → 前景小物 → 接地面/软影”重组；若缺地面关系，先补足接触阴影与地毯/平台，不要让物件漂浮。边框位于布景之前但不穿过家具，外框不能被物件遮掉。原图无重复克隆主商品、无夸张透视变形、无人的前景遮挡，不能凭空加人抢焦点。

建议图层自后向前：深棕低对比织物底 → 下部投射暖光和斜向软影 → 橱窗内景暗底 → 高立柜/架与植物 → 沙发/主产品 → 地毯、边几和小物及接触影 → 矩形发光边框 → 所有文字和自有标记。若原始素材的身份/产品几何必须保真，抠图只改变展示方式，不重画关键轮廓。

## 5. 字体与文字块

主标题是极高粗细对比的现代罗马/Didone 方向：直立，细发丝横画和衬线，较粗竖干，优雅而不书法化。大小写混排；`Home Beyond` 字面约占画宽 46%，第二行 `Home` 居中收窄到约 20%。字距按具体字形做光学校正，字距起点为字高的 0–2%，避免机械等距；两行基线间距约 0.82–0.92 倍单行字高，形成紧凑的纵向主题块。副题同一罗马语系的小号常规衬线，`To` 可呈意大利斜体对比；副题行距约 1.05–1.15 倍字高。两侧中文为轻细宋骨或衬线语气，字距略松，不能比中央副题更亮或更大。

页脚字是另一重量级：同为高对比罗马衬线，但大写、粗竖画、极细横线和尖细衬线，字面近乎铺满 88% 画宽，紧凑排列；连接符 `&` 较细、较曲线化，成为节奏间隙。页眉左与中部使用较小的典雅罗马衬线，右侧双行则是简洁无衬线粗字。所有文字为浅暖色实心，不使用立体、厚描边、发光、磨损字或随意花字。最容易误复刻的点是把主标题和页脚都用同一粗细、把页脚做成普通粗黑体，或把主题文字改成中文大字报。

现有字体条目虽有高对比罗马衬线，但没有同时约束本图的细线主题字、超重页脚字与二者的协调关系；因此建立本模板专属**测试态**字体依赖。字体 Skill 保留字骨规则，Cover Skill 只声明各角色和所在框位。中文主题如必须替换，应先测试等价宋体的两行视觉重量；无验证时不宣称跨文字系统已复刻成功。

## 6. 色彩、材质与光影

不锁原图色号。角色关系应保持：暗暖底/内景约 65–75% 可见面积；浅暖矩形灯带约 5–8%；家居/产品组约 13–20%，其中允许一处中低饱和冷色竖向锚点；下方暖光约 15–22% 视觉区域但与暗底叠加；亮文字可见笔画约 5–9%。这些类别互相覆盖，不能直接相加。明度从高到低大致为灯带与浅色标题/页脚 → 暖光受照区 → 主产品亮面 → 织物底。浅暖与深暖对比是骨架，冷色只在产品上作约 3–7% 的辅助配重。换配色时可以改成深蓝/灰褐等，但必须保留“暗大底、暖或中性亮框、亮字、局部受光”的面积和对比关系。

深棕底有细密横向编织或墙布纹，不能用平滑纯色替代，也不能用粗噪点变成脏纸。矩形框更像均匀发亮的实体灯带：边缘清晰，内部有微柔光，不是两条细描边叠放。下方光区像一道有方向的舞台投光：上缘是大弧，右侧有斜向暗影穿过，光强向边缘衰减；不能用生硬扁平半圆贴纸。家居组维持真实材质、合理接地阴影和前后遮挡；纹理不能盖住文字笔画。

## 7. 为什么成立与使用条件

上方橱窗给出具体的“是什么”，下方主题给出“为什么值得感受”，页脚合作品牌说明发布主体，三层信息相互支撑。光框把相对小的家具组从深底中分离，留下大片暗空，既显得像陈列，也能在缩略图中读出品类。拱形光把一大片文字放在可读的光场内，同时保留与上框的节奏差异。页脚重字压住整体，不让上半部漂浮。

适合有实物或完整场景可展示的品牌发布、空间概念、联名展陈、设计作品或体验主题；尤其适合“一个主场景 + 一句短主题 + 一个解释句 + 合作/账号署名”。主标题英文建议 2 行：首行约 11–17 个含空格字符，次行约 4–8 个；实际以 x27–73 的第一行框和 x40–61 的第二行框是否成立为准。中文暂建议每行 3–6 字且需重新做字形测试，不可直接把长中文塞进原英文框。副题最多 2 行、每行约 25–36 个英文字符或更短的等价中文；超过先改写。需要多项价格、参数、步骤或长论证的内容不适合此模板。

## 8. 跨行业适配与变量合同

- 家居：主沙发/单品 + 后景柜架 + 两三件真实关联软装，主题讲生活方式；不能照搬原产品和品牌名。
- 餐饮：中心菜品或餐桌为主，后景器物/空间为辅，必须真实属于同一餐饮概念；灯框保留但画面内构成应像一组陈列，不变成店铺全景。
- 美妆/时尚：主产品或穿搭陈列占中部 35–40% 内窗宽，后景高物可换为镜、陈列架或模特身形；若使用人物，仍须保留产品/场景的层次，不能转成近脸肖像。
- 商业空间：以一个可辨识的空间剖面或装置组合代替家具组，保留暗橱窗与中部接地，不把整张室内摄影简单嵌入矩形框。
- 科技/工具：展示一个真实产品或工作场景，后景竖向信息实体与前景配件有因果关系；禁止默认通用彩色 AI 小人。

可变：人物/产品身份、具体场景、文字语义、品牌自有标记、具体色值。固定：3:4 纵向三段、页眉三点配重、上方宽浅亮框及框内小于窗口的中部布景、7% 左右暗分隔带、下方弧形投光、中心两行细衬线主题、底部一行超重衬线署名、原有面积与阅读路径。若账号没有两个真实合作品牌，页脚可填一个经设计的自有机构/系列署名，但仍须维持超宽大写的视觉重量；绝不伪造合作。

## 9. 失败模式与逐项验收

1. 亮框细成普通线框、位置移到全画面边缘，或框内场景铺满不留暗空。
2. 家具/商品透视各不相同、悬空，或橱窗内只有单件产品而失去完整场景关系。
3. 暖光被画成硬边圆贴纸，或与背景纹理完全脱节。
4. 主题和页脚字重相同、衬线字被普通宋体/黑体静默替换；英文拼写、中文结构或品牌名称有误。
5. 页眉、主题、副题、页脚全部抢同一级焦点；暗分隔带被文字塞满。
6. 机械复制原图品牌、年份、地点或产品；跨行业仍沿用家居叙事。
7. 360 px 宽缩略图里看不出“橱窗 → 光区主题 → 底部署名”，主标题无法辨识。
8. 未经跨内容测试和用户验收即标为 `active`。

本阶段验收：用户可逐项核对上述空间骨架、字形判断、光区和跨行业边界；确认后才进入真实内容复刻。当前 `renderAllowed=false`。
