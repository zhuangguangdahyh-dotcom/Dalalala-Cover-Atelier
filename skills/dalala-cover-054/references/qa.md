# 054 逐项检查

1. 原图相对骨架：3:4，三点页眉、上部完整厚亮框、中部小于内窗的场景、两处暗呼吸带、下方柔边弧光、底部超宽署名均存在。
2. 场景：主对象、后景竖物、前景小物属于同一主题；视角、光线、落地与接触影合理；事实／身份锚点没有被改造坏。
3. 字：文字逐字准确；主题细高对比罗马衬线、页脚超重高对比衬线彼此有重量差；副题与中文旁注不抢主焦点；没有静默普通字体替换。
4. 材质：底纹细密低对比，灯框有均匀亮度与厚度，弧光有柔边、方向暗影与底纹穿透；无廉价霓虹边或硬贴片。
5. 360 px：先认出橱窗和主体，再认出弧光内主题，最后认出底部署名；标题可读，辅助字允许次级但不能乱码。
6. 流程：先用户确认拆解，再做原参考之外的完整主题复刻；通过跨内容测试和用户验收前保持 `studied`、`renderAllowed=false`。
