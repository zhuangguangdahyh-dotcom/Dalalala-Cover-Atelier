# 054 适配规则｜拆解待确认

## 固定空间语法

3:4 画布以中心 x≈50% 为主轴。页眉 y≈3–9% 三点分布；浅亮框外缘 x≈5.5–94.5%、y≈14–53%，边宽约画宽 2.3–2.8%，内景不填满橱窗。主体组落在 x≈26–72%、y≈18–50%，底部与地毯／平台接地；两侧保留约各 18–25% 画宽的低细节暗区。y≈53–60% 保留暗带。下方弧光约 x≈8–94%、y≈60–82%，主题 x≈27–73%、y≈65–77%，中部两行解释句 x≈31–70%、y≈80–85%；y≈85–91% 再留暗带，底部署名 x≈6–94%、y≈91–97%。上述为原图目测外接框，制作容差先取 ±2–3 个百分点，再以缩略图比较收紧。

上部亮框及内部场景是第一焦点，弧光里的细衬线主题是第二焦点，底部重衬线署名收束画面。页眉只提供来源和活动信息。无真实双品牌合作时，页脚用真实自有品牌／系列署名，保留一行超宽、超重视觉角色；不伪造合作。缺少真实地点／年份则写适当且真实的元信息，不能复制原图。

## 内容槽位与素材改造

- 先选一个可陈列的主对象，再选一个竖向后景锚点和 1–3 个真实相关的辅助物；它们须共同解释同一个主题。人物若出现，只能作为这个场景的组成部分，不能用大头近景取代整个橱窗布景。
- T0：现成完整布景且透视、地面和光线一致，只做裁切、对比调整与框内留白。
- T1：主物比例不合时重裁或扩景，维持约 35–40% 内窗宽的主物量级；标题过长先改写。亮框仍完整、等厚。
- T2：分散单品需精细抠图，按“暗底 → 竖向后景／植物 → 中景主物 → 地毯／平台与前景小物 → 接触影 → 发光边框”组装。统一镜头高度、透视和阴影方向，禁止悬浮商品。
- T3：关键实物、品牌、活动事实或场景关系缺失时补充可信素材与信息，不生成虚假联名或产品结构。

## 文字与颜色

拉丁主标题两行，第一行约 11–17 个含空格字符，第二行约 4–8 个，最终以固定框位和字面密度为准；两行紧密居中。副题最多两行，不能压过主标题。底部大写署名约铺满 88% 画宽；字数太多须用真实简称或调整文案，不能把底部字缩成普通说明。中文主题每行约 3–6 字只作为待验证假设，需要单独字体测试。

颜色具体值可变，明度秩序不可变：暗而有细纹理的大底／内窗约 65–75% 可见画面，浅亮灯框约 5–8%，实体场景约 13–20%，投光覆盖约 15–22% 且与底色叠加。受光和场景估计有重叠，不能作为面积求和。小面积冷色／品牌色可作为竖向锚点，不让颜色跳出第一焦点。弧光是柔边投影、带方向性斜暗影与织物纹理透出，不能画成硬边圆贴片；灯框是有厚度的浅亮实体，不是单线描边。

## 适用与停用

适合家居、空间设计、餐饮陈列、美妆产品组合、展陈或科技设备的概念发布，前提是“一个具体场景／对象 + 一句短主题 + 一个解释句 + 真实署名”。跨行业时替换为行业可识别的物件及关系，不套用原图沙发、品牌和口号。若内容必须呈现价格、步骤、长参数、多人群像或无接地场景，停止选用本模板。

失败判据：亮框变细线或被主物遮断；内窗被照片铺满；物件透视／阴影不一致；光弧成为硬贴纸；两级衬线重量消失；主题过长侵占暗带；页脚变普通小字；页眉和页脚复制原品牌；360 px 缩略图读不出“橱窗 → 弧光主题 → 底部署名”。
