# 参考字骨与角色

共同字骨为直立的高对比现代罗马衬线：细发丝横画、较粗竖干、锐利而克制的衬线，字内空间通透。浅暖实色，无厚描边、立体挤出、磨损或发光。逐字校正字距，以视觉均衡优先于机械等距。

- `mainTitle`：标题大小写混排，极细到中等重量，x≈27–73%、y≈65–77% 的两行中心块；第一行宽、第二行明显收窄，基线距离约 0.82–0.92 倍单行字高。高对比但笔画在 360 px 缩略图不能断裂。
- `supportingSerif`：两行解释句和两侧短语的常规细衬线；主句居中，大小约主题字高的 28–38%；个别词可用同家族意大利斜体强调，不可整段手写化。中文旁注需另行验证中文宋骨，不能由本拉丁风格直接生成。
- `footerDisplay`：全大写，竖画明显更粗，尖细衬线和发丝横画保留；一行横向铺展约 88% 画宽，x≈6–94%、y≈91–97%。连接符略细，形成两组署名之间的停顿。不可把它做成普通加粗无衬线。

上中页眉小衬线可依 `supportingSerif` 缩放；右侧双行标记是独立清洁无衬线排版，由 Cover Skill 控制，不能误用本衬线风格。
