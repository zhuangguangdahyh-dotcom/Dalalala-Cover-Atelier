# 参考 054｜调用规则

1. 先看 `assets/reference-original.jpg`，再读 `analysis.md`、`references/anatomy.json`、`references/adaptation-rules.md` 和 `references/manifest.json`。这张参考独立建档，不按编号推断其他构图。
2. 输入行业、账号身份、主题、展示对象、实际品牌／活动资料和可用素材。判断能否组成一个有地面关系的中央场景，以及是否有足够短的主题句和真实署名。没有这些条件时暂停套版。
3. 锁定 3:4 纵向骨架：三点页眉 → 宽浅亮矩形橱窗与其中的中部场景 → 暗呼吸带 → 拱形投光中的两行主题与解释句 → 暗呼吸带 → 底部超宽署名。参照 anatomy 的百分比约束制作，不能把照片铺满橱窗或移动标题来假装复刻。
4. 先诊断素材的身份／事实锚点，再决定裁切、抠图、扩景、重组、接地阴影。产品、空间及人物身份保持真实；陈列对象须互相关联且透视一致。边框压在布景之前，但不切穿主产品。
5. 字体角色读取 manifest 的 `fontDependencies` 和本模板 `font-skills/editorial-didone/` 的测试态规则。主标题、解释句与底部署名分别输出准确透明字层；中文替换只能在独立字形测试通过后使用，不能拿拉丁规则直接替代。小型页眉右侧使用清洁无衬线配重。
6. 具体配色随主题调整，始终保留暗纹理大底、最亮的灯框与文字、局部暖／中性投光，以及场景里克制的辅助色。360 px 缩略图核对橱窗、光弧、主题和底部署名的连续阅读。
7. 当前 `renderAllowed=false`，拆解仍待用户逐项确认。确认后用与原图不同、内容逻辑完整的主题做真实复刻与跨内容测试；测试和用户验收前不得标记 `active`，也不得编写前台名称与推荐说明。
