# 053 待测试检查

- [ ] 原图副本与注册表源图哈希相同，原图画幅已记录。
- [ ] 2×3 网格、主景斜纸片、左中宽纸片、右侧人物四层在 360 px 宽可辨。
- [ ] 主景对象连续且形体真实；人物脸、发丝、手部及身份没有被抹改或遮断。
- [ ] 撕纸白内圈、纤维外圈与轻微短影有层次，人物和主景片接触处仍能分开。
- [ ] 六格均与同一事件相关，景别有变化，光线／透视无明显拼贴错误。
- [ ] 地点词一行，逐字准确，使用已声明字体依赖；缩略图可读。
- [ ] 色值可换，但照片大底、亮纸亮字、右下深重的明度关系不变。
- [ ] 非原参考主题完成真实复刻，用户逐项确认后方可改变 studied 状态。
