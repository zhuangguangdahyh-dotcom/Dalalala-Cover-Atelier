# 单行透明文字层生成合同

输入必须包含准确中文 `text`、`role=hook|main`、3:4 画布尺寸、目标文字外接框和本次配色角色。按参考 007 的极粗宽身不规则方块展示字逐字绘制：保持标准可读汉字结构，局部短斜切与轻微独立姿态，紧凑光学字距；实心填充，炭灰厚外边，外侧非常短的灰色柔晕。`hook` 用近亮中性色角色，`main` 用单一高亮强调色角色。只输出这一行的 RGBA 真透明字层，无背景、无蓝色螺旋、无箭头、无人像、无多余文字。不得改写输入文字，不得换行。

检查中文每字、偏旁和笔画；如果有错字或规则黑体感过强，重新生成该文字层。最终位置与行级比例由 Cover Skill 合成，字体生成不得擅自改变外接框。
