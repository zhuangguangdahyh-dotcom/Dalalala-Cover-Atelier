# dalala-cover-048（studied）

本 Skill 以 `assets/reference-original.jpg` 为唯一参考原图。先读 `references/anatomy.json`、`references/adaptation-rules.md`、`references/manifest.json` 和本次任务 `analysis.md`。当前未通过测试和人工验收，不得作为 active 模板自动生产或推荐。

## 调用顺序

1. 判断行业、账号身份、主题和各图是否属于同一真实过程。至少有大表情近景、行动、地点/成果三个节点；缺一则补素材。
2. 在 3:4 画幅锁定非均分拼贴：左上行动、左下另一时刻、上中环境、右上小场景、右侧最大的人物近景。按 anatomy 中的范围裁切和叠压。
3. 诊断身份与事实锚点；保留脸、真实动作、道具接触、场景证据。按 T1/T2 处理照片和抠图，不伪造经历。
4. 把主题改写成一行短类型词。用 `dalala-cover-048-vlog-outline` 测试态依赖制作透明标题层，保持白实字黑厚硬边，放在左侧上下换景线；检查逐字准确。
5. 在大主角外周放 8–16 段疏密不均的白短线；小图标仅在有行业语义时贴于标题上缘。检查脸、食物及次要场景不被遮。
6. 原尺寸和 360 px 缩略图核对层级、图像真实性、标题可读与构图辨识度。完成跨行业测试和用户确认后再申请状态变更；本 Skill 不直接改共享注册表。

## 变量合同

人物、文字、产品/道具和具体色值可换，但分别保留右侧大近景与左侧小场景的景别差、单行短标题的边界、多节点真实事件关系，以及冷/低饱和背景、暖主体落点、黑白高对比标题的角色和面积。排版、相对占比与白线放射效果是固定结构。标题过长先改写，不改变结构。
