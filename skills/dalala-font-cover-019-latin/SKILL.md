# 019 拉丁主字｜测试态调用

先看 `../dalala-cover-019/assets/reference-original.jpg` 的 `MONTENEGRO` 字层，再读本目录 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md` 和 `integration.md`。输入准确拉丁短词、画布和预定字框。独立生成真正透明的单行字层，逐字检查拼写、字骨、切口与阴影，再供 Cover Skill 合成。字体只决定字形与字效，不决定背景是山海或其他行业场景。状态 `testing`，无批准样张，不得当成正式生产字体。
