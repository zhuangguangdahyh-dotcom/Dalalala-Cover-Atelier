# 019 拉丁主字｜字骨与字效

原图 `MONTENEGRO`：十个大写字母占约 x10–93%、y6–19%，形成一条极宽、极粗的水平标题带。每个字母字骨本身右倾，竖画厚、字身偏高瘦，内白狭长但不能堵死。顶部和脚部带斜切/楔形收口；部分左边缘有短促的阶梯状切口，必须局部出现、位置与结构有关，不能每字复制同一个缺角贴图。字母形体有运动感，整行基线仍稳定水平，不整块旋转。

按真实字形逐对调整间距，整体紧排但不粘；`M/O/N`、`E/N/E` 与 `G/R/O` 的疏密要用视觉面积均衡，而非机械等字距。标题长度变化时先选准确短词，不能用普通体横向强压、拉长或分行凑框。笔画实心、边缘干净；主填充为高明度中性。原图有轻微向下/侧的灰暗分离，效果只需让字从浅天空中离开：建议偏移约字高 1–2%、模糊约字高 1–3%、不透明度先从 10–25% 试，最终以实际缩略图对比调校。不能出现厚黑描边、立体挤出、强硬投影、统一脏纹或霓虹。

输出透明 RGBA 主字层；如果技术上更利于验收，暗分离影可另给透明层，但不得把来源风景画进字层。用于非地理内容时字体照用，拉丁文必须是实际主题的准确名称/词，不沿用原图地名。
