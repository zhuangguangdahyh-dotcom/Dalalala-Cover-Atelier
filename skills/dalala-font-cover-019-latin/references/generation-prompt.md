# 透明拉丁主字生成提示模板

输入：`{exactText}`（准确、全大写的拉丁短词）、`{canvasWidth} × {canvasHeight}`、`{textBox}`（参考 x10–93%、y6–19%）、`{fillRole}`、原图局部样张。只生成这一行文字，背景真正透明 RGBA。字母高瘦、极粗、内在右倾，局部结构性阶梯切口、楔形/斜切端口、狭长开放字腔；一条水平基线，逐字光学紧排，整体宽而有压迫感。实心高明度中性填充，低强度向下/侧灰暗分离影。不得生成照片、第二行、额外字母、厚描边、浮雕、霓虹、纸纹或统一破损。

生成后人工逐字核对输入与输出；如拼写、字骨或透明度错误，重做字层，不靠遮盖和普通字体代替。
