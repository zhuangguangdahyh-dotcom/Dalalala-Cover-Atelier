# 参考 026｜「打开书本里的世界」适配规则

## 内容因果

先写书籍／阅读主题 → 本页打开的具体世界 → 谁带观众进入／观察 → 三章各发现什么。原图蒙古国人物让观众代入，蒙古包、木门、车和草地证明世界存在；右侧地名是页签，左下三组像目录。书本是编辑来源和叙事入口，原图没有实体翻开的书；不得加巨书、魔法门或卷页遮住纪实现场。

## 素材门槛与改造

1. 优先一张同场真实照片：上方连续天空或简净远景承载文字，中下部有清楚的主行动，左右保留至少两个可辨世界线索。人物可一人、两人或多人，可是读者、向导、被访者或真实参与者。人数不锁；行动总体约 25–35% 画面，集中 x约 28–82%、y约 26–91%。只有空景时，须先测试能否仍表达“进入书中世界”。
2. 原图的一成人两儿童及举手是照片事实，不能每次照搬。新动作由书的内容决定，如翻阅、指认、行走、观察、采访或制作；不镜像或复制人物。多人须有自然前后、同场光线和视线关系。
3. 身份与事实锚点：人脸、实际人数、关键手势、服饰标记、建筑／产品结构、地点证据。自由区：天空延展、非关键杂物、局部明度、具体色值和授权署名。T0 裁切调色；T1 同视角扩天空或清杂物；T2 只为遮挡修复局部抠图，边缘和光色自然；T3 整幅重生成只能标为视觉试作，不能称真实纪录。
4. 景别为能见人物动作和环境的中景至中远景，平视略低。3:4 裁切保上方文字区、关键动作、左右世界线索与地面。天空不足先扩图或换素材，不移动标题盖脸；环境无事实证据时停用。

## 固定空间与文字

- 3:4，暖色宽框左右约 3.5–4%、上下约 2.5–3%；内照片 x4–96%、y3–97%。左上真实期号 x9–29%、y6–10%，右上真实坐标／日期 x61–92%、y7–10%；八字主标题「打开书本里的世界」x8–92%、y11–20%，仅一行。
- 英文左右两段分别 x9–32% 与 x63–91%、y20–23%，保持“读书／见世界”语义；右侧世界标签 x70–91%、y24–34%；左下三组章节 x9–50%、y68–93%，各有短章题与 1–2 行真实说明；右下客户署名 x71–91%、y88–93%。章节可叠衣服／地面，不压脸与识别物。
- 中文依赖 dalala-cover-026-editorial-song，英文与索引依赖 dalala-cover-026-roman-serif，均为测试态。字体决定字骨和透明层，本 Cover Skill 决定大小级差、字块位置、左右分置。
- 暖框可见约 12–14%，冷色中高明天空约 35–42%，人物可见约 25–35%。色值可变；冷暖角色、面积关系、近白字对背景的对比不可翻转。禁止整幅黑蒙版、厚描边、伪文字。

## 跨内容测试与失败

可用建筑书对应真实建筑与观察者、科普书对应生态与观察者、地方志对应街巷与走访者。每例须有明确书与真实世界的桥、不同的人物安排和三个具体章节；只改地名或人物颜色不算通过。

失败：普通商业探访没有阅读来源；强迫固定三人或举手；缺世界证据却用纯色背景；编造坐标；三章只有空话；白字在亮云上消失；复制原署名；未通过原尺寸和 360 px 检查；拆解未确认就正式渲染或上架。
