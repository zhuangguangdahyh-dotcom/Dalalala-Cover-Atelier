# 参考 034 调用规则

状态 `studied`，`analysisConfirmed=false`，`renderAllowed=false`。调用前读 `assets/reference-original.jpg`、`analysis.md`、`references/anatomy.json`、`references/adaptation-rules.md`、`references/manifest.json`。034 是 Cover Skill 编号，不等同 `layout-034`。本轮针对“注意文字图层顺序”修订。原图准确文字为“一个外卖员的 / 鲁迅文学奖”。

## 输入与判断

输入当前行业、账号真实身份、主题、标题、需要展示的对象、素材和平台。默认画布 3:4；此模板没有横版变体。先找主题中的**一个**行动主体和能证明身份/动作的工具、载具或场景，再找一句两行成立的短命题。原图骑手、奖项和媒体署名是原内容事实，不直接挪用。

## 固定骨架

- 满幅连续现场；上部约 y=7%–40% 两行大白色干刷命题，上行约 x=10%–90%，下行约 x=10%–94%。保持局部飞白、长笔锋、字间差异和相近的白色视觉面积。上行建议 5–7 字、下行 4–6 字，过长改写。
- 约 x=28%–75%、y=19%–27% 放真实短署名/短标的细线拉丁手注，面积远小于主标题。它必须在两行窄缝内，不能成为副标题。若当前主题没有真实短标，应判定该主题/素材暂不适配，不能静默删去这一层。
- 单个行动主体位于中偏右约 x=41%–84%、y=33%–100%，脸和身份锚点清楚，工具/载具与人、地面有真实接触；左下 x≈0%–42%、y≈65%–100% 保留低密度现场留白。上方低细节背景承载白字，两侧场景线索引向主体。
- 左上约 x=3.8%–16.8%、y=2.8%–12.3% 为近方形、2×2 粗字来源标；深底与高明度字，下行首字暖强调，画布面积约 1.2%–1.4%。内容必须是当前真实账号/栏目。不能用原媒体标识冒用出处；真实名称无法形成准确 2×2 时报告不适配。

## 图层合同

后到前：`连续现场与主体` → `局部对比修整` → `透明白色干刷标题` → `透明细线手注` → `方标蓝底` → `方标白黄字`。手注在白字前，行间少量交叠处细线连续；白字可贴近头盔外缘但不盖眼鼻口和关键职业证据。人物不能被抠到白字前切断笔画。方标预先腾安全区，不用蓝底事后盖掉标题。每次在 coverPlan 中写明文字 z 顺序、交叠范围和禁遮挡区。

## 字体依赖

主标题调用已存在的测试态 `dalala-cover-034-dry-brush`；行间手注调用已存在的测试态 `dalala-cover-034-fine-note`；方标调用本模板测试态 `dalala-cover-034-news-badge`，注册提案见 `references/font-registry-entries.json`。各文字层分别生成透明层并逐字检查，不以普通字体静默替代。三个依赖均未通过正式视觉验收。

## 素材与色彩

按 `references/adaptation-rules.md` 诊断身份/事实锚点、背景自由区及 T0–T3 改造级别。人物、产品、职业、标题内容与具体配色可变；上部明度与低细节、白字对比、下部深实体、小面积手注和方标强调的关系不变。原图雨雾可换成当前真实场景支持的光影，不能只换脸或行业名。
