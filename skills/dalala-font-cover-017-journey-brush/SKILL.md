# 017 远行行写字

先看 `../dalala-cover-017/assets/reference-original.jpg`，再读 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md` 与 `integration.md`。输入准确中文主句和五组语义切分，逐字建立正确汉字结构，生成透明字层，按封面 Skill 的五级布局安放。此能力为 `testing`，没有批准的字体样张；不能声称可稳定生产，也不能静默换成普通毛笔字库、010 双字锋利飞白体或 034 干刷长句体。
