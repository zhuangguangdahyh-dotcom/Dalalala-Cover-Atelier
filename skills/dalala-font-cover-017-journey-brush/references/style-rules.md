# 字形规则

参考原图只有一条中文主句，故该规则是待测试的字形假设，不是已通过的字库。字骨须先逐字符合规范汉字，再做行书化：横画宽而有轻微顿挫，转折允许软硬并存，撇捺有方向，收笔有自然长短。每字的粗细、重心、倾角与留白不机械复制。保留接近实心的填充和少量笔缘干涩；不使用整层噪声蒙版。

视觉节奏由两层承担：字形层提供活人书写的起收势；封面布局层把文字切成五组并安排宽—窄—宽—窄—宽的错落。Font Skill 不擅自改变主句文字、不负责草坡照片，也不把五组坐标烙进字形文件。白色只是在原图中承担高明度角色；替换主题可选择新的高明度色值，但仍须通过背景对比检查。

禁止普通楷体、字库式标准行楷、夸张狂草、过厚重墨与尖锐长锋、所有字同角度倾斜、厚描边、硬阴影、三维挤出以及把错误汉字当视觉特效。
