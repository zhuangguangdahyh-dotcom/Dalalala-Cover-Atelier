# 透明标题字层提示词模板（测试态）

输入：`exactText`、五组 `semanticGroups`、画布尺寸、五组文本框、`fillRole`。仅生成准确的中文书写字层，透明背景，不生成风景、人物、英文、印章、地名或边框。

参考原图中的八字五组行写：可读的现代行书／轻行草骨架，接近实心的高明度笔画，横画有宽窄节奏，转折自然，撇捺有呼吸和运动方向，笔缘少量真实干涩。每字独立构造，不重复相同字图；保持正常汉字结构和原输入顺序。按给定五组文本框形成宽—窄—宽—窄—宽的视觉重量，不机械居中排成印刷楼梯。无描边、投影、纸纹、草坡、伪书法印章。输出含 alpha 的独立图层。

生成后逐字人工核对；若模型无法稳定写准，转入人工字形构造，不可用错误字层合成。
