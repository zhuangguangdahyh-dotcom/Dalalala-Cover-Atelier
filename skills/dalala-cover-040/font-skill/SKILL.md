# 040 刀锋变形宋骨字｜测试态

本 Font Skill 仅供 `dalala-cover-040` 的主标题角色测试。源图为 `../assets/reference-original.jpg`，正向批准样张尚无，不能作为 active 字体向其他模板自动推荐。调用前读 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md` 和 `integration.md`。

核心字骨是高反差宋体/展示字的锐利横竖转折，但已被大胆拉长、错位、扭转。每字保留标准汉字可识别结构，选 1–2 条笔画伸成长而利的箭头形或薄片形端部，局部细画与粗竖之间有明显体量差。字面为干净的单色实填；粗细来自字骨，不靠描边、投影、颗粒、油漆飞白或普通字体整体倾斜。每个字独立绘制，再按封面位置微旋转、非均匀缩放及交错放置；字与字之间既有距离，也允许延长笔画跨过空白但不能压中央卡短句或人物眼睛。

先校正文案与基本结构，再检查 360 px 缩略图是否一眼可读。生成真透明 PNG 逐字层，最终按 `cover-040` anatomy 排布。字体结果需经用户与真实内容测试，现阶段不得视为批准。
