# 字骨与动作

- 先按标准汉字确定偏旁、笔顺方向和必需内部空间，任何长锋都不能形成另一个字。
- 主体笔画要有宋体式粗细反差和尖锐切边：粗画占视觉体量，细横与斜笔像薄刀片；端部可平切、楔切或箭头状伸展。
- 每字只选 1–2 处长锋，长度可达正常字框的 15–35%，方向须服务周边留白。不是每一笔都拉长。
- 单字可轻度斜切、宽窄变形、部件错位；同一句至少有一大一小、一竖一斜的节奏。上部两字视觉体量最高，下部单字散开并沿人物头顶形成弧形包围。
- 实心单色，边缘干净；没有全局噪声、轮廓描边、三维挤出、油漆刷毛或阴影。必要透视只作用于字的摆放，不改变汉字部件。
- 透明图层逐字生成；重复字也需单独实例。输出前逐字校验、检查透明通道、与中心卡和眼睛的避让，并看 360 px 缩略图。
