# 参考封面 052｜测试态 Cover Skill

先读 `references/manifest.json`、`references/anatomy.json`、`references/adaptation-rules.md` 和 `references/analysis.md`，再看 `assets/reference-original.jpg`。原图是唯一视觉证据，坐标只是帮助约束；必须复现“上方双结果卡 → 中央指向人物 → 两侧分裂大字”的因果关系。

## 调用输入

行业与账号身份、主题、3:4 输出尺寸、主体照片或可重建主体、两张可区分的结果证据、标题原文、品牌信息。缺少能做中央主体或两张证据的素材时，先标记不适配，不能用随机小人和无关界面凑图。

## 执行顺序

1. 抽取内容角色：谁完成什么、左卡和中卡分别证明什么、标题的轻前缀与两块重结果词是什么。确保新主题不同于参考原行业，且逻辑完整。
2. 把主体调到下部出血的近景；保留头部和双手/视线指向上方的动作关系。精抠人物边缘，修复毛发与手指。
3. 处理双结果卡：左浅斜、中深正，保持大小和交叠关系；卡片下缘让人物帽顶遮住。为卡片保留轻阴影与透视。
4. 建立暖中调底、局部磨损、人物后白色半调网点、人物外高纯手工粗描边。检查各层作用区，避免全画面统一纹理。
5. 生成文字独立图层。主标题调用 `dalala-cover-052-rough-white`，轻前缀调用 `dalala-cover-052-thin-black`；两者的测试态规则位于本 Skill 的 `font-skills/`。现阶段它们均未验收，不能静默降级成普通字体。中文逐字校验后按左右错位关系合成。
6. 加入少量可选角落装饰，做 360 px 缩略图复核。检查两张证据、主体头部、左右字块三者的视觉关系和标题可读性。
7. 输出复刻结果及差异记录，提交用户确认。确认前本 Skill 维持 `studied`，不得标为 `active`。

## 不可变的模板身份

中央近景人物下边出血；上方左浅斜卡与中深正卡形成双证据；右高左低的粗白大字围住人物；轻黑手写前缀；主体手工高纯粗轮廓与后层半调网点；暖中调底与冷亮焦点、深色锚点共同构成明度结构。任何主题转换均服从 `references/anatomy.json` 的比例范围。

## 失败即退回

人物动作与卡片无因果；结果卡变成两个平铺截图；白字合并成横排或遮脸；标题无法在 360 px 辨认；描边/网点被普通发光与满版波点替代；字体规则缺失却继续生产；新行业只换名词没有新的真实证据。
