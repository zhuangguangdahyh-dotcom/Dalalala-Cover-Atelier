# dalala-cover-043｜单张参考封面规则（研究态）

本 Skill 只处理参考 043。先读 `references/manifest.json`、`references/anatomy.json`、`references/adaptation-rules.md` 和 `assets/reference-original.jpg`。当前为 `studied`，拆解尚待用户确认，禁止自动推荐、生产发布或标记 active。

## 调用输入

提供行业、账号身份、主题、真实场景照片、主标题原文、顶部引句、底部微标、画幅。默认只接受 3:4。原图中的上海、建筑和骑行者是内容实例，不是固定行业元素。

## 重建顺序

1. 判断当前主题需要哪种真实场景，选择一张有明确建筑或环境秩序、中央较暗且可读、底部有一到数个自然活动主体的照片。先确认主体与主题有因果联系。
2. 把素材裁到 3:4，保留上半部建筑立面或同等秩序背景、中部承字空间、下部活动前景。主体不必是骑行者，但须有真实现场尺度与动势。不得将任意照片直接压暗冒充。
3. 调整局部曝光：背景深但看得到砖石或环境纹理；标题所在区比浅色标题至少形成清晰明度差；保留少量真实暖光。暗角只辅助，不吞掉场景。
4. 先在中部叠三行巨大浅色罗马衬线标题，块形依次为宽、窄、宽，整体居中。用 `dalala-cover-043-editorial-serif` 测试态字体依赖；透明文字层逐字校对。标题过长先改写，禁止增加第四行或改成等宽三行。
5. 顶端居中放一行极小浅色斜体引句，底部中央放极小日期或系列标记；两者只做远处回声，不抢标题。
6. 以 360 px 缩略图检查：第一眼读到三行标题，第二眼感到真实街景纵深，第三眼看到前景运动；检查文字与场景亮点、人物脸部和车轮不发生破坏性遮挡。

## 固定与变量

固定：满版低照度现场摄影；上部安静建筑或环境秩序；中部宽窄宽三行标题及居中轴；下部近景活动主体和景深层次；微小顶部引句与底部标记；浅文字对深场景的面积及明度关系。

可变：人物身份、服装、动作、具体地点、场景物件、标题文字、顶部引句、具体色相。替换后仍服从 `anatomy.json` 的框位与面积区间。没有产品槽位时不得强塞商品抠图；有产品可让其作为自然现场物件出现。

## 字体与状态

主标题依赖 `dalala-cover-043-editorial-serif`，规则见 `font-skill/`；这是本模板内的测试态依赖，待服务端校验后登记，未经验收不可称为已批准字体。顶部与底部可用同一字体的斜体细字变体，仍须逐字校对。测试与用户验收记录为空；只有完成真实内容复刻、跨主题测试、字体 QA 和用户验收，才可申请 active。
