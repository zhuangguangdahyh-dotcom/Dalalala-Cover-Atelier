# 043 编辑式罗马衬线（测试态）

此字体 Skill 仅为参考 043 的主标题与顶底微字服务。读 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md` 和 `integration.md`。源字形证据为 `../assets/reference-original.jpg`。没有批准样张，status 为 testing；不得在工作台当作 active 字体使用。

输入逐字准确的标题与行分割，生成透明背景文字层，再按 043 的宽窄宽框位合成。任何无法确认的字形进入人工复核。不要用通用细宋或普通 Times 排版静默替代。
