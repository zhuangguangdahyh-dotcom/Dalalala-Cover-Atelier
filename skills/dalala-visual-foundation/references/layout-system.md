## 核心原则：构图与风格解耦

Panel 家族决定“用什么视觉语言说”；构图骨架决定“信息怎样在画面中发生”。

不建立 Panel 001 = Layout 001 这种编号对应。正确流程是：

1. 定义传播命题。
2. 选择一个 Panel 审美家族。
3. 根据内容关系选择一个构图骨架。
4. 将骨架转译为当次比例、媒介、字量和图像类型。
5. 使用 Panel 的色彩、材料、线条、字体和留白规则完成表面语言。

## 十二个可调用构图家族

### L01｜分割与比例

**作用**：用显性区域分配主次、证据与解释。

**原型**：001 三分法、002 九宫格、003 黄金分割、007 上下、008 前后、009 水平、010 垂直、063 分栏、064 分割、065 区块。

**适合**：论点 + 证据；问题 + 方法；照片 + 判断；前后变化。

**禁区**：为了填满区域而把信息凑成同等重要。

### L02｜对称、平衡与重心

**作用**：建立稳定、权威、对话或可控张力。

**原型**：004 对称、005 非对称、006 均衡、041 单点聚焦、042 多点平衡、087 重心、088 偏重心、089 视觉中心。

**适合**：封面、品牌定调、对立观点、主题人物、核心结论。

**禁区**：把对称误解为一切居中，或把非对称误解为随意摆放。

### L03｜开放、封闭与边界

**作用**：决定内容是向外延伸，还是被容器、框架或压力包裹。

**原型**：011 开放、012 封闭、029 环绕、030 框架、094 开合。

**适合**：自由 / 束缚、内外、边界、阶段转换、被看见。

**禁区**：边框只做装饰，没有叙事作用。

### L04｜密度与留白

**作用**：通过信息密度差异建立呼吸、压力、稀缺或聚焦。

**原型**：013 满版、014 留白、015 密集、016 疏朗、017 疏密对比、045 聚合、046 分散、047 集中、048 扩散。

**适合**：焦虑 / 松弛、复杂 / 清晰、“一眼重点 + 二眼细节”。

**禁区**：密集变成小元素铺满，留白变成无内容。

### L05｜点与节点关系

**作用**：表达单个核心、双方关系、群体、步骤或网络。

**原型**：018 单点、019 双点、020 多点、026 放射、027 向心、028 离心、043 群组、044 分组、056 呼应。

**适合**：人物关系、核心客户、团队、系统、信息传播、因果。

**禁区**：节点等大、等距、等重，看不出关系层级。

### L06｜字母式与几何容器

**作用**：用一个可瞬间感知的大形统摄内容。

**原型**：021 S 形、022 C 形、023 Z 形、024 V 形、025 X 形、031 三角、032 倒三角、033 圆形、034 椭圆、035 方形、036 矩形、037 菱形、038 十字、039 T 形、040 L 形。

**适合**：一页一概念、强识别封面、路径、聚焦、转折、对立。

**禁区**：先选形再硬塞内容，导致形与意义无关。

### L07｜叠加、阶梯与次序

**作用**：表达阶段、版本、级别、过程和前后遮挡。

**原型**：049 层叠、050 阶梯、051 重复、052 渐变、053 节奏、054 韵律、078 层次。

**适合**：方法论、成长、多层产品、时间、递进、一组同源信息。

**禁区**：每层都做成一张 UI 卡片，削弱整体画面。

### L08｜网格、模块与编辑系统

**作用**：管理多个同类元素，建立系列感和可扫读性。

**原型**：061 网格、062 模块化、063 分栏、064 分割、065 区块、066 矩阵、067 棋盘、068 卡片、069 拼贴、070 蒙太奇。

**适合**：多案例、多观点、步骤、图文轮播、风格索引、系列页。

**禁区**：把所有页都做成均匀卡片网格；用模块化代替主次。

### L09｜引导线、轴线与视觉动线

**作用**：控制观众的阅读方向、速度和返回。

**原型**：058 轴线、059 中轴、060 偏轴、071 引导线、081 斜线、082 曲线、083 折线、084 波浪线、085 交叉线、086 平行线、090 视觉动线、091 动势、092 静态。

**适合**：叙事流程、动作、时间、转折、声音、情绪推进、页面阅读。

**禁区**：线条只做装饰，或动线与文字阅读方向互相打架。

### L10｜透视、景深与空间层级

**作用**：创建进入感、距离、旅程、空间级别和大小叙事。

**原型**：072 透视、073 纵深、074 近大远小、075 前景、076 中景、077 背景、078 层次、079 空间、080 深度。

**适合**：建筑、商业空间、旅行、客户旅程、从表层到核心、阶段性内容。

**禁区**：为了戏剧感使用夸张透视，破坏可读性或造成建筑畸变。

### L11｜主次与感知对比

**作用**：用一种最强对比快速建立层级。

**原型**：055 对比、093 主次、095 虚实、096 明暗、097 色块、098 色彩对比、099 大小对比、100 动静对比。

**适合**：封面、结论、痛点、反差、利益点、重点引导。

**禁区**：同时强化明暗、大小、色彩、动静和虚实，导致所有东西都在喊。

### L12｜叙事组接与呼应

**作用**：在不强制统一为一个场景的情况下，组织多个时刻、证据或观点。

**原型**：051 重复、054 韵律、056 呼应、057 镜像、069 拼贴、070 蒙太奇。

**适合**：案例过程、人物故事、内容组照、多个视角、并行线索。

**禁区**：把蒙太奇做成随意拼图，没有节奏、呼应和主导线索。

## 构图选择器

- **一个主命题**：L02、L05 单点、L06、L11。
- **两方对照 / 对立**：L01、L02、L05 双点、L11。
- **三到七个同类信息**：L07、L08，或 L12。
- **因果 / 路径 / 时间**：L07、L09、L10。
- **复杂关系**：L05 + L09，但必须建立一个主节点。
- **空间与建筑**：L01、L09、L10，必要时用 L11 建立主次。
- **情绪与哲思**：L03、L04、L09、L11，通常只选其一为主。
- **案例叙事 / 多照片**：L08 或 L12，不允许默认三宫格。

## 用在不同画幅上

构图是力学关系，不是像素坐标。从 3:4 原型转移到 16:9、9:16、1:1 或 4:5 时：

- 保留视觉中心、力的方向、密度对比、空间深度和阅读顺序。
- 重新计算文字行长、图像裁切、边缘越界和留白位置。
- 不等比缩放全张，不把竖版上的左右关系机械搬到横版。
- 每一个比例都应是一次独立的完整构图。
