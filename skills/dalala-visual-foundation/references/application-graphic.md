# 图文、封面与内容图片应用规则

## 一套图文不是一张模板复制十次

系列一致性来自共同的视觉命题、色彩角色、材料世界和文字行为；页面多样性来自构图骨架、主体尺度、密度与动线的变化。

## 封面

- 一眼只建立一个点击理由。
- 使用 L02、L04、L06 或 L11 中的一个主骨架。
- 标题、主体和一处强调色构成三角关系；不把标题贴在图片上方当横幅。
- 业务类内容不能为了高级而隐藏行业关键词。
- 标题可大，但不能同时使用巨大字、强对比、满版图和多标签。

## 内页

每页承担一种工作：

- 场景页：建立真实感；
- 判断页：给结论；
- 机制页：解释关系；
- 证据页：提供案例、数据或细节；
- 转折页：制造停顿；
- 方法页：给出动作；
- 收束页：留下记忆。

不要在一页内同时完成全部工作。

## 系列节奏

推荐序列不是固定模板，可按内容调整：

1. 强中心封面；
2. 真实场景或痛点；
3. 观念极简判断；
4. 关系 / 机制图；
5. 案例或证据；
6. 方法 / 路径；
7. 留白收束。

相邻页避免同轴、同尺度、同密度。整组至少包含：

- 一张真实或证据主导页；
- 一张强图形页；
- 一张关系或路径页；
- 一张高留白页。

## 不同平台比例

### 4:5 / 3:4

- 适合封面、单页图文和编辑海报。
- 可使用垂直路径、偏轴重心、上下分区、前后层次。
- 标题和主视觉不机械占据各 50%。

### 9:16

- 保留上下阅读节奏，但避免顶端堆满标题、底部塞满正文。
- 让视觉动线纵向推进；重要信息避开平台 UI 可能遮挡区。
- 微型注释在手机端必须仍可读，不把 PPT 小字直接缩进来。

### 1:1

- 适合单点、环绕、中心场、字母式大形和密度对比。
- 不要把竖版裁掉上下空白得到方图，要重新构图。

### 16:9 / 横版

- 适合案例横幅、公众号头图、视频章节图和横向叙事。
- 使用偏轴、横向景观带、分栏、引导线与前中后层次。

## 文字密度

- 封面只保留标题、必要对象和极少身份信息。
- 内页正文优先拆页，不在一个画面放完整文章。
- 文字可充当主视觉、注释、证据、旁白或环境文字，但同一页只选一个主角色。
- 小字不是高级感的必需品；手机端不可读的小字等于噪音。

## 视觉资产生成

- 一页一个执行提示词，避免用万能母提示词批量填充。
- 同组通过人物、主题、核心环境、配色角色和材料统一；通过构图、动作、尺度、视角和动线形成差异。
- 每个比例独立生成完整构图，不以机械裁切替代重构。
- 有参考图时，保留内容安全边界和识别锚点，不继承不相关主体、品牌、文字或危险内容。

## 图文禁区

- 所有页都是中心人物 + 顶部大字。
- 普通三宫格、照片卡片、白底圆角卡片堆叠。
- 土味红黄对比、廉价促销标签、大字报。
- 只替换标题和主图，构图、动作、前景与背景完全重复。
- 为了“有设计感”加入与内容无关的星星、圆点、胶带、网格、箭头。
- AI 塑料皮肤、光滑矢量、无材料证据的假手绘。
