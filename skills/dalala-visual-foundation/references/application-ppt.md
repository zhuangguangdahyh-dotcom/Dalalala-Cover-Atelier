# PPT / Slide Deck 应用规则

## PPT 不是把海报横过来

PPT 是时间媒介。单页要成立，连续翻页还要形成叙事呼吸。Panel 审美负责每页的视觉语言，构图系统负责每页内部的力学，整套 PPT 还需要第三层：页面之间的节奏。

## 三层结构

1. **全套叙事层**：开场、问题、判断、证据、机制、方法、案例、结论。
2. **单页构图层**：从 L01–L12 选择一个主骨架。
3. **表面语言层**：从 F01–F11 选择主审美家族，定义色彩、材料、文字与留白。

不要让一个版式从第 2 页复制到最后一页。统一来自视觉语法和叙事节奏，不来自所有页长得一样。

## 九类高频页面

### 1. 封面页

- 任务：建立唯一核心命题和气质。
- 构图：L02 重心、L04 留白、L06 大形、L11 单一强对比。
- 适配家族：F04、F05、F09、F10、F11。
- 规则：一个标题、一个主视觉、一个次级身份信息；标题不能像促销口号堆满页面。

### 2. 章节转场页

- 任务：重置节奏，制造停顿。
- 构图：L03 开合、L04 疏朗、L06 几何容器、L09 静态。
- 适配家族：F04、F07、F10。
- 规则：比普通内容页更少，允许材料或字体成为唯一主角。

### 3. 痛点 / 冲突页

- 任务：让矛盾被瞬间感知。
- 构图：L02 非对称、L03 封闭、L04 疏密对比、L11 主次。
- 适配家族：F03、F04、F06、F10。
- 规则：一次只用一种最强对比；不要把所有痛点列成红色卡片。

### 4. 观点 / 判断页

- 任务：让一句判断具有权威和记忆点。
- 构图：L05 单点、L06 大形、L11 大小或明暗对比。
- 适配家族：F04、F05、F10。
- 规则：观点文字可以成为主形，但必须保持一条主阅读路径。

### 5. 证据 / 案例页

- 任务：证明判断来自真实现场。
- 构图：L01 分割、L08 编辑系统、L12 叙事组接。
- 适配家族：F09、F11，必要时以 F10 做证据编码。
- 规则：照片优先保持真实；设计介入负责选择、裁切、层级和注释，不把案例图过度艺术化到失去证据。

### 6. 机制 / 关系页

- 任务：把看不见的关系变得可理解。
- 构图：L05 节点、L09 动线、L07 次序。
- 适配家族：F04 + F06。
- 规则：先建立一个主节点或主路径；不要做标准流程图或科技 UI。

### 7. 方法 / 步骤页

- 任务：呈现递进而不是列清单。
- 构图：L07 阶梯 / 节奏、L09 引导线、L10 纵深。
- 适配家族：F05、F06、F08。
- 规则：步骤之间要有力的方向；相邻页可通过重复形体形成连续动作。

### 8. 多案例 / 多观点页

- 任务：让多个同类信息可比较、可扫读。
- 构图：L08 网格 / 分栏 / 矩阵，或 L12 拼贴 / 蒙太奇。
- 适配家族：F01、F03、F09、F11。
- 规则：网格中必须有主次；不默认三宫格，不把每个元素都做成同尺寸卡片。

### 9. 结论 / 收束页

- 任务：留下判断和余韵。
- 构图：L04 大留白、L05 单点、L09 静态、L11 单一对比。
- 适配家族：F04、F07、F10。
- 规则：不要重复全套摘要；只留下最重要的一个判断和必要下一步。

## 页面节奏

连续页面至少在以下维度中改变两个：

- 视觉重心：左 / 中 / 右，或上 / 中 / 下；
- 密度：疏 / 中 / 密；
- 主体尺度：微缩 / 中景 / 满版；
- 构图力：静态 / 方向性 / 空间纵深；
- 图文关系：文字主导 / 图像主导 / 图文共场；
- 材料呈现：平面 / 手工 / 真实摄影 / 空间对象。

变化不能破坏同一套色彩角色、字体行为和材料世界观。

## 字体与信息密度

- 一页只保留一个标题层级和最多两个正文层级。
- 标题先短化，再放大；不要通过缩小字体容纳废话。
- 正文行长保持容易一眼扫完，避免横跨整页的长句。
- 微型注释只能承担证据、编号、坐标、来源或旁白，不承载核心论点。
- 字体总数通常不超过两个家族；变化优先来自字号、字重、字距和位置。
- 可读性优先于“像参考图”。中文竖排、旋转和解构只用于短词。

## 图像与材料

- 高审美插画、纸艺、版画、立体微景观或观念图应作为完整视觉资产生成，不用一堆 PowerPoint 形状拼成伪插画。
- 简单关系图可以使用原生形状，但必须服从选定的 Panel 线条、色彩和留白规则。
- 真实照片不做 AI 塑料化处理；只进行可信的裁切、轻调色和必要的艺术介入。
- 一张图默认只使用一次，除非它是跨页连续叙事的明确锚点。

## 16:9 适配

- 不保留原 Panel 的 3:4 上下 50:50 外壳，除非页面本身就是对照。
- 横向画幅优先使用偏轴、分栏、横向景观带、动线和前中后层级。
- 将竖版的大留白转译为横向的停顿区、行进方向或视觉终点。
- 视觉中心不必居中，但必须让演示屏上的第一眼落点明确。

## PPT 禁区

- 全套都是白底卡片网格、圆角矩形、胶囊标签和仪表盘。
- 每页都有同一张大标题、同一条色带、同一块图片区。
- 为了“高级”而去掉业务关键词、真实证据和人物身份。
- 把插画风格、材质和构图当成三个互不相关的装饰层。
- 背景过满、文字过小、装饰过多，导致观众只能读而不能看。
- 相邻页轮廓几乎相同，只替换文字。

## PPT 输出前检查

1. 缩略图模式下能否看到清晰的叙事起伏？
2. 每页是否只有一个压倒性中心？
3. 相邻页是否至少有两个节奏维度发生变化？
4. 同一视觉家族是否保持材料、色彩和字体行为一致？
5. 是否有任何页面退化成普通 UI 卡片？
6. 真实证据是否仍然可信和可识别？
7. 所有标题是否在投影尺寸下清晰可读？
