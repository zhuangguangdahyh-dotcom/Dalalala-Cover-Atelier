# Dalala Panel 001–100 风格谱系

## 使用方法

这是一个可交叉的谱系，不是把 100 个 Panel 硬分成互斥类目。一个 Panel 可以同时拥有手绘、版画、编辑和民艺属性。

为一次任务配风格时：

1. 选一个主家族，它决定作品的世界观。
2. 最多选一个辅助家族，只解决一个具体问题。
3. 再选一个局部技法作为记忆点。

不允许设定三个主家族，也不允许用关键词把彼此冲突的家族平均混合。

## F01｜安静手绘编辑

**精神**：用人的手感、编辑删减和纸面呼吸，把日常内容变成有观察感的出版物。

**关键行为**：纤细或轻微失准的线；小主体或选择性细化；大量纸面；微型文字；生活感。

**适合**：人物观察、日常细节、温和观点、情绪叙事、顾问型内容。

**先行 Panel**：001、002、006、007、016、017、019、026、036、040、053、059、062、066、067、069、070、071、075、076、079、080、081、089、091、092、094、098、100。

**最容易失败**：变成可爱贴纸、普通手账或一片柔和但没有视觉命题。

## F02｜稚拙民艺叙事

**精神**：用故意不完美的造型、朴素图符和限制色，创造亲切、幽默、有生活智慧的叙事。

**关键行为**：primitive forms；flattened perspective；粗蜡笔 / 油画棒；大块剪影；小面积跳色；笨但准。

**适合**：宠物、人物性格、生活片段、食物、社区、温度型品牌。

**先行 Panel**：005、010、017、031、034、049、059、066、067、076、082、083、089、096、097、098、100。

**最容易失败**：画得太标准、太卡通，或只留下“丑”而丢掉识别和构图智慧。

## F03｜版画、专色与民间印刷

**精神**：通过限色、高对比、套印误差和纸墨证据，让图像有被制作过的物质性。

**关键行为**：Risograph / silkscreen / woodcut；专色；网点；套印偏移；干刷拖墨；不完整边缘。

**适合**：观点海报、文化内容、复古品牌、艺术活动、强识别封面。

**先行 Panel**：005、009、010、025、029、031、034、049、061、064、065、075、076、081、086、095、096、097、100。

**最容易失败**：只叠纸纹和噪点，没有真正的限色、版次和墨层逻辑。

## F04｜观念极简与诗性留白

**精神**：把图像压缩成一个命题、一组受力关系或一个有回声的意象。

**关键行为**：1–3 个核心形；大量意义留白；黑色主形；孤置、缠绕、消散、断裂、穿越；极少旁白。

**适合**：心理、哲思、社会议题、品牌态度、转折页、结论页。

**先行 Panel**：003、011、012、015、021、022、025、056、058、060、062、079、080、086、088、090、092。

**最容易失败**：以为“少”就是高级，结果只剩无意义几何装饰。

## F05｜现代主义几何与品牌图形

**精神**：用精确的比例、几何母体、形与负形建立稳定识别。

**关键行为**：Bauhaus / mid-century；几何抽象；模块化形体；大尺度色块；严格对齐；大字或标识系统。

**适合**：品牌封面、业务架构、方法论、方案总览、精神图形。

**先行 Panel**：001、004、015、019、025、031、032、033、035、057、063、072、074、084、088、090、093、095、097、099。

**最容易失败**：做成公司 VI 手册模板、科技 UI 或与内容无关的形状堆积。

## F06｜图式思考与关系映射

**精神**：不画物体表面，而是把关系、状态、路径、节点和意义画出来。

**关键行为**：节点、线绳、轴线、轨迹、区域、刻度、符号、实验字体；理性骨架 + 手工痕迹。

**适合**：流程、心理机制、业务链路、人物关系、战略、复杂概念。

**先行 Panel**：003、012、048、057、065、087、088、090、095。

**最容易失败**：做成标准流程图、传统思维导图、数据仪表盘或假科技界面。

## F07｜纸艺、工艺与实体对象

**精神**：让视觉像一件真实存在的手工或展陈对象，而不是质感滤镜。

**关键行为**：纸层、折叠、裁切、凹凸压、箔金、珐琅、毛毡、黏土、泡沫、绣线；真实接缝与投影。

**适合**：高端品牌、收藏感封面、产品叙事、艺术展示、质感强的转场页。

**先行 Panel**：014、018、020、027、030、035、037、038、039、043、044、045、047、049、051、052、073、074、077、078、085、087。

**最容易失败**：所有东西都像一层数字浮雕，没有厚度、受力、材料边界和真实光线。

## F08｜微缩空间与建筑叙事

**精神**：把现实内容转译为可被行走、观看或收藏的空间系统。

**关键行为**：正交等距；微缩基座；平台、路径、台阶、门洞、浮岛、剖切体；空间隐喻；精确空气感。

**适合**：建筑、城市、旅行、空间设计、流程旅程、业务生态。

**先行 Panel**：008、020、028、035、041、045、047、051、052、057、073、074、077、082、085。

**最容易失败**：做成漂亮但空洞的 3D 展台，丢掉原内容的关系和使用逻辑。

## F09｜地方、旅行与现场编辑

**精神**：从地点的空间、气候、人群、商业、文字和日常节奏中提炼独特身份。

**关键行为**：真实在地锚点；地图 / 票根 / 明信片 / 旅行出版物；空气色；本地文字和微型证据。

**适合**：城市、酒店、商业空间、旅行、街区、文旅品牌、在地叙事。

**先行 Panel**：004、013、024、028、050、051、052、054、070、076、077、084、091、096。

**最容易失败**：做成通用旅游明信片，只替换地名和地标。

## F10｜字体主视觉与出版编码

**精神**：文字不说明画面，文字就是画面的结构。

**关键行为**：字形视觉化；字号差；拉伸、旋转、重复、遮挡、基线错位；编号、日期、坐标、注脚、打字机证据。

**适合**：封面、章节页、金句页、方法论命名、系列识别。

**先行 Panel**：002、007、013、019、032、033、050、053、070、075、088、090、095、096、097、099。

**最容易失败**：大字满屏但无排版逻辑，或把所有字都做成装饰而丢失可读性。

## F11｜真实视窗与艺术介入

**精神**：不把摄影与设计切成两张图，而是通过窗口、遮挡、越界、投影或柔焦让两者成为一个现场。

**关键行为**：源图择窗；窄长或异形画框；主体越界；透明层；局部柔焦；色彩光影；图文共场。

**适合**：人物 IP、商业空间、摄影故事、案例展示、真实证据页。

**先行 Panel**：023、024、030、040、043、044、069、072、076、079、094。

**最容易失败**：做成普通照片卡片、遮罩模板或小红书三宫格。

## 组合规则

### 1 + 1 + 1

- 1 个主家族：世界观。
- 1 个辅家族：解决文字、材料、关系或空间中的一个问题。
- 1 个技法记忆点：例如一处套印错位、一条红线绳、一块金箔、一个越界部位或一个高纯度节点。

### 相容示例

- 心理机制：F04 观念极简 + F06 关系映射 + 一条暖色路径。
- 律师信任内容：F11 真实视窗 + F10 出版编码 + 一处朱红证据签。
- 工装案例：F09 在地编辑 + F05 几何品牌 + 一条建筑导向线。
- 宠物情绪图文：F02 稚拙民艺 + F01 安静手绘 + 一个过度夸张的戏剧动作。
- 品牌方法论 PPT：F05 现代主义 + F10 字体主视觉 + 一枚限色圆形节点。

### 高风险组合

- F02 稚拙民艺 + F05 精确几何：必须明确谁主谁辅，否则手工误差与几何精度会互相抵消。
- F03 粗粝版画 + F08 洁净空间：不能同时要求满画面噪点与纯净 3D。
- F04 极简 + F06 高信息映射：可以有节点，但必须建立密度岛与广阔空白的分区。
- F07 实体工艺 + F11 摄影视窗：必须交代两者的真实接触关系，不能只做悬浮叠层。
