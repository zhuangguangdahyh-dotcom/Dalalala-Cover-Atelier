# Dalala Visual OS · 审美母系统

## 1. 这套底座解决什么

Dalala Panel 001–100 的价值不是“有 100 个风格可以换”，而是反复验证了一套从真实内容到高审美视觉的转译方法：

> 先理解内容的精神，再保留识别锚点，然后通过有选择的删减、重组、材料化和版式化，把内容变成一个有作者性的视觉命题。

这套底座要服务两类使用者：

- 人：能看懂为什么好看、怎么选风格、怎么判断成品。
- Codex / 生成工具：能把审美拆成稳定变量，为 PPT、图文、封面、海报和新 Skill 生成可执行配方。

## 2. 九个共同审美基因

### 2.1 内容先于风格

所有造型、色彩、材料、文字和空间决策，先回答一个问题：这个内容最值得被记住的是什么？

高级感不来自“加得多”，而来自选得准。视觉不能为了风格牺牲主体身份、业务属性、人物关系和真实情绪。

### 2.2 识别锚点不丢

每个作品必须先确定 1–3 个识别锚点：

- 主体轮廓或比例；
- 动作、方向或观看角度；
- 关键器物、空间结构或功能节点；
- 人与人、人与物、主体与环境的叙事关系；
- 最有记忆点的色彩或局部特征。

可以抽象、夸张、压缩、剪影、几何化，但不能把“这一个”做成“随便一个”。

### 2.3 选择性记忆

不复制全部信息，只保留最能承载命题的部分。删减有三层：

1. 删掉无关细节；
2. 合并为更少、更大的形体关系；
3. 把现实对象转译为能承载意义的形、线、色、材料或空间。

它不是“简笔画”，而是编辑。

### 2.4 一页一命题

一页 PPT、一张图文、一张封面，都应该有一个压倒性视觉中心。

常见中心可以是：一个主体、一个关系、一个隐喻、一条路径、一个字词、一块结构场或一种材料现象。

“信息多”不等于“中心多”。次要信息要被纳入主中心的阅读路径。

### 2.5 留白是主动语言

在 100 个 Panel 中，97 个原始审美简报明确使用“留白”。留白不是未完成区，而是用来表达：

- 层级与专注；
- 距离、孤立、时间和沉默；
- 光感、空气和呼吸；
- 版式的节奏与停顿；
- 品牌的克制感。

留白应被指定功能，而不是用百分比机械复制。

### 2.6 色彩要有职位

一个稳定色彩系统通常包含：

- 底色：提供纸面、空气或空间气候；
- 结构色：承担轮廓、骨架、文字和主明度对比；
- 主叙事色：与内容身份相关；
- 强调色：只用于路径、节点、情绪信号或记忆点。

常用规则不是“一定 2–4 色”，而是颜色数量必须低于角色混乱的临界点。强调色不能平均洒满画面。

### 2.7 材料必须“像真的”

高级感来自材料行为一致，不是从一张纸纹贴图开始。

- 纸：有吸收、透底、纤维、压痕或毛边；
- 墨：有浓淡、拖擦、断裂、套印和局部堆积；
- 彩铅 / 蜡笔：有方向、压力和纸面摩擦；
- 丙烯 / 水粉：有覆盖、干湿差和边缘停顿；
- 纸艺 / 毛毡 / 黏土：有厚度、接缝、投影和手工偏差；
- 烫金 / 凹凸压：有角度性反光与受力逻辑；
- 干净 3D：哑光、纯色、轻微环境阴影，禁止材质污染。

材料之间可以组合，但必须有主材料和次材料，不能“什么质感都加一点”。

### 2.8 文字是画面中的物体

文字要承担一种明确角色：

- 主视觉；
- 路径和节奏；
- 出版注脚；
- 地点、时间、编号等证据；
- 物件上的原生文字；
- 一句情绪旁白。

字体、字号、字距、基线、旋转、重复和遮挡都必须参与构图。若文字只是“后来贴上去的标题”，它就还没进入这套系统。

### 2.9 完成感来自取舍

高审美成品常同时具备：

- 远看结构清楚；
- 近看材料和细节有证据；
- 文字不破坏安静；
- 调性不犧牲识别度；
- 技法不压过命题；
- 每一处复杂都有用，每一处简约都有意义。

## 3. 从内容到画面的七步转译

### Step 1｜定义传播任务

先写一句“这页要让人感受 / 明白 / 记住什么”。不允许同时存在三个并列主目标。

### Step 2｜找识别锚点

选出 1–3 个丢了就不再是它的特征。

### Step 3｜选转译引擎

在以下动词中选一个为主：

`draw / print / cut / fold / carve / emboss / map / stage / construct / isolate / dissolve / typographize`

即：绘制、印刷、剪切、折叠、雕刻、压印、映射、搭景、构筑、孤置、消散、文字化。

### Step 4｜定构图骨架

使用一个主骨架：孤立锚点、偏心平衡、三角关系、横向景观带、垂直路径、窗口越界、节点网络、中心场、大字压场或模块节奏。

### Step 5｜分配色彩职位

不先写色值，先写谁承担底、结构、叙事和强调。

### Step 6｜定材料逻辑与字体行为

指定一种主材料，最多一种辅助材料。文字要说清楚是主视觉、证据、注脚、旁白还是环境元素。

### Step 7｜用禁区完成取舍

列出 3–7 条与当次方向真正冲突的禁区。禁区不是通用垃圾词清单，而是用来保护主命题。

## 4. 十条可迁移的审美定律

1. 先保留“是谁 / 是什么”，再决定“画成什么”。
2. 先定一个命题，再定一种技法。
3. 一个主视觉中心，一条主阅读路径。
4. 留白必须有作用，密度必须有梯度。
5. 色彩先分工，再选色。
6. 一种主材料，一种辅材料，一个不完美证据。
7. 文字要成为形、路径或证据，不做贴纸。
8. 一页只允许一次明显的“用力”。
9. 先确保远看成立，再补近看质感。
10. 每一张都应由内容生长，不允许只换标题和主图。

## 5. 不能被平均掉的差异

这套母系统只提取共同判断，不把以下差异合成一个模板：

- 手绘的笨拙与几何的精准；
- 版画的粗粝与纯色 3D 的洁净；
- 哲思留白与信息图式的高密节点；
- 民艺叙事的亲切与博物馆展陈的冷静；
- 旅行编辑的在地性与观念海报的抽象性；
- 大字主视觉与微型注脚体系。

新作品应该站在谱系中的一个清楚位置，而不是踩中所有关键词。
