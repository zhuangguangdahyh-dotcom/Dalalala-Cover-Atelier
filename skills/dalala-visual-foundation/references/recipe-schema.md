# Dalala Visual Recipe Schema

## 目的

把审美判断写成可执行配方，同时防止把稳定艺术方向与当次尺寸、文案和输出数量混在一起。

## A. Stable Art Direction｜稳定艺术方向

每个新视觉 Skill 或系列项目应保存：

### 1. Communication proposition

- 这套视觉要让谁记住什么？
- 第一情绪是什么？
- 业务 / 人物 / 场景中不可被弱化的内容是什么？

### 2. Recognition anchors

- 1–3 个必须保留的身份、结构、动作、关系或色彩锚点。

### 3. Style family

- 主家族：F01–F11 之一。
- 辅家族：可选，最多一个。
- 先行 Panel：1–3 个。
- 若要求准确 Panel 风格，直接读取对应原 Skill，不用本配方替代。

### 4. Transformation engine

从以下选择一个主动作：draw 绘制、print 印刷、cut 剪切、fold 折叠、carve 雕刻、emboss 压印、map 映射、stage 搭景、construct 构筑、isolate 孤置、dissolve 消散、typographize 文字化。

- 主构图家族：L01–L12。
- 具体原型：可选 1–2 个。
- 候选构图与淘汰原因：
- 视觉中心：

### 8. Typography

### 9. One accent

只允许一个明显记忆点，例如：一处套印错位、一条红色线绳、一枚哑金节点、一个越界动作、一块高纯度色、一处点阵消散，或一个大字与小主体的尺度反差。

### 10. Prohibitions

列出 3–7 条真正保护本方向的禁区。

## B. Runtime Delivery｜当次交付变量

每次调用单独解析：

- 载体：PPT / 4:5 图文 / 9:16 / 16:9 / 海报 / 封面；
- 画幅与准确像素；
- 页面 / 图片数量；
- 用户原文与可改写范围；
- 是否使用真实照片；
- 是否需要文字、目标语言；
- 品牌和平台限制；
- 输出格式与目录；
- 当次补充要求。

Runtime 变量不能反向重写 Stable Art Direction。改变画幅时重构布局，不改变审美世界。

## D. 新 Skill 的最低结构

一个由本底座派生的新视觉 Skill 至少应包含：

- SKILL.md：用途、路由边界、关键工作流；
- references/art-direction.md：Stable Art Direction；
- references/format-adaptation.md：不同画幅或载体的适配；
- references/qa.md：特定失败项；
- assets：仅存放真正会被复制或用于输出的资产；
- scripts：仅在重复处理需要确定性时添加。

不要复制本底座全部内容进每个新 Skill。新 Skill 只保留会改变其判断的规则，并链接或引用需要的家族和构图原则。
