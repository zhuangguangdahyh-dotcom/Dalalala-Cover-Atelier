# 构图学习模型：图像 × 文字 × 空间

本文件定义如何把一张构图参考转化为可迁移的判断力。目标不是记住版面坐标，而是理解内容关系如何变成画面受力。

## 一张构图必须回答的六个问题

1. **语义关系**：它组织的是单点、双点、层级、对立、过程、系统、群组、扩散、情绪还是空间旅程？
2. **图像条件**：主体有几个，重心在哪里，动作或视线朝哪里，哪些区域低信息，哪些证据不可遮挡？
3. **文字行为**：文字是主视觉、配重、路径、证据、注脚还是环境的一部分？允许多少字、多少层级、怎样断行？
4. **空间力学**：第一眼从哪里进入，力量向哪里移动，在哪里停顿，画面如何保持或故意打破平衡？
5. **留白职责**：留白承担聚焦、呼吸、方向、时间、边界、层级还是悬念？
6. **失败边界**：在什么条件下，这种构图即使技术上能排也必然显得错误、廉价或含义不清？

## 底图诊断

在选择构图前，先输出以下判断。没有完成诊断，不得先选左右、上下、居中等版式。

- `subject_count`：主要主体与次要主体数量。
- `subject_bbox`：主体占画面的大致范围；不得把脸、手、产品、建筑主节点视为空白。
- `visual_weight`：明度、饱和度、面积、清晰度共同造成的重心，而非单看几何位置。
- `gaze_motion_vector`：人物视线、身体朝向、道路、光束、透视和动作产生的方向。
- `low_entropy_regions`：纹理、对比和语义负担较低、可能承载文字的区域。
- `natural_axes`：地平线、墙边、桌沿、柱网、门框、透视线和物体排列形成的轴线。
- `depth_layers`：前景、中景、背景及其遮挡关系。
- `crop_risk`：换画幅时会失去的身份、动作、证据或平衡。
- `protected_evidence`：任何不得覆盖或生成替换的真实证据。

低信息区域不自动等于文字区。还要判断其形状、面积、方向和视觉重量是否能承受具体字块。

## 文字诊断

- `communication_job`：让观众停下、相信、理解、比较、记住还是行动。
- `semantic_relation`：单一判断、两方对立、时间过程、因果路径、系统关系、层级、并列案例或情绪旁白。
- `memory_anchor`：最应被第一眼记住的词、数字或结论。
- `text_load`：短（2–8 个汉字）、中（9–18）、长（19 以上或三层信息）。字数只作起点，语义断句优先。
- `hierarchy_count`：主标题、证据、副标题、身份、注脚中真正需要出现的层级。
- `reading_tempo`：瞬时、停顿、递进、往返、循环或慢读。
- `native_breaks`：依据意义和语气形成的断句，禁止为了填满矩形而随意换行。

## 图字空间的四种关系

1. **顺势**：文字沿底图已有轴线、视线或透视前进。适合流程、空间、行动。
2. **配重**：文字在主体另一侧形成非对称平衡。适合人物、物件和单一观点。
3. **嵌入**：文字进入墙面、纸张、屏幕、标牌或其他真实承载面。适合纪实证据与环境叙事。
4. **统摄**：文字本身成为最大形体，图像退为证据或反差。适合短观点、态度和数字命题。

默认不使用第五种“覆盖”：先决定一块不透明面板，再把文字与图像隔成两个互不相关的区域。只有内容本身存在明确分区或对立时，覆盖／分割才成立。

## 留白的七种职责

- **聚焦**：隔离主体，使其成为唯一中心。
- **呼吸**：降低密度与情绪压力。
- **方向**：给视线、动作、道路或阅读路径留下前方空间。
- **时间**：制造等待、停顿、距离与阶段感。
- **层级**：把主命题、证据与注脚分开。
- **边界**：表达内外、封闭、保护、压迫或越界。
- **悬念**：让未被填满的区域暗示尚未发生或未被说尽的内容。

留白必须能用一句动词说明其作用，例如“让视线前进”“把人物孤置”“给结论停顿”。如果只能说“显得高级”，说明留白尚未被理解。

## 选择原则

- 先匹配语义拓扑，再匹配图像条件，最后才选择表面风格。
- 一个作品只有一个主构图；第二构图只能辅助阅读，不能争夺中心。
- 一次只允许一种主要对比控制注意力。大小、明暗、色彩、动静、虚实不能同时全部拉满。
- 能用底图本身形成结构时，不再添加装饰性框、线、圆、标签或色块。
- 构图从一个画幅迁移到另一个画幅时，保留受力、阅读顺序和密度梯度，不保留原坐标。
- 如果选择结果无法解释“为什么不用另外两个候选”，说明判断仍停留在喜好而非设计。
