## 1. 画布与第一眼判断

竖版 3:4，满版摄影，无边框、无独立色块。第一眼是上方横贯画面的“0分贝房间”，接着看到在特殊房间里紧张互动的两个人与蓝色气球，再落到下方“没人敢 / 呆一晚？”的悬念。顶端标题约占画布宽 89%、高 17%，两人主要位于中下部，两行底部文案呈向右递进的台阶。

核心成立原因是：巨大标题命名一个反常空间，照片提供体验现场，人物动作使抽象的“安静”变成身体反应，底部短句让观众追问结果。标题本身不能证明场所真的达到 0 分贝，也不能证明没人敢过夜；跨内容使用时须有事实支撑，不能直接迁移这些绝对化结论。

## 2. 内容角色与有无判断

- 主标题：顶部“0分贝房间”，负责对象/条件命名，是第一文字层级。
- 主体：左侧旁观反应者与右侧操作/体验者。不是两张头像并排，必须共同参与同一个事件。
- 事件道具：中央偏右的蓝色气球，右侧人物用伸出的手接触气球上端；气球是两人关系的连接点，不是装饰圆点。
- 次标题/悬念续句：底部“没人敢”和“呆一晚？”，合起来形成一个信息单元。两行分别浅色与高亮色，后行右移。
- 辅助信息：原图没有署名、期数、标签、解释段落、品牌或 CTA，不应凭空加模块。
- 背景：从底部地面到顶端墙面的真实空间；大面积浅色吸音楔形结构形成重复、压迫和深度。背景就是事件证据。
- 装饰：没有独立贴纸、箭头、星芒或边框。可见斜向浅线主要来自墙面结构及标题半透明叠加，不能误拆成额外速度线。

## 4. 重心、主轴、阅读路径与密度

主轴是从上方大字进入人物事件、最后斜向右下落到问号。顶部横向字块和两侧暗色全身人物构成一个上横、两侧立的支架；右人物伸出的手臂将目光拉回中央道具，左人的朝向补充这条关系。

阅读推荐顺序：顶部空间命名 → 双人表情与手势 → 高饱和气球 → “没人敢” → “呆一晚？”。色彩敏感的观看者可能先看气球，仍应被动作关系导回标题和问题。

这是一张高纹理密度的现场图，没有大面积纯净留白。有效留白是两人胸腹之间、道具周围的未被文字占据的通道（约 x 27–49%、y 39–68%）以及顶部亮区。不要把这些区域填成说明文字。底部文字借相对均匀的灰地面落脚，避免与上方繁密楔形纹理平均竞争。

## 5. 素材处理、景别、透视和图层

原图视觉上是一张空间与人物统一的全身现场照片，未看到可靠的独立抠图边缘证据；不能断言其实际制作工程没有抠图。默认保留同场景底图，轻度裁切和曝光整理即可。拍摄点能同时容纳两人全身、上部大量墙面和底部地面；有广角空间感，但不能仅凭图像确定焦距。

人物后面是高密度墙面，中景是两位参与者及气球，近景是向下铺开的地面和底部文字。墙面交替横竖的楔形单元重复的是空间结构，不是人物复制。右手伸向中央，气球在躯干之前；底部字覆盖部分下肢边缘，主标题没有遮脸。

复建顺序：环境底图 → 必要的局部明暗整理 → 处于同一透视下的双人和道具及接触阴影 → 顶部标题暗色厚度/投影 → 顶部标题浅色字面及下缘渐隐 → 底部两行投影 → 底部两行字面。

若素材不足：先确认是否能得到双人全身互动镜头。已有两人但上方不够，可扩展不承载事实的墙面；脚部不足不可随便裁成半身。不同照片合成须抠发丝、配同一地平线、光向、尺度、足底接触阴影，并锁住身份与产品形状。不能把真实测试改成虚构互动或替真实场所增加不存在的吸音结构。无可用双人动作素材时判定不适配。

## 6. 字体与文字块

顶部字是高大、厚重、直立的展示型字形，粗黑体骨架为主，转折和撇捺保留中文书写结构；数字 0 比较窄长。字高约 15–17% H，紧凑排为一整条，不做逐字弹跳。浅色正面、向右下的深色厚度/阴影及下段透出背景共同产生空间标题效果。没有依据认定具体商业字体名称。

底部采用具有宋体粗细对比、锐利衬线和长撇捺的展示字，整体向右倾而非逐字随机旋转；“没人敢”约 3 字，“呆一晚？”约 4 字符，两行实际字高约 10–11% H。字间可见缝隙约 0.06–0.16 个字宽，行间可见空白约 2–3% H；保持短促、大字和向右推进的句形，不排成居中诗句。

顶端和底部不能共用同一普通黑体。现有切口宋体含额外设计动作，现有爆点黑体依赖大小跳动，均不等同于本图。分别登记 003 顶部展示字与 003 底部倾斜宋体的测试依赖；原图是来源参考，不冒充已批准字体样张。先生成透明文字层、核对字形，再合成。

## 7. 色彩角色与面积关系

原图以暖浅灰/米白墙面和中性灰地面为大底，黑色衣服形成两侧暗支架；白色文字负责命名及第一行提示，中央偏冷的高饱和蓝色道具提供事件焦点，右下偏暖的高亮黄色负责情绪收尾。

用于复建的初始可见面积预算为：环境中性色约 64%，人物及深暗阴影约 22%，浅色字面约 7%，单一道具强调约 3%，末行暖亮强调约 4%。这是近似角色预算，需在成图上复核，不是像素统计；各角色可 ±2 个百分点微调，强调色总面积宜控制在 5–9%。

不绑定白/蓝/黄的 HEX。可按新内容换具体色值，但保留“低彩度大底 + 两侧深暗主体 + 浅色命名 + 中央冷强调与右下暖强调”的关系。两处彩色焦点不得变成五颜六色全图。浅字在浅墙上仅靠色差不够，要用暗色投影/厚度分开；底部强调字也要和灰地面拉开明度。灰度和 360 px 缩略图均需验证。

## 8. 材质、光影、纹理与特殊效果

环境必须有能识别主题的真实结构和透视。参考墙面是浅色楔形阵列，边缘亮、槽内暗，带自然材质细节；地面是细密网格纹理。上方亮、下方偏暗，人物黑衣不应压到没有褶皱。气球保留曲面高光与轻微明暗变化，不做成平面色圆。

顶部字面可从上段 95–100% 不透明，逐步到下段约 45–65% 起试，使后方墙纹隐约穿过字脚；保留清晰字骨，不整行统一透明。阴影建议向右下偏移 0.8–1.6% W / 0.5–1.0% H，先紧后软；这是反推起点，原图并不能证明使用了真正 3D 挤出。底部投影更紧实，建议偏移 0.5–1.0% W / 0.3–0.7% H，轻柔边缘；不要加彩色外发光、厚白描边或贴纸边。

顶部效果服务于“字与房间相连”，底部效果服务于“短句从地面纹理中跳出”。这两种关系要分别验证。原图没有明显额外胶片颗粒或纸张叠纹，不新增脏污滤镜。

## 9. 适用内容、标题和素材条件

适合单一特殊空间、反常条件、一次现场体验或一个可视实验，且有两位参与者产生真实反应的内容。顶部 5–7 个中文等效字符，以原图 5 字为最佳起点；6–7 字需逐字检查字面宽度，无法维持字高时先改写；底部严格两行，第一行 3 字优先，第二行 3 字加标点优先。总量宜控制在 12–14 个等效字符，不增加第三行。长标题先改写，再进入制作。

不适合知识清单、多卖点商品矩阵、长引文、孤立证件照或必须展示多段解释的内容。照片需要清晰的头脸、可读的手势、单一中央道具与完整空间。即使文字摘去，观众也应能看出两个人正在经历同一件事。

原图之所以能在缩略图成立：上部大字说明事件，人体黑块区分左右角色，中央纯色道具在低彩度背景中单独显现，底部色彩变化把未完成的故事变成问题。它是叙事型封面，不是所有主题都要改成问句。

## 10. 跨行业适配、保留关系、失败检查

科技评测可用两名评测者围绕一件设备在真实测试场所操作；宠物内容可用主人与护理师围绕一只宠物，但动物仍是中央事件对象而非复制成两排角色；餐饮内容可用两位体验者围绕单一道菜，在可识别的真实厨房/餐厅互动；空间设计可用设计师与体验者围绕样板/测量对象，背景必须对应真实案例。不要把参考房间不加判断地复制给每个行业。

跨行业时保留顶部单行、左右全身角色、中央单物件、底部两行向右阶梯及两类字效；替换身份、动作内容、道具、文案和具体色彩时仍服从这些空间关系。环境可以换成行业真实场景，但需具有充满上半部的重复/纵深结构，不能改为纯色棚拍。无需添加品牌、价格标签或通用 AI 小人。

用于后续测试的完整新主题建议（本次未执行）：餐饮烘焙账号记录两位烘焙师在真实试验厨房的失败成品检查。顶部“蛋糕塌陷现场”，底部“差一步 / 就成功？”，中央放一只真实塌陷的小蛋糕；伸手检查者与旁观反应者共同围绕它，背景用真实层架/工作间纵深。它改变了行业、事件逻辑与素材，不只是替换名词。若没有这类真实素材，不能伪造为案例记录。

确认顺序：先确认上述 1–5 项空间与素材判断，再确认 6–8 项字效与色彩逻辑，最后确认 9–10 项适配边界。确认后才进入复刻测试；测试完成前不命名、不生成前台推荐说明、不上架。
