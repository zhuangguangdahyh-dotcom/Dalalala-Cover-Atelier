# 透明主标题层生成模板

输入：`exactText`（优先四字）、`canvasWidth`、`canvasHeight`、`textBox`、`fillRole` 和参考 020 原图。只生成中文主标题，在与封面同尺寸的真正透明 RGBA 画布上输出；不生成英文、人物、背景、棋盘格预览或装饰。

逐字保持标准汉字部件；再按参考塑造宽展的粗实笔、局部干刷露底、长短不齐的横画和有方向的尖锋。四个字合成一条强横带，视觉上相互呼应但不能粘连到无法识字；字高、边缘和内部刮擦不得机械重复。颜色由输入的高明度文字角色决定，不固定原图 HEX。不要用普通字库加统一污点、厚描边、阴影、发光或立体效果冒充。

生成后逐字核对、检查 alpha、360 px 可读性与原图字势。任一硬门槛失败则重做或人工复核，不静默回退。

修订硬门槛：四字大—小—大—小、两大字主体高度约为小字1.5–2倍，长锋下探但关键字骨完整。不得四格等大；内容不限制矿业。无已批准样张。
