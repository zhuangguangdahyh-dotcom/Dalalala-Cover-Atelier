# 020 中文主标题字形规则

参考字骨必须先逐字可读，然后再塑造手写力量。四字不是四个等宽等高的字库格：粗白笔画大面积成块，部分横画突然加长、撇捺向外或向下甩出；每个字的重心、笔端、飞白位置各不相同。短而细的干刷裂口只在局部笔画中出现，保留关键部件连接及完整识字线索。

这套字形比 `dalala-cover-010-ritual-brush` 的两字尖劈更需要四字连贯横带、粗白实面和横向刮擦；不能直接把 010 的两字规则拉长。也不同于 `dalala-cover-017-journey-brush` 较轻的行书化短句。字体只负责每字字骨、笔触和边缘，整条标题带的坐标、与人物距离、英文缝隙由 Cover Skill 决定。

填充保持高明度，具体白度随背景调整。禁止普通楷体、通用毛笔字、统一加粗、整层噪声做旧、黑描边、光晕、硬阴影、三维挤出；禁止为了飞白切断必须的汉字结构。当前是原图拆解出的待测字形假设，没有批准样张。

修订硬门槛：四字大—小—大—小、两大字主体高度约为小字1.5–2倍，长锋下探但关键字骨完整。不得四格等大；内容不限制矿业。无已批准样张。
