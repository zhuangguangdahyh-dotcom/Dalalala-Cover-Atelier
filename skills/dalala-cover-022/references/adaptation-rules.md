# 参考 022｜内容与素材适配

## 先判断能否使用

必须先确定行业、账号身份、这期要讲的完整过程、真实讲述者与结果承诺。上端短词应回答“讲什么”，下端 3 字左右回答“看完得到什么”；小字补充过程范围。三个文案槽位需同属一件事。人物要能自然正视镜头并作左右展开或上下承接的说明手势。单纯商品静物、多人合照、纯空间图或无流程承诺的观点内容不适配。

## 固定骨架

- 3:4；上白色手工粗字 x2–96%、y3–22%，拉丁/短系列词在左、两字中文主题在右；右上单行细注释 x55–94%、y22–27%。
- 人物头顶贴近 y21–22%，面部中心偏左；眼睛可读，身体延至底边。两只手向画面中右及右边界自然展开，中段 y27–72% 保留脸和手，不另加大标题。
- 下方暖亮实心粗字 x3–97%、y73–94%，覆盖前臂和躯干，底端还有约 6% 画高的照片尾部。字是前景，不做背景条。
- 暗中性实拍空间承字；人物、两组重字是主信息，右上副标题是次信息。保留轻微字影和必要时的柔亮人物边光，不增加图形贴纸。

## 素材诊断与转换动作

1. 标出身份/事实锚点：脸、双眼、嘴、双手、衣着或行业工具的真实形态。房间杂物、灰墙、床或门的具体样式可替换或弱化；不可为了排版改脸、改指头或伪造职业物件。
2. 先裁 3:4，检查头顶、两手与底部身体的关系。若手指靠边过紧，使用同场景扩图或换取景；不通过缩小人物腾位置。右上墙面需要低细节、足够暗，必要时局部压暗。
3. 优先保留完整实拍照片。只有人像和背景粘连时，做精确蒙版和柔边亮轮廓；光晕必须沿头发与肩自然衰减。上字只贴发顶，小字放在发缘右侧暗区，两者都避开面部。下方文字盖人物的下段袖子、前臂、胸腹与沙发；双掌和手指主体留在黄字上沿之前，不能重新抠出手掌盖字或把整只手压进字里。
4. 上主字、小字、下主字分别生成透明层，逐字核对。合成从后到前：照片 → 人物与柔亮边 → 上字软影 → 上字实体 → 小字软影 → 小字实体 → 下字软影 → 下字实体。小字与上字虽然有明确渲染顺序，空间上基本不交叉。字影在本组实体字下、照片与人物上；人物边光不得漂到黄字实体上。换素材发生手字碰撞时，先调整取景或手势回到参考安全带，不翻转底字层级。

## 文案、字体、配色

顶端建议 4–5 个拉丁字符或等宽短系列符号 + 2 汉字；若主题无需英文，可用有意义的短系列名，但必须保留左宽右短的面积。底端建议 3 汉字 + 感叹号；副标题约 9–11 个汉字含标点。超长时先重写，不压缩字骨、增加行数或扩张文字区。

主字角色绑定测试态 `dalala-cover-022-cut-display`，小字绑定测试态 `dalala-cover-022-casual-note`。两者只有来源原图，无批准字样。无法生成合格透明层时进入人工复核，不回退普通字体。

实际颜色依行业和素材重选：背景为大面积低饱和暗中性，顶字高明度近白，底字高明度暖强调，人物肤色自然，副标题与顶字同亮色但更轻。具体 HEX 不锁；要检查上下字对各自底色的缩略图对比。

## 可迁移的完整主题

- 烘焙博主：真实主厨在工作台前，双手分别指向准备与成品，顶部短系列名 + `烘焙`，底部三字结果词例如 `零失败！`，小字说明实际涵盖的步骤；道具仅在真实台面上出现。
- 工装设计师：真实设计师在灰调工地或样板间，正视镜头、双手介绍从勘察到验收，顶端短系列标识 + `工装`，底端三字承诺，小字说清阶段。不能用无关生活卧室背景冒充项目现场。

以上只是测试方向，正式文字需从真实内容提炼。至少用一例接近原主题和一例不同业态测试，验证横向字面、人物景别和内容逻辑同时成立。

## 拒绝条件

没有清楚正视人脸、双手残缺、场景过亮或太花、必须增加长标题才说得清、职业场景造假、底字不得不挪到人物下方、人物边缘只能靠硬描边分离时，停止套用此模板并选别的参考。当前拆解未确认，`renderAllowed=false`。
