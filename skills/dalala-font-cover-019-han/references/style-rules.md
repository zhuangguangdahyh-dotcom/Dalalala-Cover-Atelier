# 019 中文短标题｜字骨与字效

原图 `黑山` 位于 x59–90%、y22–35%，两字独立一行，字身直立、近方形，横竖粗实且接近等粗，端部偏平切、方硬。`黑` 的口形与下部间隔、`山` 的三竖和开口不能因粗笔堵住。两字紧排，但每字保持独立；视觉间距可从单字宽的约 0.08–0.18 试排。原图是暖亮的实心大字，边缘平整，没有拉丁主字的右倾和阶梯切口，也不靠厚描边或大阴影造块面。

新汉字必须守标准笔顺结构和部件关系。不能将普通字体整体拉宽/拉扁、几何拼片替代字腔或把两个字粘成图标。具体色值随当前素材与品牌改变，但保留“比承接面更亮、相对环境更暖、面积小于英文”的角色；承接面优先选较暗低纹理区域。字效以直接实填为主，局部对比不足可先处理背景明度，不能增加厚黑框、浮雕、霓虹或投影来强行补救。

输出真正透明 RGBA 字层，不含来源山坡或新背景像素。超出两三字容器时改写或换模板，不把字缩小成副注。
