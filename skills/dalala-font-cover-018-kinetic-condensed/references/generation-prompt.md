# 透明标题层生成提示模板（测试态）

在真正透明背景上只生成以下**准确文字**：`{exactText}`。角色：`{role}`；目标画布 `{canvasWidth}×{canvasHeight}`，文字外接框 `{textBox}`。依据参考 018 的高瘦几何中英展示字，中文逐字结构正确，笔画为实心平涂、相对均匀，局部尖切和折角，字距紧但每个字可辨；若包含英文，保持小写窄身并与中文同一横向节奏。填充用 `{fillRole}`。上方角色为一行超大字，下方角色为一行连续中英长字。只输出字，不生成人物、场景、阴影、描边、纸纹或底色。

生成后以原文逐字人工核对；一处错字、粘连误读或伪透明即重做。上字的遮挡与边缘裁切由 Cover Skill 合成阶段完成。
