# Source, truth policy, and scope

The visual references come from `nevertoday/350-layout-compositions` at commit `34dc39cb5128776b594754624fa2202d5942a35b` under CC BY 4.0.

The upstream v2 filenames and the titles visible inside the supplied images diverge for 336 of 350 entries. This skill uses the visible title recorded in `visual-truth-catalog.json` as the reference identity. The upstream path and claimed name remain in each knowledge file for audit.

All 350 source works are accepted as valid, designed references. They provide evidence for composition, content anatomy, hierarchy, typography, image treatment, colour roles, material language, and decoration.

`deepStudyStatus` measures the completeness of our local executable distillation. It does not judge the source design. A provisional item remains available for visual study and explicit inspection; it cannot be automatically selected or rendered until its anatomy, transformation grammar, semantic fit, and failure modes are complete.

A deep-ready rule is still distinct from a user-approved fixed production template. Fixed templates require real-content tests across title lengths, source materials, platform ratios, export, automated QA, and human visual acceptance.
