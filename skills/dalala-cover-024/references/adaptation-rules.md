# 参考 024｜跨内容重建规则

## 先把内容角色对齐

原图不是「任意大字盖在动物照片上」。它以真实环境说明命题，深色大主体给画面重量，两处小生命点给尺度，左侧大字给判断，右中英文给第二阅读层。开始适配前写明：行业、账号身份、主要判断、主体是谁或是什么、环境如何作用于主体、两个小尺度点为何真实存在。内容没有这条因果链时停用本模板。

中文主句建议十个汉字，按 2／1／2／2／1／2 的可读语义分组。允许改变每字的实际宽度和组内错层，但总包络、纵向推进、宽窄节奏不得漂移。标题过长先重写，不扩张 x12–57% 的主字区、不压右中英文，也不缩成等号字阵。英文必须是准确的短句或可信翻译，保留三行、中心对齐和次级权重；不能用随机英文补版。没有必要的署名、标签和 CTA 不新增。

## 素材与变形动作

1. 首选有真实环境纵深的 3:4 摄影。大主体应从下半进入并横贯右侧，约 x17–100%、y51–100%，左下有头部／动作或物件关键识别点，右侧允许出框。换成人、工具、建筑或产品时，仍须有同等深色横向重量及可信环境关系；禁止默认通用 AI 小人。
2. 身份／事实锚点：主体种类与结构、可辨动作、两个小尺度点与主体的接触或空间关系、真实环境特征、品牌或行业物件。自由区：裁切、景深、曝光、非事实性背景杂点和具体光色。不得因为套版裁掉主体关键部位、改坏产品几何或伪造接触。
3. T0 优先：原片重裁、低饱和调光；左侧过亮时 T1 局部压暗或扩大真实草场／环境；小尺度点缺失时优先重拍或选另一张真实照片，必要的 T2 合成必须有真实尺度、接触阴影与相同光向。T3 主题重构只有在事实与身份能锁定且结果仍像同一空间的摄影时才能进入后续测试。
4. 不做动物／人物悬浮抠图、重复主体、镜像鸟、夸张透视或将英文放在独立色块上。正文没有前景蒙版压字；字始终是平面标题，位于连续照片之上。背脊、鸟的站立点与头颈必须清楚。

## 不可变的图文空间

- 3:4；左侧中文字整体 x12–57%、y13–78%，顶部两字宽开、单字嵌入、中央双字错层、短字收束、底部双字再放宽。每组的边缘以 `anatomy.json` 为准，测试允许约 ±3 个百分点，重点看整个瀑布外形，不用简单等距栅格替代。
- 英文三行 x53–88%、y35–46%，在右中草场安静底上；不盖鸟和主体的关键轮廓。照片上方 y0–12%、右上 x58–100%／y0–34% 为保护留白。
- 深主体约占画面 25–35%，主要压在下半和右侧；中明低饱和环境约 55–65%；近白中文像素约 8–12%；英文约 0.5–1.5%；暖色自然点不足约 3%。这些是视觉重量参考，按实际素材校验，不硬锁具体 HEX。
- 层级：连续摄影底 → 轻微局部曝光调整 → 英文透明层 → 圆厚中文透明层。照片的软景深和主体表面纹理必须仍可见；禁止白字厚黑描边、发光或廉价贴纸影。

## 跨行业测试候选

- 自然／旅行：真实野外动物、地形和伴生小生物；主句讲地貌如何影响迁徙或生存，文字与画面事实相合。
- 商业空间：真实大尺度场地或施工状态，主物可为深色结构／设备，两个真实人物成为小尺度参照；主句讲空间条件如何改变经营动线。要保留横向深体块和右中空场，不用设计效果图强行贴小鸟。
- 餐饮／产地：真实田地与采收主体或大型食材载具，小尺度人物／工具形成尺度；主句讲风土如何改变原料与味道。若素材只有单品白底照，则不适配。

测试必须从中挑选与原图不同且逻辑完整的一例，另写真实标题与英文；仅换名词、颜色或同类牛照片不算跨内容测试。
