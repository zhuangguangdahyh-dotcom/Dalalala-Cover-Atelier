# 字形规则

- 字骨先保证标准汉字能读：必要的横、竖、撇、捺、点和部件位置不可因飞白损坏。参考原图是两个宽展巨字，单字既有大的粗白面，也有细长向外甩的尖锋；每字粗细和缺口位置不完全一样。
- 主方向是左上到右下的劈划与向外甩出的横斜收笔。笔触可有短的撕裂口、毛边、干刷露底，但空缺只出现在局部笔画，不能整个字均匀磨损。
- 两字允许局部笔锋穿入对方的空隙，保留可读字间界限。不把字排成两个等宽正方格，也不叠成一团不可辨的白色块。
- 原图的效果靠字形而非后期：不加粗黑描边、发光、浮雕、统一颗粒蒙版或长投影。填充为高明度，可依当前画面调整冷暖与具体色值。
- 本 Font Skill只负责字骨、笔触和边缘动作。封面中的字框大小、位置、色彩角色和与人物关系由 `dalala-cover-010` 规定。
