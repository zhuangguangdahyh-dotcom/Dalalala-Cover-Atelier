# 透明标题层生成提示模板

输入：`exactChineseTitle`（优先两个汉字）、`canvas=3:4`、`mainTextColor`、原参考图。只生成主标题文字，输出与目标封面同尺寸的真正透明 RGBA 图层；不得含风景、人物、英文或其他文字。

依据参考 010 的字形语法逐字塑造：巨大、横展、粗重的中文书写字，保留标准汉字结构；粗白实面和细长尖锋交替，笔画边缘出现少量非均匀飞白、裂口和自然干刷，两个字局部穿插但都能独立辨读。主标题保持单行两字；字形不要像普通字体统一加粗、旋转或叠噪点。颜色由输入控制；无描边、发光、投影、立体厚度、背景色或棋盘格底。

生成后按 `vitality-qa.md` 逐字人工核对。识字失败、透明失败或字体身份失败时重新生成，不能静默改用其它字库。
