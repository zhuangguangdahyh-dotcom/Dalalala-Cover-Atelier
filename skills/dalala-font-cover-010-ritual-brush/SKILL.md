# 010 双字锋利飞白字

先看 `../dalala-cover-010/assets/reference-original.jpg`，再读 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md` 和 `integration.md`。输入准确中文标题、画布和文字颜色，逐字构造可读字骨，再赋予不规则粗实面、飞白裂口、长尖锋和两字穿插；输出真正透明的单独标题字层。此能力 `status=testing`，无批准样张，不能声称复刻已通过，也不能回退普通毛笔字库、034 较细的干刷长句体或全图噪点滤镜。
