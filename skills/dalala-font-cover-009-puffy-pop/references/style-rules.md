# 字形规则

`solid-display`：接近软厚手写字而不是几何圆体。字芯实白/近白；笔画粗，字腔仍开，横竖粗细和末端有适度变化。每个字轻微独立倾转、高低错落，整体词组仍迅速可读。右上短喊可放大标点，底部两行第一行短、第二行宽重；这里定义字骨，不替 Cover Skill 决定位置。

`arc-outline`：英文大写字空心，白色清晰描线，字骨同样软圆，各字沿浅拱弧旋转，弧跨度约 35°–60°；不能改成直排小副标题。数字/汉字标题与英文字母按各自变体生成，不混用样式。

粉窄轮廓与黄硬影是封面合成特效而非字体固有 HEX。调整色值时必须保持浅字芯、高彩窄轮廓与右下同温硬影的对比和面积角色。
