# 拉丁字形规则

- 参考英文是端正高对比罗马衬线：细横、强竖、发丝衬线，字母宽度稳定。`OPEN BOOKS` 与 `SEE THE WORLD` 分别在左、右，均为大写；不能居中连为一行。字距轻微放松，仍保持完整词形。
- `NO.17` 比经纬度大且为浅暖色；经纬度为白色单行小字，度、分、方向字母与标点必须准确。跨行业时只能填真实坐标或改写成真实日期／现场编号。
- `Mongolia` 为首字母大写，地点词形宽约与上方中文地点块相近，字面比两段英文副题更大。实际大小及目标盒由 Cover Skill 的 anatomy 决定。
- 实色干净，合成时可用极轻短影维持天光上的可读性；没有笔刷、渐变、发光、厚描边或立体挤出。
