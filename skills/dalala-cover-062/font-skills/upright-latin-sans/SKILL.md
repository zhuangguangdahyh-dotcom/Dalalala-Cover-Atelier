# 062 顶部身份行字体 Skill（testing）

读取 `references/style.json`、`references/style-rules.md`、`references/generation-prompt.md`、`references/vitality-qa.md`、`references/integration.md`。对照 `../../assets/reference-original.jpg` 的顶行。仅用于真实品牌、工具、账号或项目身份；不得虚构合作方。此字体仍在测试态，不独立用于生产推荐。

按原文准确排成一行直立粗无衬线字。可用合法的常规字体渲染，不添加切角、手写、透视、描边或装饰。超过宽度时先删减身份文案，不机械压窄字母。
