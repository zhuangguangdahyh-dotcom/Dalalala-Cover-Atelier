# 062 硬切巨字字体 Skill（testing）

调用时读取 `references/style.json`、`references/style-rules.md`、`references/generation-prompt.md`、`references/vitality-qa.md`、`references/integration.md`，并查看 `../../assets/reference-original.jpg` 中的两行中文。仅单独生成透明文字层；此阶段没有通过复刻与用户验收，不得当作 active 字体。

先按标准汉字结构写准每个字，再在外轮廓作有限不规则切角与微倾。上行与下行同一字骨、不同颜色角色；所有字保留厚笔画和通畅字腔。不得用普通粗黑体加旋转或随机碎屑冒充。
