## 可转译的设计机制

以下为本工作台的工程化建议，不是原仓库提供的可执行配置：

- 负空间：记录 protectedRegions，限制主体或文字侵入；在缩略图检查主次，而不是机械增加空白。
- 模块系统：记录区域、间距、图层关系和可复用模块；可选副标题隐藏后，由 Skill 决定是否回收其空间。
- 固定网格：记录对齐轴线、区域边界与基线，不把教材示例行高当所有封面的通用数值。
- 阅读层级：在目标参考中核定第一、第二、第三视觉重点，再将字号比例、明暗和强调次数固化；不能仅从目录中的“视觉层级”标签推导规则。
- 一点透视：适合相关空间图的视觉分析，不应强加给人物或文字型封面。
