# 059 手裁纸块字（测试态）

读取 `references/style.json`、`references/style-rules.md`、`references/generation-prompt.md`、`references/vitality-qa.md` 和 `references/integration.md`。参考源图为 `../../assets/reference-original.jpg`。逐字保留正确汉字结构，生成不规则宽大白色实心纸字，再把两行字分别输出为透明层。每个字的边缘和切口独立变化；重复字不得机械复用。同版复刻需先通过汉字准确性、手裁边缘、字块体量和 360 px 识读检查。此字体未获用户确认，保持 testing。
