# 参考 010｜改编规则（研究态）

## 输入和语义映射

输入行业、账号身份、主题、2 字主标题、可选短英文译注、单一人物、头肩附近的主题识别物、可延向右侧的真实道具或形态、场景照片与平台。先判断行业是否确实拥有“身份/概念 + 人物 + 标志性实物”的叙事；道具必须提供内容证据。茶人可配采茶工具与叶束，建筑师可在真实场地手持测绘工具，户外使用者可配装备的展开结构。不能给任何行业机械套上羽毛、鼓或神秘符号。

## 锁定版式

- 默认 3:4。主标题在 x8%–94%、y5%–45% 的窄区间内，两字宽展、笔锋互入，上半幅占据主要视觉重量；不按均匀字盒排版。人物及道具联合外框约 x27%–99%、y42%–90%，身体深色核心约 x36%–78%、y66%–88%。
- 人物必须为背面或侧背中远景，保留头肩识别物；从人物附近向右的道具/形态约落在 x50%–99%、y52%–75%。替换品类可以，但要保留向右带出的视觉次轴。
- 英文短译注约 x45%–65%、y43%–47%，宽约画布 20%，高度约 4%；不得变成第二主标题。没有可信翻译时可用简短罗马字行业关键词，仍保持同一小字角色。
- 上部标题外、双字间、人物左侧和右上天空须保持低杂讯的可见空隙。底部约 9%–16% 用真实失焦地景收尾。标题过长先改写为 2 字；3 字需单独测试字面宽度和结构，不能扩张文字区、加行或缩成小标题。

## 素材改造触发

- **T0**：已有单幅可信摄影，人物、主题物、开阔天空和地景都满足骨架；只做 3:4 重裁、整体调色和透明文字合成。
- **T1**：实拍环境基本合适，但天空高频或位置不够；局部清理/扩充天空与边缘，保持人物和道具原貌及真实光向。
- **T2**：人物、道具、环境分图；先确认透视、遮挡、锐度、受光与景深可统一，再抠图组合。对细羽、绳索、枝条用局部精细蒙版；补接触暗部。涉及身份或产品时保留真实几何，不能伪造事实。
- **T3**：没有单一主体、可识别主题物或低杂讯上部空间；先补拍/重选素材，仍不满足则拒用此模板。不得用通用 AI 小人、无关器物或纯色板填空。

## 字体与配色依赖

主标题调用 `font-style-rules/registry.json` 中测试态 `dalala-cover-010-ritual-brush`，英文调用测试态 `dalala-cover-010-italic-note`；分别读取规则与原图，生成真正透明的字层，逐字核对。字体规则只定字形，位置、面积、字间穿插和层级由本模板定；不得静默换用 034 干刷字体或普通毛笔字。具体颜色可随品牌变化，始终保持低彩中间调摄影占绝大部分、高明度标题与背景强对比、深色主体压在中下部、暖色英文极小面积。

## 合成与验收

图层：连续的天空/山/地照片 → 人物装束及有内容关系的道具 → 近景自然虚草 → 透明中文标题 → 透明英文译注。原图未显示明确硬边抠图，合成素材须以可信摄影为目标。360 px 缩略图先读双字，再见下部背影及右伸物件；原尺寸检查中文字准确、飞白来自笔画而非统一脏纹、细线物体边缘、光向与接触影。新行业测试至少另换一套完整叙事与不同道具，不得只改人名、颜色和词。当前尚未复刻和用户验收，禁止 `active` 或前台自动推荐。
