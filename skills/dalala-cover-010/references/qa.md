# 参考 010｜测试与验收门槛

当前为研究态，没有通过复刻、跨内容测试或用户验收。先用接近原参考的内容校对结构，再以另一个行业的完整新主题测试迁移；不可仅换词或颜色。

1. 3:4 原尺寸：标题原文逐字正确，双字宽展但汉字结构清楚；飞白和尖锋属于笔画，不是全图统一噪点。中文和英文均为真正透明字层，无厚描边、强投影、立体挤出。
2. 主体：一位背/侧背人物在中下部；主题物在头肩附近，横向形态从中部向右展开。人物身份、物件几何、光向、透视和前中后景可信；抠图边缘不发白。
3. 空间：上部低杂讯天空支撑白字，仍能看到字间天空；下部远山、草地和前景虚化有深度。英文只占极小暖色面积。
4. 360 px 缩略图：无需规则名就能认出“上部双字、下部背影、右向道具”的骨架；白字先读，人物和主题物第二读。字与天空不能融成一片。
5. 新行业内容：两字主题、人、道具构成真实关系；不存在机械复制原参考符号的文化误读。若不成立，记录失败并重做素材或拒用模板。
6. 人工确认：用户确认最新 `analysis.md` 后才进入复刻测试；测试成品和跨内容样张再由用户验收。所有门槛未通过前保持 `analysisConfirmed=false`、`renderAllowed=false`、`status=studied`，不得 `active`。
