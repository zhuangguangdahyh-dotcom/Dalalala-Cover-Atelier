# 参考封面 045｜测试态 Cover Skill

调用前读 `references/manifest.json`、`references/anatomy.json`、`references/adaptation-rules.md`，并查看 `assets/reference-original.jpg`。状态为 `studied`；没有真实内容复刻、缩略图验收和用户确认，不得作为 active 模板使用。

## 输入与判定

输入行业、账号身份、主题、主标题、五张真实场景素材（一张为宽幅多人或主题现场）、一张可辨的产品或主题实物图和品牌标识。先确定一句可被画面证明的地点／生活经验／产品关系，再决定哪张图承担主场景、哪四张图承担局部证据。若没有真实、相互关联的素材，不得用通用人物拼贴补数。

## 固定生成语法

1. 建立 3:4 竖版深色去饱和环境底。街景、门店、工作场所或文化场景应与主题相关；压暗并加入受控网点／印刷颗粒，保证标题可辨。
2. 主标题构成三段纵向节奏：上部两大字，中部两大字，下部一枚超大收束字。字占画布宽约 64%–75%、高约 75%–82%；具体字数不合时改写标题，不增行或缩成普通字体。标题骨架由本模板 `font-skill/` 提供，先单独生成透明字层。
3. 金色宽扁折面笔画必须带窄高光、折痕、少量卷边与投影。四张不同实拍图分别进入上左、上右、中左、中右的字形开窗／字间开窗；下方第五张横向群像或主题场景图嵌入末字的横向开口。图与字相互穿插，不能做五张悬浮卡片。
4. 画面左上角是小型品牌锚点，右上角是小型录制符号或等权重纪实提示。中下部用两行白色小字解释主题，底部再放一行短收束句；右下角放产品包、工具或主题实物，前压末字和横图一角。
5. 按 `references/adaptation-rules.md` 进行行业语义转换；保留“地点／人群生活现场 → 可带走或可记住的对象”这类信息推进，但不复用原参考的品牌、城市和原句。

## 字体依赖与 QA

主标题依赖 `dalala-cover-045-folded-tape`；中部解释和底部短句依赖 `dalala-cover-045-neutral-caption`。两者均为本目录内测试态字体规则，调用时分别读取对应 Font Skill。不得把主标题替换为普通粗黑体加金色贴图。逐字检查中文、字腔可认、折带前后关系及照片开窗；在 360 px 缩略图检查主标题和中下方信息。照片与品牌应只用用户有权使用的素材。
