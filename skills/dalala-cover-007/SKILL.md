# 参考 007 Cover Skill

先从 `cover-skills/registry.json` 解析唯一原图 `参考封面图/dalala-cover-ref-007.jpg`，再读 [anatomy.json](references/anatomy.json)、[adaptation-rules.md](references/adaptation-rules.md)、[manifest.json](references/manifest.json) 和 [qa.md](references/qa.md)。本轮中文拆解见 `skills/dalala-cover-007/references/adaptation-rules.md`。分析尚待用户确认，不能把已写文件当成视觉测试成功。

## 调用输入与顺序

1. 确定行业、账号身份、异常主题、展示对象、可拍动作、局部证据；核实动作与特写属于同一因果链。
2. 选择 3:4 画布。短钩子 3–4 个中文等效字，现象名 4–5 个中文等效字；无独立副标题。标题过长先改写，不能改变行数和标题区。
3. 按 `anatomy.json` 固定左上标题、右中反应、左前景动作、右下越界特写的四点空间关系。素材不具备连续动作时先重构，无法成立则不使用本模板。
4. 从 `font-style-rules/registry.json` 解析测试态 `dalala-cover-007-punch-block`，分别生成透明的钩子行与现象行；逐字和字骨检查。蓝色概念符号、箭头与圆形边线分别制作，不混入字形层。
5. 合成后按 `qa.md` 检查原尺寸与 360 px 缩略图，并记录真实测试。未确认、未复刻、未验收时保持 `studied`、`analysisConfirmed=false`、`renderAllowed=false`。

## 核心机制

高亮现象名先抢视线；真实反应让“奇怪”有情绪；前景动作说明事件正在发生；右下圆形近景回答“到底奇怪在哪”。暗底留出视觉通道，白色箭头只把前景动作导向特写。任何一处变成无关摆拍，模板的承诺与证据就断开。

人物、道具、产品、文字和具体色值是可变内容；构图骨架、各区占比、标题层级、圆形越界、动作与证据的前后关系，以及标题暗边/浅晕、箭头、特写边线等标志性效果须保持。禁止用普通粗黑体替代测试字体，禁止添加副标题或前台文案，禁止复用原图的行业对象作为所谓跨行业测试。
