## 1. 画布和第一眼

第一眼读到顶端几乎顶满整行的荧亮黄色「万赞爆款封面」，第二眼看到创作者本人把一张倾斜的内容卡片递到镜头前，第三眼落到底部白色的「3000粉 → 3万粉」。这是一张“本人展示证据，并给出增长结果”的封面。有效的钩子不是单靠黄字，而是标题宣称、手持卡片里的具体内容、底部前后数字彼此印证。原图比例 0.7501；复刻基准为 1080 × 1440，禁止直接把这套空间拉成横版。

## 2. 内容角色与各区间

- **主标题**：「万赞爆款封面」是主题与结果承诺。约 x 6–94%、y 2.5–16%，单行，字高约 12% 画布高，文字几乎填满可用宽度。顶边留 2.5–3%，左右各约 6%。黄色在全黑上形成最强反差，层级第一。
- **主体人物**：真人半身至近全身，约 x 3–56%、y 17–69%；脸在 x 13–30%、y 23–37%，低于标题，位于左上视觉重心。画面右侧的手臂向镜头伸出，手在 x 40–72%、y 24–39%，制造近大远小；画面左侧指示手在 x 4–29%、y 41–52%，指向卡片。人物黑衣与背景近色，脸和两只手比躯干更亮，层级第二。
- **展示物 / 内容卡片**：一张放大的仿社交平台内容卡，约 x 16–92%、y 28–89%，整体顺时针旋转约 16–22°。白色卡边从画面右侧持卡手附近向右下贯穿；卡片下缘斜插至底部数字上方。内容是“证据对象”，不是普通配图。卡片自身分成黑色图像区约上 55–62%，白色信息区约下 38–45%。
- **卡片内标题与样例**：黑色图像区上沿的黄字「AI带货视频」约占卡片宽 80%、高 12%；下面是三人场景，中央人物重复出现为内容关联锚点，左右两人辅助说明；前景手持写有「用 Skill 批量生成」的大纸牌，展示制作能力。这些字属于卡片内部内容，应按新行业改写，不照搬原话。
- **卡片内信息**：左上小眼睛与「537197」显示观看量；白底上两行深色说明文字；下部头像、账号名、日期、红心和「4.6万」模拟真实内容反馈。约占卡片可见面积 20–25%，作为可信度证据，缩略图不要求逐字阅读，但数量级、图标位置与平台卡片观感要成立。
- **辅助提示**：左下空场的白色手写「2分钟 get 同款」及向右下弯的箭头，约 x 3–20%、y 66–82%。它把阅读从人物和卡片导向底部结果；是第二口吻，面积约 4–6%，不能抢主标题。
- **底部结果**：白色「3000粉」在 x 7–48%、y 89–98%；粗白右箭头 x 47–64%；「3万粉」x 66–94%。两组数字沿同一基线，合计占宽约 87%，承担结果对比。这里的“粉”与数字一样厚，非小字号单位。
- **背景与装饰**：近黑至深灰的棚拍背景，全幅铺底；人物背后有从灰到黑的柔和光斑，左下比上沿略亮。独立装饰只保留手写箭头、卡片白边和底部箭头，不额外加贴纸、光圈、花线。

- **副标题**：原图没有独立的封面副标题。卡片中的黄字是“证据卡内部标题”，左下白色手写是辅助口吻；两者不能被抽离成常规副标题并挤入顶部。

## 3. 几何骨架、视觉重心、阅读路径

画面沿纵向分成三段：标题 y 3–16%；人物＋卡片 y 17–89%；结果 y 89–99%。中段是斜对角交叉：人物身体从左上至左下稳定画面，卡片从中部向右下倾斜，占主体视觉面积约 42–48%。右上 x 73–100%、y 16–36% 保留深色空场，给近景手势和卡片上角呼吸。左下 x 0–19%、y 60–73% 也留空，容纳手写提示。视觉主轴先横向扫过顶部黄字，再沿画面右侧近景手和卡片的斜边下滑，进入卡片案例，最后由左下手写提示与卡片下缘汇向底部左右数字。主体、人手、卡片不平均居中；几何不对称才让“递出证据”的动作成立。

## 4. 素材改造与真实空间关系

人物最好实拍或以身份参考生成：镜头略高于人物面部，身体斜向画面右侧；画面右侧近景手抓住卡片上沿，画面左侧手指向卡片。近景持卡手约为脸宽的 1.3–1.7 倍，指尖须明确压在卡片边框前方。人物上半身与卡片要分别抠图、遮挡：背景最底；人物身体；卡片主体及轻微投影；持卡手指回到卡片前面；指向卡片的另一只手在卡片左侧前景；顶端黄字和底部结果在最前文字层。卡片是一整张透视四边形，不是直立矩形贴图旋转；两条长边朝右下延伸，远端适度收窄，边框厚约卡片短边的 1–1.8%。内部图像和白底信息必须同透视，人物的指尖、卡边和掌心接触处不可穿帮。人物脸、主标题、卡片内关键画面和底部数字各自完整露出；允许卡片遮住身体，不允许遮住脸。若输入照片没有符合的持卡/指示手势，必须重新拍摄或在身份保持前提下重建姿态，而非硬贴一只无主手。

## 5. 字体与文字块

主标题是单行、超粗、宽扁的黑体切块字：端点平切，笔画近等粗，字腔偏小，局部有短的切角/断接，少量字可有轻微宽度变化，但基线平稳。字面几乎相互贴靠，字符间距约 0–2% 字宽；没有统一描边、立体挤出或明显发光。其目标是“厚重得接近图形”，而非活泼跳字。底部结果沿用相近的厚块骨架，白色，数字尤其宽而稳；结果组与组之间以粗刷状白箭头分隔。卡片内黄标题仍是重黑体，但受卡片透视影响，字形局部略窄。左侧手写提示是白色快写笔触，笔画粗细与倾斜不规则，中文两行和英文 get 串成一句，箭头同笔触，约 2–3 行且不占据底部数字区。卡片信息区则是清晰常规无衬线，字重中等，行距约 1.15–1.3，仿平台内容层级而非另一块封面标题。

## 6. 颜色、材质与光影

面积关系：深色背景与人物黑衣合计约 48–55%；卡片白底和边框约 19–25%；卡片内照片约 15–20%；亮黄标题及卡片黄字约 8–12%；红心及其他彩色点缀低于 2%。亮黄充当结论与卡片题目，白色充当结果和真实平台界面，肤色是情绪温度，红色只作平台互动提示。可换具体色值，但需保持“低明度大底＋高明度单一强调色＋大块白卡＋少量暖色皮肤”的关系。背景是柔和棚拍渐层，无明显纸纹；人物皮肤和头发保留摄影质地，画面右侧持卡手受近景光照更亮。卡片保持干净白边、轻微接触阴影和真实透视，不能变成悬浮霓虹屏。黄字与白字为实色，主要靠明度对比出画，不靠厚描边或大投影；卡片内部摄影有暖光与局部景深，形成“真实发布内容”的证据感。

## 7. 为什么成立、适用条件

上方一句话给问题或结果，中间真人把完整内容证据递到观看者眼前，下方用可感知的数字变化收尾。观众无需先读懂卡片的每个小字，也能看懂“此人做出某个内容成果”。适合创作者复盘、案例拆解、运营增长、设计前后对照、工具工作流成效、专业服务案例，但必须有可展示的一张真实结果卡或可视化凭证。标题建议 6–8 个汉字且单行；超过时先重写，不压扁到无法识字或改成两行。底部左右结果各宜 3–6 个字符，形成清晰的“前 → 后”。至少需要一位清楚露脸、具备手部动作的人物和一张层次真实的证据卡。没有可信证据的泛观点内容不适合。

## 8. 跨行业转换与边界

按“账号身份—结果主张—可交付证据—量化变化”替换。例如设计师可用「改造爆款空间」＋本人递出完整项目发布卡＋「0咨询 → 30组咨询」；餐饮主理人可用菜品发布卡和订单反馈；律师或咨询师应以脱敏案例摘要、获客结果或公开内容数据替代涉及客户隐私的画面。卡片内部人物数量、原稿文字、具体平台数字可随新故事变化，但始终是一张被人物递出的内容凭证，保留卡片黑图像区/白信息区的上下关系与旋转透视。人物身份、服装、文案、案例图片、具体色相可变。锁定单行满宽主标题、左人右卡的空间重量、双手与卡片的因果动作、左下手写引导、底部左右数字跃迁以及高明度强调与深底的明暗结构。

## 9. 失败模式与检查

失败：只放一张平板截图却没有手指接触；人物摆拍与卡片无关；卡片压住脸或完全挡住主标题；卡片内容直接照搬 AI 带货/原人物；底部数字与中间案例无因果；黄字被做成荧光发光体；全部字用同一个常规黑体；左下手写变成硬字体贴纸；内容区塞满难读小字；只调标题位置而不改人物手势、卡片透视和背景空间。

检查：① 360 px 宽缩略图中可读主标题与前后数字，能看出人把一张卡递到眼前；② 脸、两只手、卡边的遮挡顺序一致；③ 卡片透视和内部图文同步；④ 主标题、卡内黄字、底部数字各处字形准确；⑤ 内容证据与结果表达相符；⑥ 替换行业后保留上中下三段与对角动势；⑦ 经用户确认前仅保持 studied，禁止进入 active。
