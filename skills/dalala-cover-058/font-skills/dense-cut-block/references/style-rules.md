# 字形规则

原图顶部黄字并非普通黑体放大：每字接近画面高度 12–14%，横向压得很紧，笔画极厚，局部端点是硬平切或短缺口；字腔小但仍可读。整行如一条连续的黄色厚块，个别字的宽度、横画伸出略有变化，整体基线不跳动。底部白色数字和汉字沿用厚实的同一家族，数字更宽稳；卡片内标题是较小尺寸并随卡片透视变形。不要给每字加同样缺口或统一破损纹理。通过文字块的体积、密排和黑黄/黑白对比成立。

单字应以规范汉字结构为先。个别字需要局部硬切时，只在不影响识字的端点或接合处做 1–2 处；避免把内部字腔切没。卡片标题先在透明正面平面生成，再整体投影至卡片图像区；不要让单字各自旋转。底部结果保持水平，箭头作为独立粗笔形状生成。
