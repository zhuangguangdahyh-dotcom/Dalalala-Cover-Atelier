# 透明字层生成提示词合同

输入：`titleExact`（必须逐字复制）、`canvas`、`titleBoxPercentXYXY=[4,7,96,33]`、参考图、背景明度角色。只生成一层四字优先的中文主标题 PNG，背景必须真透明 alpha。

提示：以参考 029 顶部文字为唯一字形依据，按准确汉字结构绘制粗厚近白实心字。四字单行占画宽约 90–94%，字形既有整体稳定横向块面，也有逐字不同的切边、端点、转角、字腔与轻微重心变化。字间保留窄暗缝，笔画无明显纹理、描边、阴影、发光、立体感。不得生成任何副标题、Logo、装饰、人物或背景。若输入标题过长使字块变窄，应返回不适配提示，先改写文案，不能缩小模板主标题。
