# 字形规则

参考是白色实心中文巨字，笔画厚而较直，但不是标准字库黑体：每字的端点、转角、字腔和竖画宽度有独立变化。整体以单行近满幅的白色块面压住暗背景。字块要先保证常用汉字结构，再形成手切／手画感；不追求毛笔飞白、油漆泼溅或故障裂纹。

- 单字大致占画宽 18–27%，四字间形成窄而可见的暗缝。
- 字高可有约 10–25% 的相对差异，基线轻微起伏；整体仍形成稳定的横向巨块。
- 横画与竖画不要求机械等宽，端点可平切或微圆钝，局部外沿轻微外鼓／内收。
- 保留标题准确可读。重复字也独立生成，不复制同一个字形贴片。
- 独立真透明文字层；最终色值可按封面色彩角色微调为近白，但不能改成低对比灰字。

禁止普通黑体加粗／扭曲、统一噪声蒙版、镂空、描边泡泡字、重阴影、伪三维厚度和每字完全相同的字面高度。
