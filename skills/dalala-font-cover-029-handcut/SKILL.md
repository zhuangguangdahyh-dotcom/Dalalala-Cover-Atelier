# 029 顶部手作白字

从 `font-style-rules/registry.json` 解析 `dalala-cover-029-handcut-white`，读取 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md`、`integration.md`。视觉证据为 `../dalala-cover-029/assets/reference-original.jpg`；无已批准的字体样张，状态 `testing`。

输入完整、已确认的中文短标题和目标文字盒；先保证汉字结构和逐字准确，再逐字生成厚实不规则笔画，输出真 alpha 透明字层。与 `dalala-cover-029` 的画面几何绑定，但字体 Skill 不决定人物、背景和装饰。QA 未通过不得静默换普通字体。模板未获用户确认前仅供测试准备。
