# dalala-cover-051（studied）

本 Skill 的视觉依据是 `assets/reference-original.jpg`。调用前读取 `references/anatomy.json`、`references/adaptation-rules.md`、`references/manifest.json` 和本任务 `analysis.md`。当前未测试、未获用户验收，禁止自动推荐或按 active 生产。

## 调用流程

1. 判断行业、账号身份、主题及画面主角正在做的具体动作。选择一张可承载叙事的真实环境近景：主角坐于画面中下部，头部约在中央偏左，视线向右下的纸张、作品、产品或工具；自然环境包围，背景仍可辨场所。
2. 在 3:4 满幅照片中定好头、手、承载对象、背景亮区。主角约占画幅宽 70–85%、高 82–95%，头部约 x30–75%/y11–47%，动作对象约 x42–100%/y48–76%。保留上部植物或行业环境形成的自然背景，不把人物做成棚拍贴纸。
3. 锁定双层字：上部一行宽阔拉丁手写展示字，约 x9–90%/y2–39%；下部一行松散中文手写展示字，约 x5–96%/y64–86%。两组共享鲜亮冷色、近等粗的自由笔势，但英文更连写、中文更放开字间节奏。中间 y40–64% 让脸与动作保持可读。
4. 使用 `dalala-cover-051-mint-freehand` 测试态字体依赖生成透明文字层。先生成英文和中文两层，再合成；逐字检查文字、笔画、回环、与人物五官及动作对象的遮挡。
5. 在原尺寸及 360 px 缩略图核对：先见上部大字与人物，再读下部中文，最后看到纸张/对象。自然光、环境深浅、手写字三者保持同一观看节奏。测试跨行业内容、字体 QA 和用户确认后才可申请变更状态。

## 固定与可变

人物、文字内容、行业对象、环境和具体色值可换；需保持单张满幅自然摄影、中央偏左的沉浸式人物、向右下聚焦的视线与手部动作、上英文下中文双横带、同色自由手写字和无底板叠字。标题过长先改写，不增加行数或缩小字块。禁止把原图的读纸情节当成所有行业的默认故事。
