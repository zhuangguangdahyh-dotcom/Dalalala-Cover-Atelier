# 051 双语鲜亮自由手写（testing）

读取 `references/style.json`、`references/style-rules.md`、`references/generation-prompt.md`、`references/vitality-qa.md` 和 `references/integration.md`，并对照 `../../assets/reference-original.jpg`。这是从参考拆解得到的测试态字体规则，尚无获批样张。不能作为通用 active 字体使用。

先锁定逐字确认的英文单词与中文短语。分别生成两张真正透明的文字层，再叠到同一封面；两组共用颜色和笔触性格，但不能强行让中文按拉丁连笔结构变形。文字错误、中文结构错误、笔迹太规则或缩略图不可读时重做，不回退普通字体。测试并经用户确认后才可提交注册状态变更。
