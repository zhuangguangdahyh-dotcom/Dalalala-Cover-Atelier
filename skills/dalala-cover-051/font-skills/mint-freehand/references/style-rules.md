# 051 双语手写形态规则

## 共同笔触

参考图上两组字是单一高亮冷色、实心不透明的自由书写层。笔画近等粗但有速度造成的轻微粗细和边缘变化；局部收笔细而长。不要整齐描边、投影、油漆飞溅、毛笔式重提按或统一颗粒贴图。两组字要像同一位书写者在同一张照片上写出，但不能复用相同字形骨架。

## 英文角色

一行单个词，适合约 7–10 个字母。字块约 x10–89/y2–39%。第一个大写字母有大回环，占上部字块约 1/3 宽，并升至 y2–5%；后续小写字连笔向右推进，字母 x 高明显低于首字母，基线轻微波动；尾笔形成有目的的上挑或下甩。不能用现成签名字体一键输入，字母连接处要符合真实笔顺和速度。

## 中文角色

一行 4–6 字，字块约 x5–97/y64–86%。汉字先保持正确结构，再让字高、字宽、倾角和字距有选择性地不齐；首字可大幅起笔，中间 1–2 字偏紧，末字可长收势。不得每字都同幅度夸张，也不得让图形替代关键字腔。笔画可以在邻字空隙穿插，但逐字可认是硬门槛。

## 配色与底图

只为两组文字设一个同色强调角色，具体色值随画面调整。文字要与叶片、头发、衣裤和纸张局部都有可读对比；先调底图的局部明度或换强调色，不添加底板和厚轮廓。笔迹中可有极轻微自然边缘毛糙，避免均匀数码路径感。
