# 透明字层生成提示模板

输入：`exactText`（逐字确认）、`role`（latinDisplayTitle 或 chineseDisplayTitle）、`canvas=2160x2880/3:4`、`accentColor`（两层相同）、参考原图。

英文层：只画 `exactText`，一行，透明背景。参考 051 上部的巨大自由连写：左侧夸张首字母回环，中段紧密但清晰的自然连笔，末端长收势，整个外框约 x10–89/y2–39%。实心鲜亮单色，轻微笔速差与手作边缘，不加阴影、描边、光晕或其他字。保持每个英文字母准确。

中文层：只画 `exactText`，一行，透明背景。参考 051 下部同一支笔写出的松散大字：外框约 x5–97/y64–86%，字高和字距自然不等，少量长伸展笔画，汉字骨架完整且逐字可认。颜色、笔触与英文一致；不作拉丁式机械连写，不加任何其他图形或字。

分别出层后先在中性棋盘背景验真正 alpha，再叠原尺寸封面检查。不能把照片内容烧进文字层，不能自动改写输入文字。
