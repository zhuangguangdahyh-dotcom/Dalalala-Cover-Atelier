# 051 字体 QA｜测试态

硬门槛：输入与输出逐字一致；中文结构正确可辨；真正透明背景；上下同色同笔触性格；上字不压眼口，下字不切断手与对象的关键关系；360 px 缩略图仍见英文大回环和中文一行的字块。任一失败需重做。

逐项按 0–20 记分，总分至少 85/100：

1. 英文首字母回环、连笔节奏、尾笔自然且各字母可读。
2. 中文每字有真实书写动作，高矮宽窄有选择性变化而不散乱。
3. 两组字笔画近等粗但有速度，边缘不呈完美矢量管线或统一噪点。
4. 上下字块落在目标范围，保持中部脸与动作的安静区。
5. 同色强调在深浅照片区域均可读，未靠底板、厚描边或发光补救。

本字体尚未有通过测试的样张；这个分数门槛只规定后续验证方式，不代表已通过。
