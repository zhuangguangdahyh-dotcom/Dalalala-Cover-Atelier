# 参考 014 暖色视频字幕

先读 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md`、`integration.md`，复看原图。`badge` 是右上较细、直立的中文受众标签；`screen` 是手机内两行紧凑粗斜拉丁短字幕。同属暖色文字角色和短红色偏移影，但不把两者硬套一个字重或倾角。输出逐字准确的透明文字层，不画手机或视频。

状态 `testing`，`approvedReference=null`，`productionApproved=false`。不得以普通系统斜体或系统黑体静默替代。
