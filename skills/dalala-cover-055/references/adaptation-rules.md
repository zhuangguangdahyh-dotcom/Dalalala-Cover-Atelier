# 055 适配与重建规则（测试前版本）

## 内容映射

先确定行业、账号身份、主题与展示对象。将原图的“喜欢的画风 → 做成 skills → 四种画风样例”抽象为“一个集合或痛点 → 明确的转换动作/结果 → 四个互不重复的真实案例”。为四张卡分别写一句内容说明，再生成卡图；内容说明之间若只是同义词，先重做分类。

## 固定骨架

画布 3:4。x0–100%、y0–12% 为更黑顶栏；白色一行引题在 x5–72%、y3–13%；暖亮色一行主标题在 x17–99%、y15–27%。四卡占 x0–100%、y33–72%，标签贴合各卡上边，按亮、亮、暗、亮排列。正面真人从 y60% 向下出血，脸居中，双手在 x≈15% 和 85%、y≈81% 上托。卡片边缘被人物头部少量遮住，不能压脸。保留暗底大空区，使四卡与人物各自分开。

## 素材改造语法

1. 人物照有双手外摊且手指完整：去背景、修发丝/眼镜/衣袖边，裁成胸腰景，置于底部。没有动作时重拍或受身份约束地重构姿态；不能把两只手贴到普通头像上。
2. 四张素材先各自放入卡片，保持主体可辨。画幅不符时优先内部裁切或扩图，保留产品、界面、场景核心事实；必要时放大局部。四卡可以是产品、书页、菜品、案例、空间或真实结果图，必须同属一个标题的四种例子。
3. 左右卡向外倾，中央两卡轻微相向；只做轻旋转与短软阴影，不做厚白贴纸框。中央卡的下缘进入人物头发后方；人物始终在前。
4. 标签一一卡顶对应，跟随卡片角度，但保持独立可读。主标题与四卡上沿之间保留约 5–7%H 暗区。
5. 标题过长先改写。保持引题一行 5–7 个汉字、主标题一行 2–3 个汉字加 4–7 个英文字母/数字或相当宽度的短结果词。严禁压缩字宽或增加标题行数。

## 色彩与字体

具体颜色按当前品牌、素材和情绪选，但保持低明度冷底、近黑顶栏、高明度暖色行动字、白色引题/标签、卡片亮—亮—暗—亮节奏。标题使用 `dalala-cover-055-rounded-monoline` 测试态字体能力：引题与主标题同源圆头手写，标签为同源细笔变化。制作透明文字层，逐字检查中英结构。当前字体未经过实测及人工批准，复刻阶段必须做字体 QA，不能默认作为生产字体。

## 禁止与验收

禁止将四卡改成整齐四宫格、让单一卡盖住人脸、让人物手掌朝下、把标题换成粗黑体或普通圆体、在暗底添加大量星点/霓虹、复制原参考卡片/人物到其他行业。验收时看 360 px 缩略图：一眼是否能读到行动字、数出四张卡、看懂人物在托举；再放大查中文正确性、卡图真实内容、抠图边缘、人物与卡片遮挡关系。拆解完成不代表可生产，需后续真实主题测试和用户确认。
