# 049 拆解后的复刻验收清单

- [ ] 参考图与归档图 SHA-256 一致；设计未照搬原图文字、城市或商标。
- [ ] 3:4 全幅实景一镜空间成立，远景身份锚、中景横向构件、近景活动同属主题。
- [ ] 中轴与标题区的比例符合 anatomy；近景模糊不压字，标题下方仍能看到横向连接线。
- [ ] 主字一行大写衬线，副字一行无衬线；文字内容、字骨、字距、行距和透明背景通过字体 QA。
- [ ] 具体色值适应素材，但冷／中性远景、暖光点、浅字／暗中景的明度关系保留。
- [ ] 360 px 宽缩略图里先读出标题，再认出地标或空间，最后读到人的现场动作；副标题仍能辨认。
- [ ] 近源复刻与不同主题测试均完成，用户确认后再上架；未完成时保持 studied/testing。
