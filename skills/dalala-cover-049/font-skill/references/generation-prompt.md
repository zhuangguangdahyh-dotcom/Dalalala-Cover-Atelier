# 透明文字层生成提示词

输入：`role`、`exactText`、`canvasWidth`、`canvasHeight`、`targetBoxPercent`、`colorRole`、049 参考原图。只生成单独透明 RGBA 文字层，不包含城市、桥、行人或背景。

当 `role=mainTitle`：严格逐字生成 exactText 的一行全大写英文，直立宽展的高反差罗马衬线字；真实细横与薄衬线，平直基线，光学紧排，实心浅色。整行放入目标框，不自动换行，不加纹理、立体、外发光、描边或投影。

当 `role=subtitle`：严格逐字生成 exactText 的一行全大写英文，端正中性无衬线，常规至中等字重，轻微疏字距，水平居中，实心浅色；无任何效果。

输出前后都逐字符核对；错字、漏字、误加空格、透明通道不真、字体角色混用或字框越界即重做。
