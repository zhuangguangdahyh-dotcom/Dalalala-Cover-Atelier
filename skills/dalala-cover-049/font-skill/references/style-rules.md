# 字形规则

## city-roman／主标题

端正大写罗马展示衬线，直立而宽展，粗竖与细横有明显反差，横画和锐利薄衬线仍要在 360 px 缩略图中保留。`S` 与 `G` 开口清楚，`A` 腿脚稳，`H` 两竖有支撑感。原图不是厚重老式碑刻、极窄现代刊头，也不是斜体。参考 `SHANG HAI` 整行的平稳水平基线，采用光学紧排，字间仍可辨；目标整行宽为画布 43–52%，字高 5–7%。实色浅字，边缘干净，无描边、凹凸、金属、发光、笔刷和大阴影。

## city-sans／副标题

一行直立大写的中性无衬线，常规至中等字重；与主字不同家族但基线稳定。字高约画布 1.7–2.3%，目标行宽 21–28%，字距 0.02–0.09 em，不能排成夸张稀疏的时装品牌字标。副标题水平中心与主标题中心差不超过画布 1%，顶边距主标题下缘约 0.6–1.5% 画布。颜色保持浅色同角色，无描边、投影、底板。

两个角色均先写对，再做视觉；标题过长先改写，不强压或增加行数。光学细节需用真实新标题做测试后才能批准。
