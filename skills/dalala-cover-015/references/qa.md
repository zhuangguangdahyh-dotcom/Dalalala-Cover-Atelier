# 参考 015 复刻检查

1. 3:4 中上方一行主字宽约 86–92%W，英文引题在其上；标题下的开放空间和下方深色实体仍形成两种清楚字底。
2. 小主体位于中心附近的实体边缘，画布占比约 1–3%，动作方向与接触/阴影可信；360×480 缩略图仍能找到它。
3. 右侧大体块、左侧次体块与中距锚点提供纵深；没有把参考降级为“蓝色背景＋红字＋贴图人物”。
4. 底部身份标识两行紧叠，旁边仅一枚同高强色符号。没有原图游戏名称、伪造品牌、价格、CTA 或额外说明。
5. 中文宽硬字骨与稀疏字内磨损、英文上方旧式衬线和底部厚重字块分别通过对应测试态字体 QA；中文逐字正确。
6. 颜色可换，但明场域、中景层次、暗前景、强色主字、高明度英文的面积与对比保持。粗描边与大投影不能掩饰不合格背景。
