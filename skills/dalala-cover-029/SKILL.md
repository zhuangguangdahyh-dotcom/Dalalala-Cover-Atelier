# 参考 029｜测试态调用规则

状态 `studied`；`analysisConfirmed=false`，`renderAllowed=false`。本 Skill 对应封面参考 `dalala-cover-029`，不等于 `layout-029`。先读 `assets/reference-original.jpg`、`references/anatomy.json`、`references/adaptation-rules.md`、`references/manifest.json`、`references/qa.md` 和 manifest 指向的中文报告。不得自动推荐、生成正式封面或上架。

1. 判断行业、账号身份、主题和展示对象。选择一位与主题相关、能与镜头建立联系的真人；手中小物或明确手势须能证明主题。无合适真人、短标题或暗场环境时停用。
2. 保持 3:4 连续满版人物照片。主标题为顶部近满宽的四字单行白色手作巨字；人物腰部以上居中，眼睛约在画高 38–40%，脸、手、主题物形成中轴。画面上部暗、脸部可辨、下部有低对比空间。依 `anatomy.json` 控制标题、人和小物的面积与遮挡。
3. 前景保留两段分离的粗手绘开放曲线与少量浅色点缀的视觉职责：从两侧暗区引向人物下方，制造环绕和速度感。每次根据新人物轮廓、手势、道具和背景负空间重新画线；原图的曲线坐标只作观察证据，不可描摹。保持双段、开放断口、收尖、同色、避开眼鼻口、道具及标题；不能画成一个闭合椭圆或实体绳索。
4. 主标题依赖已有测试态 `dalala-cover-029-handcut-white` 字体 Skill，按注册条目读取规则并单独输出真透明文字层。文字准确且笔画完整，不能静默换普通黑体。无副标题、CTA、价格或新信息牌。
5. 优先使用 T0 实拍裁切和局部控光；必要时 T1 清理干扰或向上同透视扩图。照片、人物、道具保持真实。合成后向前的顺序：连续照片与局部修复 → 浅色点缀 → 白色标题 → 新绘制的两段曲线。白字可少量压住帽顶，不得被人物修复层反盖；曲线与文字不相交。点缀与曲线的相互遮挡可按新线条位置重定，但须自然可信。
6. 具体色值随主题和素材改变，保持暗底、最亮白字、次亮面部、单一中饱和运动色和少量浅色点缀的明度及面积关系。按 `references/qa.md` 在原尺寸和 360 px 缩略图检查。用户确认拆解后才可做结构复刻与跨行业主题测试；最终验收前不能变为 `active`。
