# 参考 029｜可迁移设计语法

## 锁定的视觉关系

3:4 满版暗场单人实拍；顶部一行几乎铺满画宽的白色手作四字；中央脸—手—小物形成动作链；两段同色、开放且有宽窄变化的手绘曲线在人物两侧和下方形成运动环绕；两枚小面积浅色点缀补节奏。曲线的作用、数量、笔触、层级、与人物的避让关系固定，具体路径随新主题重画。不要把原图蓝线当成必须原样复制的矢量资产。

## 空间与内容合同

- 标题外接约 x4–96%、y7–33%，四字单行；每字约 18–24% 画高，字间暗缝约 0.5–2% 画宽。仅支持四字已分析规格；3 或 5 字须另测，长题先改写。
- 单人腰部以上中景，占中部约 50–60% 画宽；眼线约 y38–40%，脸中心约 (48%,43%)，躯干延伸至底边。真人身份、衣服、表情可换，但不得变小全身或多人拼贴。
- 小道具或手势在嘴下至胸前，通常约 6–12% 画宽；与行业主题、真实握持关系一致。它是动作证据，不是第二个大型产品主视觉。
- 前景两段曲线主要活动于左右侧和 y42–75% 的中下区：一段接左侧暗场与人物下方，另一段从右侧暗场回引至手或躯干附近。两段之间保留约 10–22% 画宽的可见开放缺口。允许曲率、端点和覆盖衣服的位置跟着人物姿势改变；不得照搬原图路径，也不得穿脸、穿道具或穿标题。
- 右中浅色实心点、左下空心四角星是原图的点缀角色；适配时可按动线在各自象限内微调 3–6 个百分点，不能放大成主角、堆成贴纸雨。圆点与右侧曲线是否相叠由新线条的合理走向决定，不能为模仿原图强造交叉。
- 暗底及暗衣约 60–68%、可辨人物中亮约 17–24%、白字约 11–15%、曲线约 2–4%、浅色点缀约 0.5–1.5%，按互斥着色面积归一化；不是外接框面积。具体色值可变，维持暗底/最亮字/次亮脸/清楚但不抢脸的运动色。

## 素材诊断与重建

先标记脸、发型、年龄感、肤色、表情、手指、握持和产品几何等事实锚点。背景家具、灯点和无关文字可降对比或清除。优先裁成连续照片；缺顶部暗区时只在能维持光线透视的条件下扩图，否则换素材。不默认整人抠图换纯色。人物和现场保持同一相机透视，文字与手绘装饰是画布前景平面层。

为新主题画线时，先定标题、脸、物三块保护区，再在两侧负空间选起止点；用两段不等长开放曲线引视线回人物。笔宽中段约画宽 1.2–2.2%，端部自然收尖，局部有手作起伏。可调整弧度、走向和手臂前方的覆盖范围，使其呼应当次动作。最终缩略图需要读到“被运动线围拢的人”，但不能认出原图那两条线的逐点轮廓。

从后到前合成：实拍与局部修复 → 小点缀 → 独立透明主标题 → 手绘曲线。标题在照片和帽顶前，少量压帽顶但不遮眉眼；任何人物补丁不许反盖字。曲线与标题分区，避开脸与道具；若曲线经过圆点，遮挡方向由新画面决定并保持一致。星与曲线可相邻，不必强制相交。

## 跨行业角色转换

- 工装设计师：本人在真实工作现场持一块小材料样板，四字主题聚焦一个明确选材判断；曲线沿身体两侧引到样板附近，不能盖住材质。
- 餐饮主理人：真实店内持一份小样或食材，四字主题讲一个具体做法；背景保留店面证据，曲线从工作台暗区包围人物与食材。
- 心理咨询师：本人在咨询空间持简短笔记卡或做克制手势，四字主题表达一个可执行判断；曲线不要暗示医疗仪器或伪造资质。

以上均为待测试方向。必须按行业、身份、主题、展示物重新建立完整语义，不能只替换几个名词。

## 停用与失败

多人并列、全身远景、纯产品静物、明亮杂乱背景、必须展示长解释或大量价格信息时停用。标题变双行、字体变普通黑体、照片变纯色抠图海报、道具与行业无关、曲线复制原图精确轮廓、曲线闭合或随意多画、曲线穿过脸/文字/事实锚点、点缀抢过人物、白字被帽子反盖，均判失败。未通过真实内容测试和用户确认不得生产或上架。
