# 033 手写字规则（testing）
源证据为 ../../dalala-cover-033/assets/reference-original.jpg；尚无批准样张。只仿字形语言，不复制原题。
粗实心自由手写汉字，长纵画与宽展横撇捺并存，局部宽度起伏和细碎毛边；不能用普通字体＋颗粒实现。笔内大体饱满，仅少量自然断口。emphasis 两个汉字一横块，单字高约 26–30%H，字间最近边距约 1–3%W；continuation 单列六字与尾标点，单字约 9–13%H，字间外缘距 0–2%H。字宽各异，骨架清楚，不能整列旋转。颜色由调用方提供，字效无描边、投影、底板、立体挤出。毛边尺度 0.1–0.3%W 是待校准初值，不能做全局脏污。
