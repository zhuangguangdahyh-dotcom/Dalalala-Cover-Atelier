# 031 字层 QA

硬门槛：每字准确；汉字结构正确；拉丁大小写和数字正确；真 alpha；无多余文字或图像；按指定角色和单行文字盒输出。任一失败不得合成。

1. 顶部汉字是否方角超重、字腔仍开放，360 px 宽还能读清？
2. 重点拉丁词是否比汉字明显高、带适度手切动作，却没有变形到误读？
3. 右下黑影是否硬朗、方向一致？没有柔光、霓虹、金属渐变或多层贴纸效果？
4. 左下数量锚点是否在同一行中突出且边界清楚？
5. 白底结果行是否仍是一块紧凑字组，黑描边有力但不堵字腔？
6. 原尺寸与 360 px 两档对照原图，顶部、数量和结果字的权重阶梯是否成立？

目前没有批准参考样张，结论最多为“可进入人工复刻测试”，不可标注已验收。
