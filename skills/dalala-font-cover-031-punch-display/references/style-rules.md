# 031 字形规则

原图 1086×1448：顶部汉字是方角、近等粗、字面饱满的超黑展示骨架。笔画端点多为平切，重心稳、字腔小但不堵死，不能用圆角泡泡字、普通无差别加粗黑体或带飞白的毛笔字代替。字距约为字宽 −2% 至 +1%，全行近满宽。

`Ai` 是特殊重音：比邻近汉字高约 1.2–1.45 倍，A 的斜边和 i 的点有手切不规则性；大小写、字母数量必须完全遵从输入。非 `Ai` 的新短词也要保持“更高、手切、实心、可读”这一角色，不强行写成 `Ai`。

顶部字面是单一高亮实色，封面合成层另加右下深色硬影。影子偏移约 1–2% 画宽、0.6–1.2% 画高，边缘清楚；不做模糊辉光、金属渐变或等厚外描边冒充体量。

左下第一行缩到顶部汉字高度约 55–65%，仍需厚重、紧凑；选定数字/短词约比邻字高 15–30%，可用白色实心，但要通过黑影保边。最后一行在独立白色矩形上，黄亮实心加黑色重描边，允许个别字轻微倾斜或上下弹跳，整体仍是一条紧凑可读的线；描边约为画宽 0.3–0.6%。

所有角色先单独生成真透明层，文字盒和行数由 Cover Skill 锁定。颜色值随当次主题选，但亮主字/深影/白底条的角色不变。透明层中不得混入照片、随机装饰、伪字或白底条。
