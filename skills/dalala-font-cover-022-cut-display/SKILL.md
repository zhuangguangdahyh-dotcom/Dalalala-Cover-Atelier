# 022 粗切展示字｜测试态

先查看 `../dalala-cover-022/assets/reference-original.jpg`，再读 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md`、`integration.md`。输入准确中英文字、用途、画布、字框和颜色角色。每个字独立形成透明字层，逐字检查字腔、笔画、英文拼写及小图可读性。白色上字与暖亮下字是同一字骨的两个色彩角色。尚无批准样张，不能用于正式生产或回退普通粗黑体。
