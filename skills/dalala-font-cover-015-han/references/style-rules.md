# 中文字形规则

参考字约为 5 字单行，整体约占画布宽 90%、高 17%。骨架是极厚、横向舒展、低重心的硬边展示字：横竖笔画宽重，撇捺也以大块面结束；内白不应因为加粗而闭塞。字间略紧，但各字仍独立清楚。局部笔画边缘有非规则切口，字腹内有稀疏到中等密度的黑/透底斑点，密度不均，有些字更粗粝，有些区域保持完整色面。斑驳像户外印刷掉墨，不能统一撒在整张图上。

每字按标准汉字结构绘制，笔画连接与部件位置准确。生成尺寸以成品画幅为准，字距约 -0.05–0.02 em；不要把普通现成字体横向拉伸。填色取当前封面“高饱和主强调”角色；原图红色只是视觉证据，不是固定色值。字层须真透明，以便在不同场域上合成。标题过长先改写成 4–6 个字，不能通过压扁、换行或挤出边界解决。
