# 纸面手写字结构

这套字承担外部白字。`lead` 用于“我的/技巧大公开”类较细的小字；`core` 用于极大的 `Vlog` 类核心词；`promise` 用于右侧类别及底部四字结果。三个变体属于同一位作者的笔迹：略不齐的基线、局部直线与手画弧线、开阔字腔、不同字有不同的起收笔。细字不能变宋体，粗字不能变规整黑体。

`core` 在参考中约占 42–47%W、22–26%H，拉丁笔画粗细不一，`g` 类下伸部可压住手机上沿；即使替换成中文短词，也要留可执行的向下笔势或局部越界关系。字内可有少量纸刮边，不可把统一噪声贴满字面。`promise` 要宽松但不散，四字结果约占 55–62%W，一行。白色是高明度角色，色值由本次封面配色决定。阴影由合成阶段加在字层下方，不内建背景。
