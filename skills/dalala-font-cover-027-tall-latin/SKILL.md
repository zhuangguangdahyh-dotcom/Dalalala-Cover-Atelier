# 参考 027｜窄高拉丁测试字体

从 `font-style-rules/registry.json` 解析 `dalala-cover-027-tall-latin`，读取本目录 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md`、`integration.md`。证据是 `../dalala-cover-027/assets/reference-original.jpg`，尚无批准样张。

输入左右准确拉丁词、目标盒与颜色角色，分别生成真 alpha 文字层。左右同基线、同高度与字重，保持窄高衬线和轻旧印刷细节。不得静默使用普通窄无衬线体。
