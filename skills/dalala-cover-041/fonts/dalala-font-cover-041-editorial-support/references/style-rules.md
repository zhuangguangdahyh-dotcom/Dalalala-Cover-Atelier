# 辅助字形规则

- 副标题用中等字重、端点平直的现代中文无衬线，一行放在 `x 4–50%, y 47–51%`。原图约 32–38 px / 1263 px 画宽；字距约 0.08–0.18 em。它说明大标题的利益点，不复制大标题圆点材质。
- 角落栏目字、右侧词列和左下小注用同族感的窄身至中性英文大写无衬线，常规字重、字距约 0.12–0.25 em。页眉和小注只负责编辑结构，词列更浅、更弱。
- 中英两个角色的笔画都平整、清晰，无描边、发光、颗粒和厚阴影。副标题下方的强调色手划线另层绘制，不算字形一部分。
- 如果实际文本溢出既定框，先改写；不可压窄字形、减小到手机上读不清，或占据主标题与影像区。
