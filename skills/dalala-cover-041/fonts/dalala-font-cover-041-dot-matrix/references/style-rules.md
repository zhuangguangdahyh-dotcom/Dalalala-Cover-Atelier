# 字形规则

- 英文、数字、汉字、标点使用同一种近圆实点语法，但分别按正确字骨落点。画布宽度为 1263 时，点径起点约 14–19 px，圆心距约点径的 1.05–1.25 倍，留有稳定的白缝。
- 英文主要是几何圆弧、水平/竖直点列与开阔字腔；中文保留横竖撇捺、转折和框内空白，笔画相遇处可轻微调整点位，但不并成整片黑面。
- 每个点允许轻微圆度、墨量、落点差异；整体行基准与字符结构仍稳定。不是统一颗粒滤镜，也不是散点装饰。
- 三行分别落在封面规定的字框，视觉左齐。首行高纯色、下两行深色，第三行终止标点回到首行强调色。具体色值可改，角色关系不改。
- 单独绘制透明层，逐字符核对，再进行行级间距和标点位置调整。原图第三行 `CarPlay了！` 的 `了` 不能误成数字 `7`，还须检查叹号点、中文框字和字腔。
