# 参考 041｜复刻测试质量门槛

1. 原尺寸：点阵标题每个字可读，圆点分离；文字、数字和标点逐字正确，无漏点造成的错字。
2. 结构：三行左齐、行宽扩张；上部干净浅底与底部实景暗场相接；前景核心物遮住一部分后景执行物，但双方都可辨。
3. 色彩：高纯强调只用于首行、终止标点和少量划线/圆点；深色文字与底部场景形成主要视觉重量。具体色值按主题选择。
4. 360 px 宽缩略图：第一眼认出点阵大字，第二眼看出下半部正在发生的具体工作；副标题仍能辅助理解，辅助英文不抢焦点。
5. 内容：原品牌、商标、界面和语句不复用；跨行业测试要是完整新主题而非几个名词的替换。
6. 状态：拆解确认、近题测试、跨行业测试、字体 QA、用户验收逐项留证。此前不可标记 active。
