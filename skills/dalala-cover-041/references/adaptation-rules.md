# 参考 041｜适配与重建语法

## 先定语义槽位

输入必须说明行业、账号身份、主题、行动发生的具体场景、前景要让观众看见的“结果或入口”、后景要证明的“执行过程”。原参考分别由车机屏、后景笔记本和道路构成一条链。跨行业可以用其他器物，但必须让观众看出同一件事从入口到执行；不默认使用车、笔记本、通用 AI 人物或原品牌 UI。

## locked｜固定骨架

- 3:4 画幅；高明度干净上部约占高 52–60%，自然过渡到下方深色实景。可见暗场约占画面 30–38%。不得将照片满铺至主字背后，也不得用硬边横条把上部做成说明卡。
- 三行大型点阵从 `x≈4%` 左齐，依次约 `y 11–22% / 23–33% / 34–45%`。首行较短、第三行最长，整体右沿向外扩张；第三行末尾留独立高纯色标点。源图第三行是 `CarPlay了！`，其中 `了` 是汉字；生成新标题时不得用数字 `7` 替代。保留离散圆点字形与强调色/深色的首尾关系。字框占比锁在解剖规则的小范围内。
- 副标题位于 `x 4–50%, y 47–51%` 单行；其下有一条红色细手划线。上方小页眉左右呼应，右上词列、竖线和渐疏微点提供低权重技术感；右中手写短句与红弧线为语气层。
- 下半部“远景环境 / 后景执行物 / 前景核心设备或结果”三层深度必须成立。前景从底边大裁切，约占下半幅主要宽度；后景在右侧露出足够内容，不能完全被遮挡。
- 阅读先看红色标题首行，再看黑色标题与红叹号，然后是利益句，再进入前景屏幕和后景执行证据。细小栏目字允许第二轮读，不改变主阅读路径。

## adaptive 与 optional

- `adaptive`：标题原文、行业对象、场景、可辨设备/商品/工具、屏幕显示内容、手的身份与动作、具体色值。适配时保留相对面积、景别、位置与遮挡。具体强调色可变，但维持高纯小面积与深色主体信息的对比。
- `optional`：右侧微点密度、辅助英文词列、轻微远景雾化。隐藏辅助信息时保留原位置的空白，不回收给主标题。
- 不适合只有抽象观点、无可展示动作或证据的题材；可先设计真实视觉证据，做不到就不用这套模板。

## 素材改造等级与触发

1. `T0` 事实锁定：标出品牌、人物身份、产品结构、真实屏幕内容、场景安全事实。不得凭构图改动这些锚点。
2. `T1` 裁切和净场：已有前后景关系与浅底时，重裁为前景设备从画面底部越界、后景设备在右侧露出；清理主标题背后的高频细节，保留真实环境氛围。
3. `T2` 扩图/分层/换景：源图上方没有足够浅底，扩出约 50% 以上干净区域；若前景设备、后景线索和远景不在正确层次，分别抠图、校透视与光向，再重叠合成。屏幕要有合理反射、亮度和实际 UI 层级。
4. `T3` 重建场景：无可用的“入口 → 执行”双证据或原视角无法调整时，重新拍摄/生成与行业事实一致的场景。禁止为凑模板把无关设备拼在一起。
5. 主标题单独生成透明层：按本模板圆点字体 Skill 拼点，逐字核对英文、数字、中文、标点，尤其核对 `了` 的字骨。副标题和微型英文按 `dalala-cover-041-editorial-support` 分别排入原字框，手写短句按独立候选字形核查。将汉字笔画复杂度控制在手机缩略图仍可读的范围。标题过长优先改写，不压缩点径、增加第四行或占用右侧注释区。

## 失败与检查

- 失败：普通字体叠圆点滤镜、字点过密粘连、上下照片硬切、暗景侵入主标题、前景和后景并排平铺、红色范围过大、手写注释变成第二标题、把原商标/软件界面当模板默认素材。
- 检查：三行的左齐及宽度扩张、每个点的分离度、标题全文准确、浅底占比、深色场景层次、前后遮挡与透视、红色面积、360 px 缩略图识读、跨行业主题的完整因果。通过拆解不代表已通过复刻测试。
