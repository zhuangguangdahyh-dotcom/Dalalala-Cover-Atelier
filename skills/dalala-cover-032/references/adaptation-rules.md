# 参考 032 的内容迁移规则

## 先把主题转换为三个角色

1. **疑问**：一条有真实解释价值的因果/反常识问题，拆成“短问句 / 条件或变化 / 结果？”三行。参考只是海拔与气温，跨行业不能只换两个名词。标题先改写到上窄下宽的行宽，再生成字层。
2. **见证者**：具有明确账号身份的真实人物，表情与问题的情绪相符。该人物右偏近景、在照片里举出证据；人物可以替换为医生、设计师、户外研究者、产品测试者等，但不默认用通用 AI 小人。
3. **可读证据**：与问题相关且视觉上可核对的工具、样品、记录或测试结果，落在 x34–56%、y46–61% 的前景槽位，手与物件真实连接。原图屏幕可读出约 −18 °C，只是参考图里的内容；新主题的数值必须从新素材核对。若主题不需要证据物，另选模板。

## 素材诊断与处理

- **事实/身份锚点**：脸与自然表情、真实职业身份、手与道具接触、仪器/物件几何及显示的数值、能证明场景的环境线索。不要生成不存在的数据。
- **构图自由区**：背景杂物、上方暗空间、局部雾层、色温、衣服非身份细节、裁切和两枚语义插画。为文字留空间时可压暗或扩展背景，但延续原场景的光向、景深和纹理。
- **T0**：素材本来就是右偏近景、向前举物、上方暗而清楚。裁切、色调、局部对比即可。
- **T1**：同一照片的顶部/左侧空间不足。扩图、清理背景、局部抠人重排；脸和手物关系保持原样。
- **T2**：有同一人物和真实证据，但景别和前举角度不合。受控重建近景透视与场景连续性，核对手指、设备和读数；不改事实锚点。
- **拒用**：只有平视证件照或产品孤图、没有可读证据、设备显示不可核对、素材清晰度不足以识别脸或数字。此时换素材或重拍，不能凭空做测试结论。

## 布局、颜色与特效合同

- 画面比例固定 3:4；三行标题约占上方 42% 高，左边缘逐行略外伸，行宽约 45% / 74% / 79%。人物明亮体量在右下，手和证据物伸至中部。标题与人物在第三行下沿相接，不能变成上下彻底分离的字板与人物卡片。
- 具体配色随品牌与题意选择；保留深低饱和环境大底、亮主标题、稍低一档的亮人物、小面积主题装饰。原图的“冰霜”是特殊效果的类型示范：换主题时，后两行仍应带节制的主题材质微纹理，第一行相对干净、笔画边缘仍为细暗边。
- 两枚插画各对应问题中的一个关键语义，维持 x2–18%/y10–23% 与 x79–94%/y5–16% 的左右重量。不得加第三枚同等重量图标或撒满符号。
- 人物、标题、证据物的前后遮挡按 anatomy 执行。原图帽沿接近右端问号；新素材仅在确有自然交叠时用真实前景蒙版恢复，不为追求层次硬造遮挡；不可把问号、脸或设备切碎。

## 跨行业测试与退出条件

先做一版靠近原题的结构复刻，再用与高山气温无关、内容逻辑完整的行业主题做第二版。记录行业、账号身份、三行标题、证据来源、T 级别、色彩角色与两枚语义图形各自作用。检查标题去掉后，人物举证动作仍能解释主题；图形去掉后，文字与人物主结构仍成立。任一版没有可读证据、三行失去宽窄节奏、人物移出右下、字形换成普通字体、或 360 × 480 缩略图只剩文字而认不出举证动作，均为失败。用户确认前保持 `renderAllowed=false`。
