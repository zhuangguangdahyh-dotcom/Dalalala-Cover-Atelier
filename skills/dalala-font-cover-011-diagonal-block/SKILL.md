# 011 主标题字体依赖（testing）

按顺序读取 `references/style.json`、`style-rules.md`、`generation-prompt.md`、`vitality-qa.md`、`integration.md`，并查看注册表 `sourceReference` 指向的原图。输入准确标题、上组或下组角色、画布与目标区域、当前配色角色；逐字构成透明层。字形和字块都要按原图核对。没有确认样张，不能声明字体已验收，也不能静默替换为普通粗黑体。
