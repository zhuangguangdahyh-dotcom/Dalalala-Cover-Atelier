# 036 双语极窄主标题测试规则

证据是参考 036 顶部拉丁短标与中文主命题。未知具体商业字体名称，不声称已经识别字库。两块共享“高耸、极窄、单色、无附加字效”的家族气质，但分别保留不同语种的结构。

`latin` 为 3–6 个字符的高挑展示字：整体高度约为平均字宽的 2.2–4 倍，长纵笔稳定，弧线与收口可有轻微软化或外撇，不能变成普通无衬线窄体。大小写按真实名称保留，不自动全大写。字距约单字宽 5%–14%，不能挤成连续栅栏。

`cjk` 为 4–6 个汉字的极限压缩展示骨架：字高约为平均字宽的 2.2–3.2 倍；主纵笔高耸，部分横画细而短，撇捺或转角可做三角切口、楔形外伸和非对称收笔。每字只允许 1–3 个结构动作，标准部件、重心和字腔必须完整；不能先用普通字体再水平压缩。

两种变体都使用调用方提供的单一 `accentRole` 实心填充，无描边、阴影、渐变、发光、浮雕或纹理。输出真实透明背景。字形的窄来自重新构造骨架，不是把笔画压到粘连。
