# 参考 008 手写字骨架

同一位书写者写两档字：`fine` 是右上“P人/无痛/出行”和右中旁白的细圆头随手字，`display` 是底部两行放大的粗圆笔字。两档都保留柔软略弯的横画、圆钝起笔、不同字宽、轻微高低起落、开放字腔和清晰标准汉字结构。不是工整字库排版，也不是毛笔、油漆刷飞白、铅笔灰或卡通泡泡字。

- `fine`：近等粗，笔宽目测约字宽的 `4.5%–9.5%`；右上单字较大、每行两三个字左右，字距自由但不互相粘连。三行在同一右侧窄带略错位，整体仍清楚；右中小字的中英文和标点要像同一只手写，不可用规整英文无衬线字体替换。
- `display`：同样圆头与自然笔势，但笔宽约字宽 `11%–19%`，实心且字腔开放；笔画长短、字框宽窄与轻微倾角各字略异。底部第一行较短，第二行更大且近满宽。不要给每字统一旋转角度或刻意做乱。
- 两档只生成文字本体和准确笔画；颜色是输入角色，不锁死原图奶白与蓝色。主标题的右下硬色错位影由封面合成，不属于本字体本体，也不能做成全周描边。
- 对含数字、英文的短句逐字符校验：`1` 要直而略长，`P` 字肚开放，英文小写连接自然，问号/感叹号仍可认。重复字不得复制同一个字形贴片。
