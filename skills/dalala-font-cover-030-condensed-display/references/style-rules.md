# 字形规则

- 骨架为直立、极窄的工业无衬线大写英文。主词像一道黑色横墙，笔画粗而字内白腔仍可认；竖画偏厚、水平端点基本平切。
- 主标题字距紧至约字宽 0–2%，不相碰。词组整体目标宽高比约 3.4–4.1:1，落入封面 x17–84%、y29–47% 的盒内。过长的词先改文案，不压扁或缩成细字。
- `identity` 同字骨但约主词高度 25–30%，可略松字距；`environment` 用同字骨的巨字，保持浅灰低对比，再由封面层做顶面、侧墙、地面的透视。
- 主词以深色实心为主，允许极轻的灰影像/磨损在字内变化；不得把字做成大面积透明、描边、金属 3D、胶囊圆角或综艺跳字。
- 这一规则只决定字形及三种文字角色的相似性；封面中的透视、遮挡、面积和空间次序由 Cover Skill 决定。
