# 透明字层生成提示

输入：准确的大写英文短词、目标文字盒、角色 `main-title | identity | environment`。以 `../dalala-cover-030/assets/reference-original.jpg` 为测试视觉证据，生成真实透明背景上的单独字层。

`main-title`：一行、极窄极重、直立、平切的工业无衬线大写字；黑实心，白腔清楚，字间仅留窄缝。字内可有极轻暗灰照片感，不能降低轮廓可读性。不要人物、鞋、背景、透视、阴影、描边或额外文本。

`identity`：同一窄重字骨的小尺寸清晰大写字，字距稍松。`environment`：同字骨大字的低对比灰色/细条纹填充，仍输出平面真 alpha 字层，后续由封面规则放入透视空间。

必须逐字准确；无法正确排出字母或透明通道时返回失败并进入人工复核，不以近似伪字代替。
