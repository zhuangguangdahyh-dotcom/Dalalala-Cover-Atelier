# 字形规则

- 标准汉字结构优先。保持高对比宋骨：厚竖/斜画与细横有显著粗细差，字腔开阔，撇捺端部有清晰的锐收和有限延展。它是平面展示字，不是毛笔、水墨、硬黑体或默认宋体直接放大。
- 每字可有 1–2 处略超常规字框的横挑、钩、撇或捺，服务四角外向张力；不得为了“设计感”扭曲偏旁、掐断必需笔画或让字变成抽象图形。
- 字面宽高约 0.95–1.1；四字各自完整，边框可因下排贴底产生轻微裁切，但主要字形与识字部位不能缺失。四字视觉重量接近，不要对某一字加粗描边或特殊花纹。
- 输出单色实心、硬净边缘、透明底图。没有描边、投影、三维挤出、渐变、噪声、飞白、金属质感或柔光。
- 生成只负责字形。四角位置、人物避让、色彩角色和近边裁切由 Cover Skill 控制，字体规则不复制布局合同。
