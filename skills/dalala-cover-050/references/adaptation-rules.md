# 050 适配规则（拆解待确认）

## 固定语法

- 竖版 3:4。单人坐姿或稳定上半身近景居中，头部约 x29–72/y10–46，肩胸扩至 x7–89/y45–100；面部眼鼻口保持无遮挡。四个超大汉字分别在左上、右上、左下、右下，近似形成一圈开放的字框。左上/右上为上半句，左下/右下为下半句；两行各两字，阅读顺序为左上→右上→左下→右下。
- 角字均为同一浅亮色、同一高反差宋骨/刀锋式字形。单字框约占画幅宽 22–26%、高 22–25%；下排底边可贴近或轻微切出画布，四字不可变成上方整行或居中标题。面部两侧保留呼吸通道。
- 暖暗大面积室内背景与深色人物服装托起肤色、字色。肖像是第二视觉焦点，四角亮字与面部形成互补：先读命题，再看是谁提出命题。不能用几何色块、贴纸或产品卡替代这一关系。
- 下部中央可放一枚低权重、细线手写感账号标记，宽度约 18–24%、高约 4–7%，只承担来源标识。没有可靠署名资产时可空置，不把原图署名照搬成新账号标记。

## 素材改造与触发

1. **T1 裁切/净场**：已有单人胸像、目光方向和柔和侧光时，先按脸高与肩宽重裁；清理四角刺眼杂物，保留真实空间渐变。
2. **T2 分层/扩图**：头顶或左右不足以容下上排字时，保留身份锚点（脸、发型、肤色），延展背景与服装，必要时精细抠出人物；不得把脸压小到远景。下排文字在前景覆盖手臂、服装或座椅，交叠边缘须干净；文字不压眼睛、鼻子和嘴。
3. **T3 重建/补拍**：原素材是多人、正面证件照、强烈逆光或手势遮脸时，需重新拍或锁定人物身份重建姿态与场景。不能为了塞字而拉伸脸型或改变人物身份。
4. **产品替换**：本参考没有独立产品展示区。若行业必须展示产品，让它成为低权重胸针、手边物或环境线索，原胸针约只占画面 1–2%；不能把产品放大到和脸或角字争焦点。

## 行业语义转换

- 先提炼适合四个字表达的真实议题，如设计行业的“何为质感”、律师行业的“何为证据”、餐饮行业的“何为好味”。这些仅是文案结构示例，实际制作必须针对账号身份和当期内容重写；不复制原题“何为审美”。
- 若账号以人物观点、审美判断、专业解释或价值追问建立信任，四字命题和肖像能互相证明。若内容依赖价格、参数、步骤、多个商品对比或强证据截图，本模板不合适。
- 标题严格四个汉字，优先“二字问题/判断 + 二字对象”语义。超出时先改写；不可缩小字号、加第三行或把长句放进角字框。

## 配色与材质

- 色值按身份、肤色和主题重选；面积关系维持：暖暗或中暗背景/空间约 55–70%，人物深色衣着约 20–35%，肤色约 10–18%，浅亮文字约 8–13%，金属或暖亮道具不超过 2–3%。这些区域互有遮挡，不能相加当像素分割值。
- 背景保持低对比、柔和明暗梯度；人物有侧向暖光和温柔阴影，皮肤不过度磨皮。主字为平涂浅亮色，边缘干净，**无**厚描边、投影、发光、纸纹和颗粒蒙版。深色衣服可有真实布料/首饰反光，不能把胸针高亮改成第二标题。

## 失败即退回

- 四角字被排成普通两行标题；下字缩小或底部留出大白边；脸太小、被字遮眼；背景亮度和文字接近；普通宋体完全等距机械排版；书法笔刷飞白/油漆效果；高饱和装饰或金色边框抢走字和脸；复制原图人物、原题、原署名；凭一张参考就标记为已验证或 active。
