# 参考 061｜适配规则

## 内容进入条件

主题必须能被压缩为两行短主张，并有与行业直接相关的工作现场或历史档案照片。先确认账号身份、行业、主题判断、可公开的真实证据，避免把职业场景变成无事实支撑的视觉摆设。原始参考的文字、人物和具体纸色都只是可变内容。

## 锁定的转译语法

1. 画布 3:4；上方旧纸印刷区高度 51–55%，下方黑白纪实摄影区 45–49%，y≈53% 清楚硬切。
2. 旧纸顶端横贯大写衬线主题，左下 3 行分类/领域词，右侧占上段视觉重量约三分之一的不规则黑剪影。双层黑框围住纸面主体。分类词少于 3 项须按新内容补真实维度，不编造行业事实。
3. 白色主标题两行，上行短且右置，约 x 27–95%、y 35–52%；下行长且近满宽，约 x 6–95%、y 55–72%。必须压住右侧黑影与下方照片，形成跨介质连续性。字形遵循 `dalala-cover-061-outlined-poster-block`。
4. 底部 x 7–97%、y 80–88% 安置单行浅暖高明度判断句，依赖 `dalala-cover-061-verdict-han`；上栏与三行分类依赖 `dalala-cover-061-archive-roman`。其文字内容是主标题观点的具体落点，不复述主标题。
5. 后景纸面、英文、双框、右侧剪影、下方照片、两行巨字、底句依序叠合。中文只靠细黑描边与短暗影分离，不用厚描边/发光/三维挤出。

## 素材处理

照片优先保留人物、桌面与绘图动作的真实比例和同一场景透视；裁切保持至少一条可读的职业关系。上方黑影用具有行业意义的建筑、机器、工具或物件轮廓替换，必须仍是压在右半部的大面积深色形。旧照片可做黑白、局部对比、细颗粒处理；身份/事实锚点不变造。纸面可以重新制备，但保留低频不均与细纤维，避免全画面统一滤镜。输入素材若无法支持横向下段的职业现场，先补拍/选图，不通过放大低清晰度竖图充数。

## 可变与禁区

可变：人物身份和数量、场景/器具、行业词、主标题与观点句、纸面的具体色相和底句强调色。禁止：改变两段面积与字块主次；把上行移到左侧；让双框/黑影消失；照片变彩色干净棚拍；把纸纹叠到白字里导致脏字；为容纳长标题增加第三行或挤压字腔；英文无意义乱码；无职业证据的通用 AI 人物。

## 测试与放行

先做原主题结构复刻，再用至少一种逻辑完整的新行业主题测试可迁移性。对照原图检查分界、双框、黑影、两行字和底句；360 px 缩略图检查标题与场景。字层逐字校对，写真素材核查身份/事实。用户确认前只保留 studied/testing 状态。
