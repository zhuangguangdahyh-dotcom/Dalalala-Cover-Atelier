# 参考封面 061｜视觉拆解（待逐项确认）

原图已核对：2526 × 3368 px，严格 3:4。下述 x/y 以左上角为 0%、画布宽高为 100% 的视觉估计；原图并非分层设计文件，范围供复刻起稿，最终仍须叠图核对。此次为首次拆解，尚未复刻、跨内容测试或人工验收。

## 1. 画幅与第一眼

第一眼是两行极大的白色硬块中文：上行横压旧纸招牌与右侧黑影，下行横压黑白建筑/人物纪实照。第二眼才读到上方横贯版心的细衬线英文建筑主题，最后落在照片下方的浅黄判断句。吸引力来自“历史档案的权威口吻”与“当下大字的直白判断”之间的年代碰撞，以及白字横跨纸面与照片边界的压迫感。画面不是一张复古照片加标题：必须同时保留旧纸招牌、纪实摄影、两行巨字的跨介质叠压。

## 2. 内容角色和分区

- **主体/证据图像**：下半张黑白纪实照片，约 x 0–100%、y 53–100%，展示多人在建筑设计工作场景中围桌绘图/伏案工作的档案现场；前景人物约 x 0–72%、y 70–100%，后景人群与建筑约 x 38–100%、y 54–94%。它承担“旧时代建筑行业工作现场”的证据角色，人物不是独立抠出的明星主体。主体脸部可被上方巨字部分挡住，但底部仍应读出至少 1 个清楚的职业动作/场景关系。
- **主标题**：中文超大白字两行。上行约 x 27–95%、y 35–52%，贴近纸面底缘；下行约 x 6–95%、y 55–72%，压在照片上沿。上行比下行短，文字块从右半部开始，下行几乎横贯版心，构成“右收上行、满宽下行”的阶梯。字是视觉第一层，不以副标题挤开其面积。原词仅是这张参考的内容，不随模板固定。
- **副标题/结论句**：底部单行浅暖色中文判断句，约 x 7–97%、y 80–88%，压在照片暗部/中灰部上。字高约 4.0–4.8% 画布高，明显低于主标题；承担观点落点，不应伪装成第三行主标题。新主题须以一句具体、可辨的判断替换。
- **上方英文主题**：大写高对比罗马衬线标题，约 x 6–95%、y 5–16%，在旧纸上横向铺满，和下方黑色双线矩形边框共用近似左右边界。其下有 3 行较小的大写英文分类词，约 x 7–45%、y 18–31%，左对齐，前后由短横/三角式符号夹持。它们提供档案感与主题定位，阅读级别低于中文主标题；不应直接复制原有英文词。
- **装饰/边界**：纸面内双层黑色矩形边框，外框约 x 4–97%、y 2–54%，内框再内缩 1–1.5% 画布宽；黑色建筑剪影从 x 58–97%、y 17–53% 抬入，左高右低的不规则上缘与大字相压。右侧竖排旧纸边缘字与顶部被裁切的残字属于原始档案质感，不是必要文案槽位；可用轻微边缘残印模拟，但不得生成无意义乱码。
- **背景**：上段约 53% 是暖中明度粗纸/旧印刷招牌；下段约 47% 是中低明度黑白摄影。上段不是纯色空白，下段不是彩色照片。纸张、墨印、摄影颗粒以整体统一的年代感连接，两段分界保持清楚。

## 3. 位置、重量与阅读路径

画面水平分界在 y≈53%。顶端英文横轴与双框形成稳定矩形；左侧三行英文列表对应右侧建筑黑影，构成“左信息、右重物”平衡。中文上行重心在 x 60–65%、y 43%，下行重心在 x 50%、y 64%；两行共同把视觉重量从上段右侧拉向下段中部。底部判断句在 y≈84% 把视线重新拉回照片与行业情境。阅读顺序：两行白色中文（先上后下）→ 纸面英文主题/分类 → 黑影与旧照现场 → 底部观点句。可保护的留白主要在上段 x 8–55%、y 31–35% 及旧纸边缘，面积较少；这是有意的密集档案式布局，不需人为加大空白。白色主标题与底句是最强视觉重量；实际像素面积和视觉重量不可混作同一百分比。旧纸约 53% 画布面积、照片约 47%，其余文字与剪影叠在这两个底区之上。

## 4. 素材改造、空间关系与图层

先找/制一张有真实场景线索的旧照：建筑图稿、桌面、人物、绘图动作彼此有因果，透视统一。照片按 3:4 画布横向铺满下段，用裁切决定前景主动作和后景职业环境；不得把一张竖拍人像强行拉宽，也不得只剩模糊背景。上半部使用单独的旧纸版面，黑色建筑/行业对象剪影约占上段右下 30–38% 的视觉重量，沿下缘连接照片；若新行业没有建筑，可换成该行业具有辨识度的设备、空间轮廓或物件剪影，仍须维持右侧大黑形。剪影边缘可不规则，有历史印刷缺口；不应用贴纸式白边。主标题的上行覆盖剪影前沿，下行覆盖照片前景，文字与画面之间靠细黑描边及短投影拉开；无需给人物单独抠图。推荐顺序：粗纸底 → 英文主题和分类 → 双线框 → 右侧黑剪影 → 下半黑白照片 → 两行主标题及描边/投影 → 底部判断句。照片与纸面在 y≈53% 硬切，不做柔和渐变。原图并未对照片人物逐个抠图：人物、桌面和背景仍是同一摄影透视。剪影才是上段独立深色图层；不重复人物或景物来制造密度。素材改造级别通常为 T2（纸面版式与照片裁切重组）；若需根据新主题构建可信年代场景才升至 T3，并把事实/身份锚点单独核对。

## 5. 字体骨架与文字块

中文主标题是极粗、近等线的硬块字，字面宽大，轮廓有轻微人工切角/局部不规则，但仍保持标准汉字结构；不是圆润泡泡体、书法或磨损刷字。白色实填，约 1–2 px/1080 宽的黑色细描边（以成图实测调到能分离纸/照即可），黑灰短投影朝右下约 0.5–1% 画布宽。每字有微小角度差（约 约 ±8°以内），基线总体稳定，局部紧贴/轻度互压，不能出现统一机械间距。每行字间距约字面宽的 -3% 至 2%；两行间距约字高的 10–20%，版面上允许两行轮廓局部接近但不得粘字。上行宜 3–5 字、下行宜 4–6 字，以完整的两行判断句为最佳；超长先改写，不缩字后再硬塞。英文上栏是大写高对比衬线，细粗反差显著，紧密字距，字号约上段高度的 27–33%；左侧分类词与其同一编辑字体家族的小号/较紧字距。底部中文是厚重而较规整的窄身黑体，浅暖实填、清楚黑边及短暗影，清楚区别于白色主标题，不用同一层级。主标题、上栏罗马衬线与底句分别依赖三个测试态字体 Skill，注册条目见 `font-registry-entries.json`；这只是字形规则，并不表示生成字层已通过验收。

## 6. 色彩、材质与效果

参考以暖纸色约 47–52% 作为大底，黑色照片暗部/剪影/边框约 28–35%，黑白照片亮中灰约 12–18%，白色主标题约 10–14%，底句浅暖高明度强调约 3–5%。这些是角色和面积关系，不锁定具体 HEX。新内容可调整纸面冷暖与底句色相，但须保留“中明度有材质上段 + 无彩低明度下段 + 高明度白主标题 + 小面积次强调”的明度秩序。上纸有均匀细纤维/氧化斑、轻微不匀墨色；英文字和边框像旧印刷，局部可轻微缺墨。下照片有胶片颗粒、较硬黑白对比和保留人物层次的中间灰，避免纯黑压死。中文主标题本体保持干净白块，只在边缘做薄线和贴近的投影，不把纸纹全面叠到字内。纸面与照片不加外发光、彩色霓虹、夸张 3D 挤出。

## 7. 为什么成立与适用条件

上段借旧招牌与衬线排印建立专业/历史权威，下段纪实图给“这行到底在做什么”的现场证据，两行现代巨字把判断压在历史材料上；底部口语化断语再把观点落到人身上。适合有行业历史、职业刻板印象、代际变化、设计/建筑/工艺/文化脉络等内容，尤其是“旧叙事与新判断相撞”的观点封面。至少要有一张能够读出职业或场景的照片，以及能提炼为两段短语的主标题；仅有商品白底图或纯信息清单不合适。英文上栏需要真实可核对的行业词，若无英文表达可用真实可核对的拉丁大写领域词组，但不填虚构术语。底部结论句建议中文 12–18 字、单行；实际装入时先检查 360 px 缩略图可读，太长优先改写。

## 8. 跨行业转译与变量合同

先确认账号身份、主题断言、可公开的历史/现场证据，再替换角色：法律行业可用真实/授权的旧式案卷与工作现场；餐饮可用传统后厨或老店经营照；设计/工装可用施工/画图现场；医疗可用经授权的历史工作照与器具。新素材不必是旧照片原人物，但必须承担同样的“行业档案证据”角色。可变：人物/场景/工具、主副文字、分类词、纸面与强调色的具体色值。锁定：3:4 双介质上下分段；上纸约 53%、下照约 47%；顶端横向英文与左三行分类、右侧大黑剪影；主标题上短下长、白色实心黑细边并跨纸/照；底部单行浅亮判断；纸面/照片的年代质感与阅读次序。若改行业后无法给出真实可辨的场景，须先补素材，不能用通用 AI 人偶充当档案。

## 9. 失败模式与逐项 QA

失败：只保留复古滤镜而丢掉双框和双介质；两行标题大小平均、同宽居中；上行被移到纸面中央不压黑影；下行不横贯照片；白字没有边缘分离，贴到黑白照片上不可读；把英文装饰当乱码生成；黑影变成无语义的大色块；照片不含可辨职业动作；底句写成空泛口号或缩略图读不清；把所有颜色锁死为原图色值；靠更换标题位置冒充复刻。

验收时逐项核对：① 2526×3368 原图叠图看分界、框、黑影、三类文字的相对位置；② 360 px 宽缩略图能同时看出双介质骨架和两行主标题，底句至少保持可辨；③ 中文逐字准确、笔画与字腔完整，主标题不是普通粗黑体；④ 下部人物/行业动作与主题相符；⑤ 字体透明层无白底和脏边；⑥ 色彩角色、明度与面积关系成立；⑦ 换一个不同行业的新主题后仍保留同样空间重量、阅读顺序和年代冲突。完成这份拆解仅标记 studied，测试与用户确认前禁止 active。
