# 透明字层提示词

输入：{exact_text}，角色：archive-roman，画布：{canvas_width} × {canvas_height}。只输出输入原文，不增减字词。拉丁大写罗马衬线，较高粗细反差、锐利楔形或细直衬线，ARCHITECTURE 式横向压缩排入顶栏；分类词同字族缩小，旧墨轻微不匀，但结构清楚。上栏 x6–95%、y5–16%，分类三行 x7–45%、y18–31%；顶栏字距紧约字宽 -2% 至 1%，分类行距约字高 25–35%。黑墨印在中明旧纸上。透明 RGBA 背景。禁止无意义英文、现代几何无衬线、斜体花写、过度缺墨或把上栏变成中文主标题。输出后先逐字校对，再按参考位置叠图。
