# 参考 008 Cover Skill

先由 `cover-skills/registry.json` 解析唯一参考原图，再读 [anatomy.json](references/anatomy.json)、[adaptation-rules.md](references/adaptation-rules.md)、[manifest.json](references/manifest.json) 与 [qa.md](references/qa.md)。本轮可供逐项确认的报告在 `skills/dalala-cover-008/references/adaptation-rules.md`。此 Skill 仅记录待确认的结构知识；写入文件不代表复刻通过。

## 调用顺序

1. 确定行业、账号身份、受众、主题、结果承诺和一件能够近景举到镜头前的真实证据物。没有同框证据则拒用本模板。
2. 固定 3:4；用参考的近距离自拍景别重建左脸与右前景手持物。照片可更换人物、衣服、设备与场景，但人脸、手、展示面须属于可信的同一视角。
3. 右上写三段“受众/身份 → 情绪或效率利益 → 场景/结果”，细字分三行；右中写一条短的亲历式反应。底部写两行结果承诺：第一行约数字加四个汉字的宽度，第二行约四个汉字并接近满宽。文字太长先改写，不得挤占脸、屏幕或增加行数。
4. 通过 `font-style-rules/registry.json` 调用测试态 `dalala-cover-008-casual-hand` 的 `fine` 与 `display` 变体，逐字生成透明文字层并检查字形。蓝色右下硬错位背影在封面合成层制作；不得静默改用圆体、普通黑体或其他手写风格。
5. 按原图层序合成，核对 360 px 缩略图。只有分析确认后才能进入真实内容复刻测试；跨行业测试、缩略图 QA 和用户验收均完成之前保持 `studied`、`analysisConfirmed=false`、`renderAllowed=false`。

## 视觉机制

人脸建立亲历可信度，举到镜头前的界面/物件说明内容不是空口承诺，右上短语锁定“谁因此变轻松”，底部大字给出具体结果。右中细字只增加当下口语感。暖自拍底上的冷亮展示面，与奶白主字及小面积冷色硬错位影相互勾连。主体、标题、证据和旁白要说同一件事。

人物身份、文案、证据物和具体颜色可换；近脸/手持物的面积关系、右上三行与右中单行、底部两行一短一长、阅读路径与蓝色硬错位字效的作用位置不可变。禁止默认通用 AI 小人、悬浮设备拼贴、假界面、平均字号、无证据的抽象标题或未经用户确认上架。
