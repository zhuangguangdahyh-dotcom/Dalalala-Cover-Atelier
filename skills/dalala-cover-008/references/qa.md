# 参考 008｜复刻测试检查（尚未执行）

1. 原图叠图检查：3:4；脸、手机/证据、右上三行、右中旁白和底部两行的外接框是否落在 `anatomy.json` 范围；第二行是否明显更大并近满宽。
2. 真实关系：手、物件、屏幕/展示面、人物视线和光线是否属于可信的同一自拍现场；证据与承诺是否对应。
3. 文字：汉字、数字、英文逐字正确；`fine` 与 `display` 的字骨一致，主字硬色影只向右下；无普通字体回退。
4. 360 px 宽缩略图：眼睛、证据物、两行主标题均可识别；右上三段可顺读，旁白不争主视觉。
5. 色彩：暖/中性照片大底为主，展示面冷亮，主字高明度，小面积强调色与硬影呼应；具体色值可变。
6. 流程：真实跨行业测试记录、视觉 QA、用户确认都存在后才可从 `studied` 前进；本轮未完成这些门槛。
