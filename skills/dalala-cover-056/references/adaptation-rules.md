# 056 适配与复刻规则（测试态）

## 输入判断

先确定行业、账号身份、要带用户看的人/物/场景、行动承诺和真实出处。选一名能承担“带看/讲述”角色的主体，与背景在业务上有真实关联。素材应有完整脸部、肩线、胸腹和可延续到底部的下半身；背景需留出左上约 60% 宽和右中约 40% 宽的低竞争区。缺条件先换素材或重裁，不用大量贴纸修补。

## 固定骨架

1. 画布 3:4，照片满版。单人约 x26–75%、y21–100%，脸中心 x53%、y32%（可偏差 ±5 点）。照片环境可见，不改为影棚纯色。
2. 暖灰/中性灰半透明上带 x0–100%、y5–25%；左上主标题 x1–63%、y8–23%，单行 4–6 汉字。前段为引导语，后段为人名/身份或对象，后段通过相邻浅色突出。下带 x59–100%、y30–43%，小标题 x63–98%、y33–39%，单行约 5–7 汉字。主副字高比 2.1–2.4:1。带不拉成圆角卡片。
3. 人像头发压住上带下沿，右侧带从肩颈之后开始；文字和带不盖住眼睛、鼻口。底部署名 x38–63%、y92–95%，小字疏排。下半部不塞正文。
4. 保持左上 → 人脸 → 右中 → 服装/场景 → 底署名的阅读路径。所有坐标以比例控制，适配不同输出尺寸时按比例重新检查。

## 素材转换

- **T1，默认**：照片重裁/扩展以稳定中心人物，压暗或降低背景局部竞争，保留环境透视与真实光线；根据最亮窗格位置调整带的透明度与文字短柔影。
- **T2，遮挡不成立时**：从同一素材抠出头发、脸/肩前景，分层放回横带之上并修复边缘。不得改变人物身份、服装结构、产品信息或环境事实。
- **T3，素材根本不适配时**：更换/重拍与行业一致的场景和人物；不能用无关场景加标题凑版。
- 双带需有可见背景穿透；推荐初测透明度约 45–65%，按实景明度调到字与带、带与背景可分，而不把玻璃窗完全抹掉。颜色随主题定，保留低饱和中明度带和浅色字的层级。

## 字体与图层顺序

主副标题使用 `dalala-cover-056-street-song` 的 `hero` / `support` 两个字级，单独透明层；先按语义切分双色字，后统一短柔影。底署名使用细净无花字中文，四字或相当宽度的真实出处，疏排。图层依次为：全幅照片 → 局部暗化 → 上下半透明带 → 两个标题透明字层与轻影 → 从原片还原的头发/肩前景 → 底署名。必要时把前景局部置于标题附近，但不得切断正文汉字或盖眼睛。

## 内容适配例（供测试，不是已通过案例）

餐饮主理人可用“跟着主理人 / 解锁一席风味 / 真实门店名”，主角站在自身门店，服务线索在后景。医生可用“跟着 X 医生 / 看懂面诊选择 / 真实科室或账号”，后景为真实诊疗工作区。两者都需重写到单行宽度，不得只是替换原人名或原地点；医疗例不可伪造诊疗证据。

## 检查与拦截

测 360 px 缩略图：左上标题、中央主体脸、右中标题的三点关系应立即成立；横带有透明实景，人体轮廓完整。核对字字准确、主副同字体家族、双色有语义切分、字影短而软、底部来源真实。若主标题换行、两带等宽、主体偏离中线、人物被横带盖脸、普通宋/黑体替代测试字形、背景变纯色、信息区占到 y43% 以下，直接判失败并重做。

仅完成接近原图的结构复刻后，再用不同主题和不同内容逻辑进行迁移测试；完成用户逐项验收前不得改为 `active`。
