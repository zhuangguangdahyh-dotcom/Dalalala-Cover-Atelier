# 002 编辑衬线字体规则

测试态；原图可观察风格，不能证明具体字体名称或中文版本已成立。

mainTitle：高反差现代衬线展示字，直立大写，厚直干、极细横画与平直发丝衬线，瘦高字骨；粗细比初值 12:1–25:1，光学紧配字。无倾斜跳动、切口、错位、圆角、磨损或描边。以实际标题整行生成，不直接复制原刊物文字。行内粗细语言一致，重复字不能随机改变字骨。

topImprint：同语系正常大小写衬线，字高为主字的 10–12%。sideEdition：同语系大写，单行旋转成为竖向侧标，不逐字堆叠。issueLine：大写小衬线，字高为主字 6–8%，保持小字清晰。

中文测试：端正现代宋体结构，细横粗竖、尖锐但克制的三角收笔，禁止现有呼吸切口、书法、综艺或黑体替换。中文每个字需完整可识别，尚无确认样张；只允许生成待审核样张。不能声称现成字体可以准确复刻。

字体不锁具体色值。输出独立真实透明文字层，无背景、无阴影、无纹理；局部读不清时调整生产方案并复核，不能增加描边改变身份。

侧标补充：sideEdition 旋转前字高约为主刊头的 6–8%，整行逆时针旋转 90°、从下向上读；不得逐字堆叠。刊头字距按相邻字形光学校正，净空 0–3% 字高仅作测试初值。所有数值来自目测，不是确认字体的测量数据。
