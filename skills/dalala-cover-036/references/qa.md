# 参考 036 QA（拆解测试态）

以下均为硬门槛；未生成测试成品前保持 `not-run`。

- [ ] 输出为 3:4；顶部约 37% 文字、下部约 63% 人物与模块阵列，未改成普通上下海报。
- [ ] 主标题保持左侧 3–6 个拉丁字符、约 7%W 分隔缝、右侧 4–6 字中文命题；两块同色、单行、超窄高耸。
- [ ] 主标题字骨完整，无普通字体机械压扁、描边、投影、渐变、发光或 3D。
- [ ] 副标题 6–9 个中文等效字，单行右对齐，层级显著低于主标题。
- [ ] 一位人物居中坐在 6–9 个同类模块中；脸、手、腿、鞋和身份锚点正确。
- [ ] 坐面、脚部和模块之间有可信受力、遮挡、接触阴影与设备厚度；无悬浮或穿帮。
- [ ] 模块分为后排、承托层、前景层，并由左右/底边裁切；不是九宫格或一排货架。
- [ ] 只有 3–5 块信息面显示真实参数/步骤，透视、发光和玻璃反射成立；无假数据。
- [ ] 浅底、深实体、单一强调色和肤色的面积关系成立，未锁死参考具体色值。
- [ ] 没有贴纸、箭头、价格、底栏、边框、第二人物或无关装饰填满白场。
- [ ] 360 × 480 时先读主命题，人物身份可辨，模块阵列仍有层次，屏幕信息不争抢。
- [ ] 已记录近语义复刻、至少一个完整跨行业测试、字体 QA 和用户验收；缺一项不得批准或上架。
