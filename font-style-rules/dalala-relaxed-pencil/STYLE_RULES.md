# Dalala 松弛速写铅笔体

## 风格身份

这是一套以快速铅笔速写为基础的中英双语手写规则。它应当随性、轻松、干净、清爽，同时具有清楚可见的活人生命力。确认样张为 `references/approved-reference.png`。

生命力来自真实的落笔决定：轻重压变化、行笔速度、局部停顿、短暂重描、略有差异的比例和倾斜，以及不完全齐平的基线。不得用灰色字体叠统一颗粒代替手写。

## 字形规则

1. 每个字符必须独立书写；相同字、相同字母再次出现时也要重新生成。
2. 相邻字符至少在宽窄、高低、倾斜、重心或笔画长度中有一项不同。
3. 中文必须保留标准汉字结构。松弛可以改变姿态，不得改坏部件关系。
4. 每行选择少量笔画做重压、延长、轻微越界或局部重描，其余笔画保持轻快。
5. 起笔可以试探、轻触或斜切入纸；收笔应有快速提笔、干燥渐细或轻微冲出。
6. 轮廓不追求完全平滑，必须保留铅芯经过纸纹形成的细小干边。

## 中英文统一规则

- 中文和英文必须像同一个人在同一时刻用同一支铅笔写成。
- 英文小写采用自然的印刷体与连写混合，只在部分字母之间连接。
- 英文大写和数字必须逐个手写，不得使用规整无衬线体充当副标题。
- 英文允许斜率、字宽、升部、降部和字距变化，但必须保留正确拼写、大小写和标点。
- 双语排版可以有大小层级，材质、笔压和松弛程度不能割裂。

## 清爽边界

- 铅笔纹理只出现在笔画内部和边缘。
- 局部可有淡淡的试笔回声或二次描线，不能铺满全部字符。
- 背景输出必须是真透明；确认样张中的暖白纸只用于观察，不属于标题资源。
- 禁止大面积擦痕、手掌蹭灰、脏纸、炭笔黑块和统一噪点。

## 默认生命力

默认使用 `alive-clean`。它需要明显的字形姿态差异和铅笔压力变化，同时维持干净、轻盈和可读性。不得自动降级为 `clean`。

## 禁区

- 电脑字体改灰后增加颗粒。
- 所有字同宽、同高、同倾斜、同一基线。
- 文艺毛笔字、钢笔书法或标准英文连笔字体。
- 幼儿涂鸦、圆泡泡字、综艺爆炸字。
- 用铅笔、橡皮、卷笔刀等图标代替字形设计。
