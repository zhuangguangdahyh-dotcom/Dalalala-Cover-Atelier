# 猫咪手写体 V1｜耳朵肉垫款

保留真实手写的粗细、长短、角度、比例和重心差异，松而不散。猫咪元素融入局部笔画，保留安静的字形成呼吸。近黑笔画，少量桃粉细节；不套用已有黑体的方角要求。

版本元素：猫耳、肉垫、爪印、条纹尾巴；猫耳顺着上端笔画生长，尾巴延续收笔，肉垫作为点画或笔画内的小细节。

两版并列保留，V2 不替代 V1；不得擅自混合版本。样张原图不重绘、不覆盖。

每次生成逐字检查原文、偏旁和关键字腔，不能用肉垫或毛线球替换整个口部等识别结构。缩至 360 px 检查可读性；检查手写生命力、猫元素融合、所选版本一致性和真实透明背景。评分：文字准确与可读性 30，手写生命力 30，猫元素融合 25，版本一致性 15；至少 85 分且文字结构、版本一致性、透明背景硬门槛全部通过。确认样张仅代表审美认可，不代表其全部字形已通过生产验收。
