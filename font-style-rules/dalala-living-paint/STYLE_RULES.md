# Dalala 生命油漆字：封面文字风格规则

## 定位

这是一套供封面工作台调用的动态字形规则，不是可安装字体。每次标题都要根据原文逐字重画；同一个字在同一句中出现两次，也必须像真实手写一样产生不同的姿态和笔触。

唯一主参考是 `references/approved-reference.jpg`。它定义宽平刷、缺墨露底、松弛手写和儿童般不受训练的字形气质。`references/energy-reference.png` 只补充生命力强度。其余两张图是反例，不得作为生成参考：

- `references/rejected-fixed-font-preview.png`：固定字模造成重复、规整和生命力不足。
- `references/rejected-wrong-character.png`：笔触有活力，但出现错字；只可用于结构错误检查。

默认档位是 `alive-max`。除非用户明确要求收敛，工作台不得自动降低生命力。

## 字体人格

像一个有直觉、有情绪的小孩拿着蘸了油漆的平刷写字：动作直接，比例天真，偶尔写长、写短、写歪或写偏。字不是故意扮丑，也不是统一做旧。每一笔都像当场做出的决定。

## 不可妥协的顺序

1. 先确认原文和标准汉字结构。
2. 再对每个字的每次出现分别设计姿态。
3. 然后生成真实油漆笔触和自然缺墨。
4. 最后组织整句节奏与封面位置。

结构正确是硬门槛。生命力再强，只要错字、漏字、多字或关键部件错误，就必须淘汰。

## 每字独立生成

- 每个字符实例都有独立编号，例如第一个“看”为 `看#1`，第二个为 `看#2`。
- 重复字不能复用、镜像、等比缩放或只改变角度；必须重新生成笔画关系。
- 每个字选择一种主姿态：前冲、后仰、低坐、上窜、横向撑开、纵向压缩、左重右轻或上小下大。
- 相邻字至少在姿态、比例、倾斜、重心四项中有两项不同。
- 每个字必须有一处“大胆动作”和一处“安静动作”。大胆动作承担个性，安静动作让字保持可读。
- 部件比例允许变化 15%–35%，但关键部件的数量、连接和相对位置不能错。

## 真笔触

- 先把每笔当成平刷蘸油漆后真实划过纸面，再形成字，不得先用标准字体再统一加噪点。
- 同一字内也要混合粗、细、长、短、正、斜，不得使用统一笔宽。
- 长笔可延伸 12%–38%，短笔可缩短 10%–30%。常规角度变化 3°–12°，重点笔可到 17°。
- 起笔混合厚重积漆、轻触、双落笔和轻微犹豫。
- 收笔混合突然截断、长拖尾、刷毛分叉和逐渐消失。
- 每个字至少同时出现三种局部油漆状态：实刷、正常含漆、干刷露底。状态在一笔内部也可发生转换。
- 没刷到的缺口沿真实运笔方向出现，大小和密度不均匀；禁止整字平均撒点、统一锯齿或一圈毛边。
- 允许少量回描、接笔错位、压力突变和刷毛分流，但不能遮掉关键识别结构。

## 整句生命力

- 每行选 1–2 个重点字承担主要动作，其余字有强弱变化，不能整行一起吼叫。
- 逐字调整大小、倾斜、基线和间距。相邻字允许轻微挤压，少数长笔可以进入邻字空间。
- 基线可以上下漂移，行首和行尾不要机械对齐。
- 逗号、数字和标点作为语气动作处理，可以缩小、下沉或贴近前字，但不能漏掉。
- 默认每行 4–8 字，优先 1–3 行；最终行数根据底图安全区和标题长度决定。
- 同一标题重新生成时可以得到新的书写版本；同一封面再次导出时，应复用已确认的透明标题层，避免无意改变成稿。

## 三档强度

- `relaxed`：生活化、轻松，变化可见但碰撞少。
- `lively`：明显的高低、长短、粗细和节奏变化。
- `alive-max`：默认档。大胆比例、急停、拖笔、偏航、缺墨和局部挤压充分出现，同时保留清楚字义。

“最大生命力”不等于随机破坏。随机噪点、所有字同样夸张、错误结构和不可读都属于失败。

## 生产方式

1. 按字符出现次数建立 `plan.json`，锁定每个实例的姿态、动作和笔触差异。
2. 为每个汉字准备标准结构参考，只用来校正结构，不作为最终字体骨架。
3. 每次少量生成字符实例，优先 4–8 个；逐字检查后只重做失败字符。
4. 提取每个合格字形为透明 PNG，再按计划组合成完整透明标题层。
5. 标题层与人物照片分开保存和合成，禁止重生底图人物。
6. 在原尺寸和 360 px 宽缩略图分别检查，全部通过后才可进入封面成稿。

## 禁止方向

- 固定 TTF、OTF 或 WOFF 作为主要渲染器。
- 一个标准字模反复排版，或重复字只旋转、缩放。
- 标准黑体、圆体或书法体加统一破损滤镜。
- 统一粗细、统一字宽、统一角度、统一基线。
- 为追求童趣加耳朵、肿包、皇冠、表情或字义图标。
- 大面积平均缺墨、整圈毛边、喷溅贴图和数字化噪点。
- 错字、漏字、异体误写、部件缺失或额外装饰文字。
