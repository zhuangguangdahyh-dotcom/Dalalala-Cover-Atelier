# Dalala 粗记号趣味体：封面文字风格规则

## 规则定位

这是一套实心粗记号笔生成式字体风格。确认样张位于 `references/approved-reference.png`，它是字形、笔触、黑度和趣味节奏的唯一正向标准。

字体必须呈现真实粗记号笔在纸面上的压笔、扁头方向、叠墨和停顿。趣味来自字骨比例、笔画长短和整句节奏，不依靠装饰图案。

## 核心特征

- 笔画为实心近黑色，不能做成镂空字或双层描边。
- 使用宽扁记号笔语法，起收笔要能看出斜切、平切和压力释放。
- 每个字拥有不同的胖瘦、高低、倾斜和重心。
- 同一字内的横画、竖画不得完全等粗、等长、平行。
- 局部允许叠墨、轻微笔芯纹理和纸纤维晕边，但大部分笔画保持厚实干净。
- 生命力来自真实书写动作，不能把标准粗体统一扭曲后冒充手写。

## 字骨与比例

- 部件比例允许变化 15%–32%。
- 每个字选择一种主要姿态：矮胖、高挑、前倾、后仰、横撑或局部压缩。
- 相邻字不得使用相同比例和相同倾斜方向。
- 长笔可延长 10%–28%，短笔可缩短 8%–22%。
- 每个重点字至少有一个出乎意料但合理的动作，如长横突然伸出、竖笔明显下沉或点画放大。
- 所有趣味变化必须保留标准汉字结构和一眼可读性。

## 记号笔触感

- 起笔混合扁头重压、斜切落笔、钝块起势和局部重复压笔。
- 行笔可出现方向变化、重叠变黑、局部变窄和轻微笔芯纹理。
- 收笔混合平切、斜切、快速变尖、短拖和压力释放后的圆钝尾部。
- 纹理必须少量且跟随行笔方向，禁止整字均匀做旧。
- 禁止油漆刷毛、墨汁飞溅、毛笔书法和过度圆润的气球字体。

## 整句趣味节奏

- 每行优先 4–8 字，最多两行。
- 每行选择 1–2 个重点字，放大到普通字的 114%–124%。
- 逐字改变大小、基线、倾斜和间距。
- 允许轻微碰撞，允许重点长笔进入相邻字的间距。
- 两个重点字之间安排一个较安静的字，让节奏有松有紧。
- 标点可以放大、缩小或下沉，但不能抢过标题主体。

## 默认档位

默认使用 `playful`。它应明显有趣、有手写动作，同时保持厚实、清楚和容易使用。

- `casual`：变化较轻，适合生活感标题。
- `playful`：默认档位，比例和节奏变化清楚。
- `wild`：更强的错落、伸笔和碰撞，用于高情绪标题。

## 输出要求

1. 标题逐字准确，不得错字、漏字或多字。
2. 输出为透明背景 PNG 文字层，与封面底图分开保存。
3. 缩小到 360 像素宽后仍能一眼读出。
4. 使用 `VITALITY_QA.md` 验收，总分至少 85。
5. 任一硬门槛失败，重新生成或进入人工复核。
