# Dalala 爆点节奏黑体：封面文字风格规则

## 规则定位

这是一套以加粗黑体块面为基础的强综艺标题风格。确认样张位于 `references/approved-reference.png`，它是字骨、体量反差、爆点分布和整句节奏的唯一正向标准。

这套字的趣味不来自贴纸、描边、阴影或表面纹理，而来自每个字不同的身体状态，以及重点字与安静字交替形成的爆点节奏。

## 不可改变的身份

- 第一眼必须是加粗黑体：厚、实、现代、直接、清楚。
- 默认强度为 `impact-max`，不得自动降低。
- 每行安排 3–4 个爆点字和 1–2 个安静字，禁止所有字同样大、同样吵。
- 爆点字与安静字的视觉体量比至少达到 1.28。
- 不加任何装饰时，缩略图中仍必须明显感到综艺节奏和动作。
- 每个字独立重画；重复字也不能复用同一轮廓。

## 字形动作

每个爆点字只选择一个主动作，做大做清楚：

- 点画突然放大并偏离常规中心。
- 上部变大、下部缩紧，形成头重脚轻。
- 下部明显加重下沉，像踩住整行。
- 长横或斜画突然向侧面爆开，进入相邻字空间。
- 中段压缩，首尾释放，形成挤压反弹。
- 偏旁局部弹出名义字框。
- 字体前倾冲出或后仰回弹。

安静字负责稳住句子，只保留小幅比例差和一个清楚的重心，不得与爆点字争夺注意力。

## 整句节奏

- 禁止平均放大、平均旋转和整行机械波浪线。
- 相邻字不得连续使用相同胖瘦、倾角、基线和重心。
- 爆点成组出现时，前后至少留一个安静字或一段呼吸间距。
- 允许局部碰撞、短粗连接和部件越界，但不得破坏标准汉字结构。
- 整行轮廓应有突然的高点、低点、宽撑和收紧，像一句话连续出现反应和包袱。

## 表面与工具感

- 使用实心近黑色块面，笔画大体等粗。
- 边缘允许轻微手工裁切感，但必须保持干净。
- 禁止记号笔叠墨、油漆刷毛、毛笔飞白和均匀做旧。
- 禁止镂空、描边、阴影、渐变和三维效果参与风格判断。

## 输出要求

1. 标题逐字准确，不得错字、漏字、换字或多字。
2. 输出透明背景 PNG 文字层，与封面底图分开保存。
3. 缩小到 360 像素宽后仍能立即读出，并明显看到爆点节奏。
4. 使用 `VITALITY_QA.md` 验收，总分至少 85。
5. 任一硬门槛失败时重新生成；连续三次失败进入人工复核。
