# Dalala 硬折人文黑体：封面文字风格规则

## 规则定位

这是一套面向专家、创始人和高信任服务内容的粗黑标题风格。确认样张位于 `references/approved-reference.png`，它是字重、方折轮廓、稳重程度和人文变化的唯一正向标准。

第一眼必须正式、可靠、沉稳；第二眼才能看见字宽、字腔、转角和重心经过人为调整。它不能像公文，也不能靠跳字和夸张动作制造活力。

## 不可改变的身份

- 以加粗黑体为基础，笔画厚重、实心、清楚。
- 字体站姿偏宽，视觉重心偏低，具有稳定支撑感。
- 起收笔使用平切或克制斜切，内外转角保持方、硬、利落。
- 禁止圆头、圆角、药丸形字腔和膨胀气球感。
- 默认强度为 `grounded`，不得自动降级为普通黑体。

## 不死板的来源

- 相邻字的宽窄、肩部宽度和上下部件重量有细微差异。
- 字腔可轻微偏左、偏右、偏上或偏下，但保持矩形或梯形结构。
- 个别横画可延长 4%–12%，短画可缩短 3%–9%。
- 每字最多使用一个短斜切、内角缺口、横画轻微伸出或下部加重动作。
- 基线大体稳定，只允许不超过 2% 的上下光学校正。
- 变化必须在第二眼才被发现，不得形成综艺跳字或机械波浪。

## 正式程度

- 适合人物观点、专业判断、知识解释和信任型封面。
- 不能像政府通知、银行公告、合同标题、机构门牌或企业 PPT。
- 避免所有字完全等宽、等高、等距和同一重心。
- 排版应沉稳但留有呼吸，字距依字腔和部件密度做光学校正。

## 表面要求

- 使用实心近黑色，笔画大体等粗。
- 表面保持干净，仅允许极轻微的手工裁切边缘。
- 禁止毛笔、记号笔、油漆、飞白、做旧和纸张纹理。
- 禁止描边、阴影、渐变、三维和外部装饰参与风格判断。

## 输出要求

1. 标题逐字准确，不得错字、漏字、换字或多字。
2. 输出透明背景 PNG 文字层，与封面底图分开保存。
3. 缩小到 360 像素宽后仍能立即读出。
4. 使用 `VITALITY_QA.md` 验收，总分至少 85。
5. 任一硬门槛失败时重新生成；连续三次失败进入人工复核。
