# Dalala 生长行写体

## 风格身份

这是一套现代中性笔行书风格。它保留普通人使用 0.5mm 黑色中性笔自然书写的质感，在稳定可读的行写中加入少量向上、向下或向外生长的动作。

确认样张为 `references/approved-reference.png`。核心比例是 **七成自然行写，三成选择性生长**。生命力必须强，但不能让所有字同时爆发。

## 中性笔规则

1. 使用圆头、近乎等粗的中性笔线条，不模拟毛笔或钢笔尖的粗细反差。
2. 墨色保持干净深黑，只在真实停顿和转折处出现少量积墨。
3. 快速笔画可以轻微跳墨、提笔或出现短促回走，不能使用飞白刷痕和墨汁飞溅。
4. 生命力来自速度、停顿、连带、比例、重心和笔画惯性。

## 行书与生长规则

1. 中文保持现代、日常的偏行书写法，允许局部笔画连带，但不得破坏标准汉字结构。
2. 每个短语只选择 1–2 个重点字；其他字承担安静、紧凑或承接作用。
3. 每行最多出现 3 个明显向外延展的笔画。
4. 重点字可放大 15%–30%，或改变重心、倾斜和基线；不得超过确认样张的野性上限。
5. 延展笔画可进入空白，但不得横穿多个字，不得形成贯穿画面的斜线。
6. 字距可以局部靠近或放开，不能大面积重叠和纠缠。
7. 相同字符再次出现时必须重新书写，姿态与动作不能复用。

## 中英文统一规则

- 中文、英文、数字和标点必须像同一个人用同一支笔完成。
- 英文采用自然印刷体与局部连写混合，连写不能从头贯穿到尾。
- 英文只在少量大写、升部、降部或横画上出现生长动作。
- 必须保留原文大小写、拼写、数字与标点。
- 英文不得退化成规整副标题或标准商业连笔字体。

## 生命力档位

- `natural`：更接近日常行写，仅用于明确要求降低动作时。
- `selective-growth`：默认档位，保持七成自然、三成生长。
- `high-growth`：动作更强，但仍必须遵守“只让少数字表演”的规则。

不得自动从默认档位降级。不得恢复已经否定的“所有字都野蛮爆发”方向。

## 禁区

- 工整硬笔字帖感。
- 所有字同高、同宽、同倾斜和同一基线。
- 所有字同时放大、倾倒、穿插和外冲。
- 横穿多个字符或贯穿画布的巨型长线。
- 毛笔行草、古风书法、钢笔花体和涂鸦字。
- 用藤蔓、枝叶等具象元素解释“生长”。
