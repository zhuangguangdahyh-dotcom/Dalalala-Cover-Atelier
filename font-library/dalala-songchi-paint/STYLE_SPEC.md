# Dalala 松弛油漆体造字规范 v0.1

## 风格核心

字体要像一个性格松弛、动作大胆的小孩，用蘸墨不均的宽油漆刷迅速写下。厚重感来自大面积实色和有分量的主笔，生命力来自每一笔不同的动作以及整字不稳定但可信的重心。

## 1. 字骨

- 不从现成黑体轮廓出发，也不先排标准字再统一变形。
- 同一字中的横画不得等长、等粗、平行；至少一横明显拉长或缩短。
- 部件允许出现 15%–30% 的比例差：左部挤、右部撑，上部小、下部沉。
- 内白不得机械居中；口、日、目等封闭空间可偏向一侧，但不能影响识别。
- 每个字必须有自己的姿态：前倾、后仰、低坐、上窜、横向撑开或纵向压缩，只选一种主姿态。
- 单字仍需守住关键识别笔画，不能用趣味装饰代替汉字结构。

## 2. 笔画动作

- 一笔内部允许出现明显粗细差，最窄处约为最宽处的 55%–75%。
- 起笔可形成短促、厚重的积漆；行笔中段允许突然变薄或露底；收笔可以出现 2–3 条刷毛拖痕。
- 长横可超出常规长度 8%–22%，短横可缩短 8%–18%。
- 角度偏移通常控制在 2°–8°，个别主笔可到 11°。
- 交接方式必须混用：有的笔压成厚结，有的笔差一点没有接上，有的笔发生轻微错位。
- 每个字最多保留 1–2 处回刷或修补痕迹，不能所有笔都做同一种破损。

## 3. 油漆表面

- 缺墨跟随书写方向出现，不能使用覆盖整字的随机噪点蒙版。
- 单笔露底面积通常为 2%–12%；主识别笔画不允许被大面积挖空。
- 边缘应同时存在钝口、刷毛分叉和局部飞白，禁止统一锯齿或统一圆角。
- 一字之内必须同时出现偏湿、正常和偏干三种局部含墨状态。

## 4. 生命力检查

每个新字入库前必须回答：

1. 遮住纹理后，单看字骨是否仍然像手写？
2. 任取两笔，它们的粗细、长度、角度、起收方式是否明显不同？
3. 这个字是否有独立姿态，而不是同一字体骨架的统一做旧？
4. 最少是否存在一处大胆动作和一处克制动作？
5. 缩小到封面标题尺寸后，字义是否仍可一眼识别？

任意两项不成立，不能进入正式字库。

## 5. 排版层的自然变化

以下变化由 Cover Engine 根据作品 ID 确定性生成，不永久写进基础字形：

- 单字基线偏移：字高的 -3% 至 +3%。
- 单字旋转：-2.5° 至 +2.5°。
- 字间距：基础值的 75%–125%。
- 水平或垂直缩放：95%–105%，每个字只选一个方向轻微变化。
- 重复汉字优先切换手工替换字形；没有替换字形时才使用上述微调。

禁止每次刷新完全随机。相同作品 ID、字体版本和文案必须得到相同排版结果。
