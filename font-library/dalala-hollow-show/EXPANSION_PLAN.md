# 扩字计划

## 第一阶段：样张与高频语气字

当前母版覆盖：

```text
今 天 有 点 好 笑 这 也 太 离 谱 了 吧 的 不 ！
```

下一批优先补充综艺标题常用字：

```text
真 很 又 还 我 你 他 她 们 怎 么 能 会 别 快 看 说 到 底 啊 呀 呢 吗 ？
```

## 第二阶段：情绪与反应

```text
惊 喜 怕 气 爽 疯 绝 救 命 尴 尬 崩 溃 无 语 可 爱 搞 怪
```

## 第三阶段：封面通用词

根据封面工作台真实标题统计补字，不按字典顺序铺满。优先收录重复出现且能形成稳定栏目资产的汉字。

## 单批生产流程

1. 每批最多 16 个字符，使用 4 × 4 独立母版。
2. 每个字必须完整居中并保留安全边距，禁止字间碰撞。
3. 先对照 `approved-style-reference.png` 检查生命力，再检查汉字结构。
4. 切分后保存单字 PNG 与 SVG，编译 TTF。
5. 用真实 TTF 渲染至少两组短标题，不用母版截图代替回测。
6. 复杂字和高频字最终制作 3 个替换字形，减少机械重复。

## 禁止事项

- 不直接从整句概念图粗暴切字。
- 不用系统字体描边后叠加噪点补缺字。
- 不因追求狂放而牺牲关键部件。
- 不把所有字做成相同倾角、相同长横、相同干刷尾巴。
