# Dalala 镂空综艺体造字规范 v0.1

## 风格核心

字体像一个有表现力的人在兴奋状态下一口气写出。它粗、空、松、活，带有临场发挥的速度和判断。每个字都应有自己的身体姿态，每一笔都留下不同的力度、犹豫、加速和收势。

## 1. 字骨

- 不从标准黑体轮廓出发，不以统一描边制造手写感。
- 同一字中的横画不得等长、等粗、平行；至少一笔明显伸出或收短。
- 部件比例允许有 18%–35% 的差异，如左紧右松、上小下沉、外扩内挤。
- 每个字只选择一个主要姿态：前冲、后仰、低坐、上窜、横撑或纵压。
- 字的重心可以偏移，但关键识别笔画必须保留。
- 内白不机械居中，允许偏向一侧、忽宽忽窄，并与外轮廓保持可读距离。

## 2. 单笔生命力

- 一笔内部最窄处可为最宽处的 45%–75%。
- 起笔混用厚压、轻触、短促回锋和轻微重复落笔。
- 行笔可出现突然加速、局部变薄、轻微偏航或短暂犹豫。
- 收笔混用平切、斜切、尖收、短钩、干刷分叉和拖尾。
- 长笔允许超出常规长度 12%–32%；短笔允许缩短 10%–25%。
- 常规角度差控制在 3°–10°，承担情绪的主笔可达到 15°。
- 每个字至少有一处大胆动作和一处克制动作，不能所有笔都同时夸张。

## 3. 镂空外框

- 每一笔先按粗手写笔画理解，再分别勾出外沿与内沿；两条边不得机械平行。
- 外框粗细随压力变化，禁止全字使用统一线宽。
- 外轮廓允许顿挫、折角、局部回描和轻微错线；内轮廓相对收敛，保证镂空清楚。
- 局部可以出现双线修正、接笔差一点碰上或略微压住，但每字最多 1–3 处。
- 不使用整字统一锯齿、随机噪点或做旧蒙版制造假手绘。
- 复杂字缩小后，镂空通道不得粘死；必要时主动放大内白。

## 4. 字间关系

- 单字基线允许上下偏移字高的 -5% 至 +5%。
- 单字旋转允许 -4° 至 +4°；承担情绪的个别字可到 ±6°。
- 字间距允许为基础值的 62%–128%，相邻字可轻微挤压或碰撞。
- 单字水平或垂直缩放允许 92%–110%，每个字只突出一个方向。
- 一行内要有疏密、升降和快慢，不能平均分布。
- 标点可以明显缩小、下沉或靠近前字，作为语气动作使用。

## 5. 综艺感边界

- 综艺感来自字的动作和节奏，不依赖星星、爆炸框、贴纸或廉价描边。
- 活泼不等于幼儿园卡通；避免气球字、统一圆头和过度可爱。
- 粗犷不等于难读；标题在手机缩略图上必须一眼读出。
- 松弛不等于散乱；一组标题仍要有共同的笔压、镂空尺度和黑白密度。

## 6. 入库检查

每个新字入库前必须通过：

1. 遮住边缘纹理，只看字骨是否仍像人写的？
2. 任取三笔，长短、粗细、角度和起收是否明显不同？
3. 外沿和内沿是否存在自然差异，而不是等距描边？
4. 是否有一个鲜明主姿态，同时保留汉字识别结构？
5. 是否至少有一处大胆动作和一处克制动作？
6. 缩小到小红书封面标题尺寸后，镂空是否仍清楚？
7. 与字库其他字并排时，是否同族但不复制同一姿势？

任意两项不成立，不能进入正式字库。
