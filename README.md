# Dalalala Cover Atelier

一个在自己电脑上运行的 AI 封面设计工作台。它包含两个完整工作区：**爆款封面制作**用于输入内容、上传素材、选择已上架封面并制作；**风格实验室**用于导入参考、拆解规则、复刻测试和验收上架。右上角按钮切换工作区。当前版本打开即用，**没有工作台登录页**。

> 这是本机安装版，不是网页 SaaS。每位安装者使用自己电脑上的 Codex 登录和可用额度；分享仓库链接不会分享作者的账号或额度。服务只监听 `127.0.0.1:4318`，不要用端口转发、反向代理或隧道直接对外开放。

## 安装前准备

1. **macOS 13 或更高版本。** 仓库带有 macOS App 外壳；命令行启动方式依赖 Node.js，其他系统尚未完成验证。
2. **Node.js 20 或更高版本。** 在终端执行 `node --version` 检查。运行工作台本身不需要 `npm install`，服务端只使用 Node 内置模块。
3. **Codex CLI，已在本机登录。** 在终端执行 `codex --version` 检查。封面制作、拆解与最终验收由本机 `codex exec` 执行。只安装工作台而没有可用的 Codex，仍能浏览模板，但制作任务会失败。Codex 运行环境还必须能实际调用图像生成工具；检测到 CLI 不等于已经验证生图可用。
4. **网络连接。** 下载仓库、Codex 执行及图像生成需要网络；可用性取决于安装者的账号与服务地区。

## 下载和启动

在 [GitHub 仓库](https://github.com/zhuangguangdahyh-dotcom/Dalalala-Cover-Atelier) 点击 **Code → Download ZIP**，解压到一个以后不随意移动的文件夹；也可以用 Git：

```bash
git clone https://github.com/zhuangguangdahyh-dotcom/Dalalala-Cover-Atelier.git
cd Dalalala-Cover-Atelier/workbench
node server.mjs
```

终端出现 `Dalala 工作台 http://127.0.0.1:4318` 后，在浏览器打开 [http://127.0.0.1:4318](http://127.0.0.1:4318)。不需要注册工作台账号。首次启动会自动把随仓库附带的 63 款已验收模板名称、说明与展示图导入本机数据目录；之后的修改只保存在本机，不会被仓库更新覆盖。

macOS 也可以双击 `workbench/start.command` 启动服务，再打开上述地址。若系统不允许双击执行，可在终端进入 `workbench` 目录运行 `chmod +x start.command`，然后重试。关闭运行服务的终端会停止工作台。

### 可选：生成 macOS App

如果安装了 Xcode Command Line Tools，可以在仓库的 `workbench` 目录执行：

```bash
./macos/build-app.sh
open "build/Dalala 封面工作台.app"
```

App 会启动同一套本机服务，并打开独立窗口。**请把 App 留在仓库的 `workbench/build/` 文件夹中**；需要桌面图标时，请在访达中为它创建“替身”，不要只把 App 本体移到“应用程序”而丢下项目文件。重新下载或更新仓库后，可再执行一次构建脚本。这个 App 是本机临时签名版本，首次打开可能需要在 macOS 中手动允许。

## 两个工作区怎么用

### 爆款封面制作

1. 写下本次内容或封面标题，可上传人物、产品或场景照片（JPG、PNG、WebP，最多 6 张，每张不超过 20 MB）。
2. 选择画幅：默认竖版 `3:4`；也提供横版 `4:3` 和 `16:9`。
3. 在已上架模板中看参考样张、名称与适用建议，点击喜欢的模板开始制作。工作台会读取对应封面 Skill、字体规则和当前素材，按模板固定的版式关系生成。
4. 等待页可观看素材轮播，或主动选择“猫咪版贪吃蛇”。生成完成后查看成品、保存，或写明修改意见重做。

模板约束：人物、文案、产品和具体配色可变；排版、画面占比与标志性效果要遵守所选模板。完成后仍应检查文字准确、人物与产品保真、缩略图可读性和模板相似度。

### 风格实验室

右上角切换进入。可以批量拖入自己的新参考图，在待拆解列表中选择并发拆解；逐张确认拆解结果、查看和调整 Skill 规则、用自己的素材或内置御用模特做复刻测试，最后选择合格样张验收上架。已上架模板可以返厂重测或从目录移除。任务记录提供排队、插队、暂停、继续、取消和失败重试等操作。拆解与测试仍需安装者自行判断审美和授权。

## 模板与原图的公开版边界

公开仓库保留 **63 款已上架模板的名称、建议、规则、字体依赖和已验收展示样张**，也保留风格实验室。作者收集的第三方爆款封面原图及其原图副本未随公开仓库分发，因为公开再分发权无法确认。为保证安装版可以浏览与调用这些模板，仓库中的 `参考封面图/` 和各 Cover Skill 的视觉参考位置链接到对应的**已验收展示样张**。因此公开版的视觉参考与作者本机保存的原始拆解证据不同；若需研究某张原图，请自行取得授权并通过风格实验室导入自己的参考，不要假定展示样张等同于原始图。

`layout-rules/` 的通用构图参考来自另一个带许可证的资料源，许可证及来源审计保留在该目录。颜色、字体、人物模型与模板规则位于各自目录。勿把某一参考图的配色当成模板唯一配色。

## 文件与数据位置

- `workbench/public/`：前台、风格实验室、等待页和猫咪游戏界面。
- `workbench/server.mjs`：本机服务、任务调度与 Codex 执行入口。
- `workbench/seed/`：公开安装版的已验收模板目录和展示样张；仅在首次启动且本机目录尚无模板数据时导入。
- `workbench/data/`：**安装者本机私有数据**，包括上传、作品、任务、日志和后续模板修改；已被 `.gitignore` 排除，不应提交或发送给别人。
- `cover-skills/registry.json` 与 `skills/dalala-cover-*/`：每张封面的注册记录和独立规则。
- `font-style-rules/`、`layout-rules/`、`color-rules/`、`model-assets/`：字体、排版、配色和人物模型资源。

公开仓库不含作者的 Codex/ChatGPT 登录信息、API 密钥、会话或历史任务。首次运行产生的数据只在安装者电脑上。卸载时先备份 `workbench/data/`；删除仓库文件夹会一并删除本机作品与任务记录。

## 更新、备份与排障

**更新：**先备份 `workbench/data/`，停止服务，在仓库目录执行 `git pull`（ZIP 用户下载新版并替换程序文件）。不要用新版仓库的空数据目录覆盖旧 `workbench/data/`。更新 App 外壳时重新执行 `./workbench/macos/build-app.sh`。

**页面打不开：**确认终端仍在运行、`node --version` 正常、访问的是 `http://127.0.0.1:4318/`。若 4318 被其他程序占用，先停止旧工作台进程；本版 App 和文档默认使用 4318，临时改 `PORT` 启动时 App 外壳不会自动跟随。

**未找到 Codex：**在终端运行 `codex --version`；若命令不存在，先按 Codex 官方安装和登录步骤配置。工作台查找当前 `PATH`、`~/.local/bin` 和常见 App 安装位置；装在其他位置时可在启动前设置 `DALALA_CODEX_BIN` 为可执行文件完整路径。

**任务开始后失败：**在工作台任务记录中查看阶段和失败原因。`Codex 已发现`只说明找到了可执行程序；图像工具、账号额度、网络、模型权限以及文字/模板质量都需要实际任务验证。失败结果不会把原参考图冒充新成品。

**刚装好却看不到模板：**检查 `workbench/seed/templates.json` 和 `workbench/seed/showcases/` 是否随仓库完整下载，重新启动服务。首次导入发生在 `workbench/data/templates.json` 不存在时；已有本机数据会优先保留。

**安全边界：**免登录版本默认拥有本机管理能力，包含风格实验室。只在自己的电脑上运行。不要把 4318 端口通过公网隧道、路由器端口映射或反向代理分享给别人。

## 验证与许可

在 `workbench` 目录运行 `npm test`，检查本机接口、模板状态与免登录入口。macOS App 可用 `./macos/build-app.sh` 构建。真实生图质量需使用安装者自己的 Codex 环境做一次端到端测试，自动测试不代表图像模型已可用。
